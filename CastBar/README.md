# Cast Bar — KHQOL 1.5.2

1.8.5: 긴 액션명은 줄바꿈하지 않고 한 줄로 표시합니다. 표시 가능 폭(최대 진행 바 폭의 65%)을 넘을 때만 글자를 1pt씩 최대 2pt 줄이고, 그래도 길면 UTF-8 글자 단위로 말줄임표(…)를 붙입니다. 시간 표시를 위한 기존 여백도 유지합니다. 짧은 액션명 및 저장된 글자 크기는 바꾸지 않으며 바 폭이 늘면 원문과 기본 크기를 다시 적용합니다.

Lua 5.1 문법 및 모의 검증을 통과했습니다. 실제 게임 화면에서는 아직 확인하지 않았습니다. 보호된 액션명은 문자열을 자르거나 비밀 너비를 비교하지 않고 네이티브 한 줄 렌더링과 폭 제한을 적용합니다.


1.5.2: 차단 불가 색상 옵션을 제거했습니다. 차단 불가 시전도 일반 바 색상을 사용합니다. 배경 색상 팔레트에도 투명도 조절을 추가했습니다. 바와 배경의 투명도는 독립적으로 저장·적용되며 취소하면 원래 값으로 복원됩니다.

1.5.1: Appearance의 바 색상 팔레트에 투명도 선택을 추가했습니다. 변경은 즉시 적용되고 저장됩니다. 취소하면 RGB와 투명도를 모두 원래 값으로 복원합니다. 투명도는 진행 바에만 적용하며 아이콘·텍스트는 유지합니다.

플레이어 전용 시전·채널 바입니다. `/kh cast` 또는 KHQOL 설정의 **Cast Bar**에서 설정합니다.

모듈은 기본 활성화됩니다. 기본 크기는 아이콘을 포함한 전체 폭 300, 바 높이 22이며, 독립 위치는 화면 중앙 기준 X 0 / Y -120입니다. 위치 잠금을 해제하고 미리보기를 켜면 주문을 시전하지 않고 이동할 수 있습니다.

색상, 배경, 텍스처, 아이콘, 주문명, 시간, 방향, 위치는 즉시 적용됩니다. 방향은 바 채움에만 적용됩니다. 주문명과 시간은 활성 상태에서 동일 위치를 사용할 수 없습니다. 표시를 다시 켜면 마지막으로 켠 항목의 위치를 유지하고 상대 항목을 이동합니다.

미리보기는 정적이며 실제 시전이 우선합니다. 설정 페이지를 떠나거나 창을 닫으면 미리보기가 종료됩니다. 정상 종료 후 바가 숨겨지고, 중단·실패는 0.45초 동안 표시됩니다.

ResourceSwing 위/아래를 선택하면 기존 공개 프레임에 Anchor만 연결합니다. ResourceSwing이 꺼지면 독립 위치를 사용합니다. 폭 연동 시 아이콘을 포함한 전체 프레임 폭을 맞춥니다. 별도 주문명·시간의 외부 위치는 바 위쪽입니다.

DGROUND는 1.4.1 첨부에 없습니다. Blizzard 기본, 단색, Raid, Skill 텍스처를 지원하며 기본 선택은 Blizzard 기본입니다. Channel과 차단 불가 시전은 일반 시전 색상을 공유합니다.

Forever의 `UnitCastingDuration` / `UnitChannelDuration`과 네이티브 StatusBar 타이머를 우선 사용합니다. 네이티브 타이머가 없는 환경에서는 공개된 시작·종료 시간에 한해 계산합니다. 보호된 시간값에 대한 직접 연산은 하지 않습니다.

Blizzard 바는 삭제·재부모화·이벤트 해제 없이 숨기며 비활성화 시 상태를 다시 동기화합니다. 보호된 프레임의 전투 중 변경은 전투 종료까지 미룹니다. 이 경우 기본 바와 사용자 바가 일시적으로 함께 보일 수 있습니다.

Lua 5.1 문법, 이벤트·설정·저장값 복구 모의 테스트는 통과했습니다. 실제 Forever 클라이언트의 시전, 전투 오염, 화면 배치, `/reload` 및 로그아웃 후 디스크 저장은 게임에서 확인해야 합니다.
