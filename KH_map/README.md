# KHQOL 1.11.2 — 미니맵 모듈 (KH_map)

KH_map 1.0.0을 KHQOL 선택 모듈로 통합했습니다. **KHQOL 공통 기반이 필요합니다.** 설치 폴더 `KH_map`과 계정 저장 변수 `KHminimapDB`는 유지하며 기존 설정을 자동으로 읽습니다. 폴더명 변경이나 WTF 이동·삭제는 필요하지 않습니다.

`/kh`의 왼쪽 **미니맵** 메뉴는 **인터페이스 바로 아래**입니다. 기존 **미니맵 / 버튼 정리** 두 탭, 항목·선택지·범위를 유지하고 KHQOL 공통 글꼴·색·버튼·ON/OFF·입력·반응형 배치를 적용했습니다. 독립 설정창 대신 공통 설정창을 사용합니다. `/khmap`, 사용 가능한 경우 `/kh_map`·`/khminimap`, 보관함 우클릭도 이 창을 엽니다.

## 미니맵

| 항목 | 설정 |
|---|---|
| 외형 사용 | OFF·게임 편집 모드 때 원래 UI로 복원 |
| 모양 | 원형 / 사각형 |
| 미니맵 크기 | 180~300 UI px |
| 색상 변경 | 테두리 색상 |
| 지역명 표시 | 지도 마우스오버 때 표시, 100~200%, 지도 외부-위 / 내부-위 |
| 위치 · 지도 및 주변 아이콘 | 공통 잠금, 주변 아이콘 크기 70~150% |
| 표시할 아이콘 | 우편 / 검색 / 낮·밤 각각 ON/OFF |
| 초기화 | 지도 위치와 주변 아이콘 위치를 구분해 초기화 |

잠금 해제 후 지도 손잡이 또는 주변 아이콘의 이동 손잡이를 드래그합니다. 원래 검색 메뉴·우편 알림·낮밤 갱신과 원본 엔진의 화면 경계 처리를 유지합니다. KHQOL 모듈 사용을 OFF하면 외형과 보관 버튼을 복원하고 설정값은 남깁니다.

## 버튼 정리

| 항목 | 설정 |
|---|---|
| 사용 | 보관함 ON/OFF |
| 아이콘 크기 | 20~30 UI px, 기본 24 |
| 방향 | 위 / 아래 / 왼쪽 / 오른쪽 |
| 정렬 | 가로형 6열×n행 / 세로형 n열×6행 |
| 보관 버튼 목록 | 체크한 버튼 보관, 원래 숨김·접근 제한 상태 표시 |
| 목록 새로고침 | 늦게 생성한 버튼과 등록 메뉴 재확인 |

보관함 버튼은 원래 27×27 UI px와 #1F1F1F 배경을 유지합니다. 좌클릭으로 펼치기·접기, 우클릭으로 설정, 드래그로 이동합니다. LibDBIcon, KHQOL·Forever Note·Books on map 실물 버튼과 AddonCompartment 등록 메뉴의 원래 처리·중복 방지·클릭·툴팁·숨김 의도를 유지합니다.

## 저장·호환성

지도·버튼 세부 설정과 위치·제외 목록은 계정 공용이며 전체 KHQOL 프로필을 바꿔도 유지됩니다. 모듈 사용 토글만 전체 프로필에 저장됩니다. 미니맵 모듈 초기화는 계정 공용 세부 설정을 초기화합니다. 설정창 위치는 공통 설정창 정책을 따르고 옛 `settingsPosition` 값은 보존하지만 독립 창에 적용하지 않습니다.

전투 중 적용·복원은 전투 종료 후 최신 설정으로 처리합니다. 다른 외형·버튼 관리 애드온과 충돌하거나 원래 엔진이 지원하지 않는 지도 구조이면 이유를 표시하고 해당 기능을 보류합니다. 다른 모듈을 자동으로 켜지 않습니다.

## 검증·출처

이번 미니맵 통합 모의 검사 18/18과 원본 1.0.0 대비 동작 대조 14/14를 통과했습니다. KHQOL 전체 회귀 256개와 계정 파티 프로필·메뉴 검사 24개를 포함한 합계는 312/312입니다. 실제 게임 화면·입력·전투·taint·디스크 저장은 미검증입니다. REPORT.md와 TEST_RESULTS.md의 1.0.0 본문은 당시 이력이며 그 119개를 이번에 재실행한 것으로 계산하지 않습니다.

Theme.lua와 세 동봉 그림은 원본 그대로입니다. 새 외부 라이브러리·소재를 추가하지 않았습니다. 설치와 A/B 캐릭터 프로필 이전은 `KHQOL/INSTALL-GUIDE.md`를 참고하세요.
