게임 폴더·WTF·다른 애드온 파일과 sources/는 수정하지 않았습니다. ZIP은 KH_map 단일 폴더와 13개 파일(TOC, Lua 5개, 문서 4개, TGA 3개)로 구성합니다. 이전 개발 파일까지 정리하려면 설치 폴더 전체를 교체하도록 안내했습니다. 디스크의 기존 백업 파일을 자동 삭제하지 않습니다.

## 유지한 동작

주 설정창 LOW strata/레벨 1, SetToplevel(false), 열 때 Raise 미호출을 유지합니다. 드롭다운·외부 클릭 닫기 영역도 LOW이며 다른 애드온 표시 순서를 수정하지 않습니다. 정규화 위치 저장·드래그 중 배치 보류·닫을 때 이동 종료·작은 화면 보정도 유지합니다.

원형/사각형·180~300 크기·테두리, 전체 지도 마우스오버 지역명·위치·배율, 우편/검색/낮밤 표시·배율·이동, 화면 끝 배치·기본 핑·휠·추적·우편·낮밤 이벤트를 유지했습니다. 전투·편집 모드·외부 소유권 변경에 대한 지연과 조건부 복원도 유지합니다.

LibDBIcon 고정 레벨을 수납 중에만 해제해 아이콘을 배경 위에 그리는 수정, 최신 소유자 위치·잠금·그리기 순서 복원, KHQOL·Forever Note·Books on map·AddonCompartment 지원을 유지합니다. 보관함 4방향·두 정렬·화면 경계·페이지, 27 UI px 여닫기 버튼과 불투명 #1F1F1F 배경도 유지합니다.

프레임 원복용 메모리 내 속성 journal은 개발 로그와 별개이므로 유지했습니다. 아직 소유한 값만 복원하며 SavedVariables에 프레임·함수는 저장하지 않습니다.

## 검증

Lua 5.1 모의 검사 **119/119 통과**. 이전 150개 중 삭제된 진단 기능 검사 32개(기능 30개, 재접속·진단 파일 제외 시작 2개)는 이전 자료로 보관했습니다. 기존 기능 회귀 118개를 유지하고 로그 UI·명령·이벤트·입력 후크 제거 및 일반 동작 유지 검사를 추가했습니다.

두 독립 런타임에서 일반 설정 저장 호환성을 검사했습니다. 이전 로그가 포함된 계정 값에서도 일반 설정은 유지하고 로그만 버리는지 확인했습니다. 여러 화면 크기·UIParent 배율의 90% 비율, 드래그·재열기·경계, 설정창·컨트롤·드롭다운의 낮은 표시 순서를 검사했습니다. 확대된 닫기 버튼으로 드롭다운까지 닫고 설정을 다시 여는 동작도 확인했습니다.

정적·원본 대조 **11항목**은 Lua 문법, 버전·아이콘·TOC 로드 순서, 일반 설정만 저장하는 선언, 로그 코드 제거, 외부 의존성·전역 스캔·반복 타이머 부재, 기본 UI·호환 애드온 원본 해시, 제공 그림과 둥근 스위치 알파를 포함합니다. ZIP **4항목**은 파일 목록·CRC·바이트 일치·아카이브 코드와 TOC 재확인입니다.

90% 두 탭을 약 677×612 모의 미리보기로 그려 X 크기·텍스트·배치를 확인했습니다. 실제 게임 스크린샷은 아닙니다. 게임 화면·입력·폰트/텍스처·보호/taint·전체 애드온 조합·실제 저장은 미검증입니다.
