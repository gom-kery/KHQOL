## 0.1.2-preview · 2026-10-17

사용자가 제공한 세 개의 진단 로그를 바탕으로 미세한 레이아웃 수치 차이를 외부 변경이나 잘못된 버튼 크기로 판단하는 문제를 수정했습니다.

- 정사각 버튼의 가로·세로 비교와 16~64 UI px 경계에 0.01 UI px 오차를 허용. 부모·배율 변경 후 수납과 제외가 반복되는 현상을 방지.
- 미니맵 소유권 확인·원복에서 크기·앵커 오프셋은 0.01 UI px, 배율·알파는 0.00001 오차를 허용. 부모·스크립트·앵커 수·프레임 레벨 등은 정확히 비교.
- 실제 외부 크기·배치 변경에는 기존 제어 중단·조건부 원복 유지.
- 진단 수치를 소수점 아홉 자리까지 보존하고 OWNERSHIP_LOST에 이전·현재 값을 함께 기록.
- 실제 상태가 같으면 적용 전·후·후속 단계명만 다른 STATE 기록을 중복 추가하지 않도록 수정.
- 기존 설정·로그 저장 형식 유지. 설치 후 `/reload`로 적용.

기존 코드에서 새 회귀 검사 여섯 항목의 실패를 재현한 뒤 수정했습니다. 전체 모의 검사 **85/85 통과**. 새 버전의 실제 인게임 검증은 미실시입니다.

## 0.1.1-preview · 2026-10-17

- 설정 아래에 개발용 기록 ON/OFF, 현재 상태 기록, 로그 저장/복사, 기록 지우기 추가.
- 설정 변경 전후와 0.25초 뒤의 안정된 상태를 기록. 수납함·지도 조작, 수납 제외 이유, 외부 버튼 변경 메서드와 가능한 호출 경로 포함.
- 미니맵·컨테이너·기본 알림·수납함·버튼의 실제 부모·앵커·가로·세로·배율·표시 여부·레이어·스크립트 유무 기록.
- 수납 표시와 실제 부모가 다른 경우, 닫힌 수납함의 버튼이 보이는 경우, 미니맵 실측 크기 불일치 진단 표기.
- 복사 전용 창과 선택적 증상 메모. 자동 전체 선택 후 Ctrl+C. 복사 중 출력 고정.

- 전투 중 상세 프레임 조회 보류, 전투 후 상태 기록. secret·접근 제한 값은 대체 표기.
- `/khminimap log` 진입 경로. 개발 빌드 스위치를 끄면 진단 UI·수집 비활성화.
- 기존 미니맵 설정과 수납 대상 판정·복원 정책 유지. 전체 설치 ZIP 갱신.

기존 기능 회귀와 진단 기능을 합한 모의 검사 77개 통과. 실제 게임의 새 진단 창·Ctrl+C·디스크 저장은 미검증입니다.
