# 검증 보고서 — KHQOL DevTools v0.1.5

## 구현 완료

- 독립 애드온 폴더, Interface `16001`, 독립 `KHQOL_DevToolsDB` SavedVariables를 사용하며 `KHQOL` 의존성 항목이 없습니다.
- 멀티라인·스크롤을 지원하는 공통 복사창을 구현했습니다. 포커스 설정, 전체 텍스트 선택, Esc 닫기를 지원합니다.
- Frames 탭은 탭이 열려 있고 추적이 활성화된 경우에만 0.25초 간격으로 프레임을 샘플링합니다. 단축키 입력 시점에는 복사창을 열기 전에 마우스 위치를 다시 조회하며, 자체 창은 캡처 대상에서 제외합니다. 스냅샷에는 부모 체인·앵커·Frame Stack 실행 시도가 포함됩니다.
- 키 바인딩 항목 `KHQOL DevTools: Capture frame under cursor`를 등록했습니다. 기존 사용자 단축키를 덮어쓰지 않기 위해 기본 키는 지정하지 않았습니다. 게임 내 키 설정에서 Ctrl+Shift+C를 직접 지정할 수 있습니다.
- Console 탭은 수집 활성화/비활성화, 일시 정지/재개, 세션 로그 개수 제한(10/50/100/250/500), 초기화, 최신 결과/전체 결과 복사를 제공합니다.
- 전역 `print`를 교체하거나 후킹하지 않습니다. 채팅 이벤트 필터는 `false`를 반환하므로 채팅 출력이 숨겨지거나 변경되지 않습니다.

## 정적 검증 완료

- TOC가 참조하는 Lua 파일이 존재하는지 확인했습니다.
- `Bindings.xml`은 의도적으로 TOC에 넣지 않았습니다. WoW는 정확히 이 이름의 파일을 키 바인딩 매니페스트로 별도 로드합니다. TOC에 넣으면 Forever 클라이언트가 일반 UI XML로 해석하여 “Unrecognized XML: Binding” 경고를 발생시킵니다.
- TOC에 KHQOL 의존성이 없고, 소스에 `KHQOL.` 코어 참조가 없는지 확인했습니다.
- 소스에 `_G.print` 대입 또는 전역 `print` 교체가 없는지 확인했습니다.
- ZIP 파일에 설치 가능한 최상위 `KHQOL_DevTools` 폴더 하나가 포함되는지 확인했습니다.
- 버전 `0.1.1`에서는 `Bindings.xml`을 TOC에서 제거하여 바인딩 매니페스트 로딩 문제를 수정했습니다.
- 버전 `0.1.2`에서는 빈 Console에서 **Copy Latest**를 눌렀을 때 인덱스 0을 읽어 발생하던 Lua 오류를 수정했습니다. 빈 로그는 이제 안내 문구만 복사합니다.
- 버전 `0.1.3`에서는 Forever 클라이언트의 `print()` 출력이 `CHAT_MSG_SYSTEM`을 거치지 않고 기본 채팅 프레임의 `AddMessage`로 바로 전달되는 경우를 관찰하도록 보완했습니다. 또한 EditBox에 없는 높이 측정 메서드를 호출하던 복사창 오류를 수정했습니다.
- 버전 `0.1.4`에서는 Position Diagnostics 탭을 추가했습니다. 위치·지도·인스턴스·방향·속도 API의 존재 여부와 안전 호출 결과를 보고하고, 사용자가 수동으로 시작·중지하는 1초 샘플링 및 전체 보고서 복사를 제공합니다. KHQOL의 절제된 어두운 표면·회색 경계·청록 포커스 색상 원칙을 독립 UI에 적용했습니다.
- 버전 `0.1.5`에서는 위치 API가 반환한 `nil` 값과 실제로 반환값이 없는 경우를 구분해 보고하도록 수정했습니다. 이 변경은 실제 Forever 결과의 해석 정확도를 높이기 위한 진단 개선입니다.

## 실제 게임에서 검증하지 않음

이 환경에는 WoW Forever 클라이언트가 없으므로 아래 항목은 **PASS가 아니며**, 인게임 확인이 필요합니다.

1. `/run print("TEST", 123)`가 Forever 클라이언트에서 `CHAT_MSG_SYSTEM` 이벤트로 전달되는지
2. `GetMouseFoci()` 또는 `GetMouseFocus()`가 기대한 마우스 아래 프레임을 반환하고, 보호된 값이 안전하게 처리되는지
3. Ctrl+Shift+C를 지정했을 때 DevTools 이외 프레임 위에서 단축키가 실행되며 클라이언트 바인딩과 충돌하지 않는지
4. 복사창의 전체 선택·Ctrl+C·Esc, Frame Stack 로드, `/reload`, 전투 제한, 다른 애드온과의 동시 실행

## API 제한 사항

WoW의 시스템 채팅 이벤트와 채팅 프레임의 메시지 전달은 출력한 Lua 호출의 출처를 안정적으로 식별하지 못합니다. 따라서 Console은 기록을 `/run` 결과라고 단정하지 않고 **Chat Output**으로 표시합니다. v0.1.3은 `CHAT_MSG_SYSTEM`과 기본 채팅 프레임을 모두 수동 관찰하며, 우회 수단으로 `print`를 교체하지 않습니다.

## KHQOL 1.11.5.2 코드 재사용 내역

`KHQOL_Labs/Modules/FrameInspector.lua`의 설계 일부를 재사용했습니다. 구체적으로 안전한 프레임 메서드 호출, `GetMouseFoci` 우선·`GetMouseFocus` 대체 조회, 0.25초 샘플링, 앵커/부모 체인 설명, 복사창의 포커스 및 전체 선택 흐름입니다. 구현은 하나의 독립 Lua 파일로 새로 작성했으며 KHQOL UI, LabLock, SavedVariables 및 모듈 의존성은 의도적으로 포함하지 않았습니다. 원본 KHQOL 패키지의 파일은 수정하지 않았습니다.
