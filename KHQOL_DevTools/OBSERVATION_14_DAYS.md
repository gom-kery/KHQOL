# 약 14일 수집 안내

이 작업은 수집 가능한 구현과 확인 절차를 제공합니다. 14일의 실제 플레이 자료는 사용자의 플레이로 쌓이며 이번 결과물에는 실제 플레이 데이터를 넣지 않았습니다.

## 시작일

1. 게임 종료 후 Full 1.11.8.14/DevTools 0.3.0 설치·활성화를 확인합니다. 기존 SavedVariables와 내보내기를 별도 보관하고 자동 초기화하지 않습니다.
2. **먼저 기록 OFF 마법책·접속 종료 재현 확인**을 수행합니다. 차단 또는 실제 창 기능 이상이 남으면 관찰 배포를 보류하고 진단 결과를 남깁니다.
3. `/khqoldev usage`에서 ON을 누릅니다. 현재 버전·연결·NOT TESTED·LIMITED 의미를 확인합니다.
4. 일반→경험치→시전→경험치 이동, 체크 한 번, 슬라이더 한 번, 색상 확정/취소, 위치 무변경/변경 저장을 확인합니다. 전후 고정 ID 기준값을 비교합니다.
5. 7일/30일 JSON을 복사해 로컬 파일에 보관합니다. 정상 /reload 후 같은 카운터가 복원되는지 확인합니다. 미접속 시간이 체류로 더해지면 중단하고 보고합니다.

## 1~6일

평소처럼 플레이하고 필요할 때 설정합니다. 통계 창을 계속 열어 둘 필요가 없습니다. OFF 구간은 수집하지 않으며 캐릭터별 분리는 없습니다. 같은 날짜의 여러 캐릭터는 계정 합계입니다. 매일 완전 관찰했다고 가정하지 않습니다.

테스트 행동은 실제 통계에 포함됩니다. 초기 검증 자료를 유지하며 해석하거나, 사용자가 원할 때만 JSON·SavedVariables 백업 후 통계 초기화를 직접 실행하고 그 시점을 메모하세요. 테스트 자료를 몰래 빼거나 설치 시 삭제하지 않습니다.

## 약 7일

최근 7일·30일 JSON을 각각 저장합니다. enabled·관찰 날짜·recordingSeconds·observedRoutes·observedVersions·diagnostics를 확인합니다. 미계측(관찰 0일)을 사용 0회로 보고하지 않습니다. 새 연결 날짜 이전의 수치는 비교 범위에서 구분합니다. 일별 UTC 자정은 한국 오전9시입니다.

## 8~13일 / 종료 약 14일

평소 플레이를 이어갑니다. 중간 업데이트가 있으면 버전 쌍과 지표 정의를 구분합니다. 종료 시 7일·30일 JSON을 다시 저장합니다. 기록 OFF를 누르면 현재 구간을 정산하고 기존 통계는 보존합니다. 마지막 정상 /reload 또는 로그아웃으로 디스크에 저장합니다.

## 해석·공유

30일은 14일 관찰 전체를 포함하기 위한 창이며 접속일·ON 관찰 시간과 함께 해석합니다. 기능 실행 지표는 카탈로그 의미대로 요청/초안/처리 증거를 구분하고 서로 다른 단계를 합산하지 않습니다. 지속 기능은 날짜 수이고 사용자/캐릭터 수가 아닙니다. 평균 메뉴 체류는 날짜별 유효 방문 표본 기준입니다.

Usage JSON에는 개인 식별자·본문·좌표가 없습니다. Console/Frames/Position 보고서는 별도 원본 정보를 포함할 수 있으므로 통계와 섞어서 공유하지 않습니다. 자동 전송은 없습니다. 비정상 종료 직전 메모리 통계와 30일을 넘긴 자료의 보존은 보장하지 않습니다.
