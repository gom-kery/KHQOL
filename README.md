# KHQOL 1.11.4.1

기준 1.11.4 · 결과 1.11.4.1 · 인터페이스 16001 · 2026-10-18.

아코디언을 접으면 큰 여백이 남고, 다른 메뉴를 다녀온 뒤 펼치면 옵션이 겹치던 문제를 수정했습니다. 하위 섹션의 높이가 바뀔 때 상위 행과 화면 배치도 함께 갱신합니다. 일반·프로필 화면의 스크롤 높이도 현재 접기 상태를 따르도록 수정했습니다.

전체 설정의 **[▼/▶] 섹션명**과 **두 열 배치**를 유지합니다. 화살표만 작은 버튼이며 제목은 일반 글자입니다. 목록·편집기·미리보기와 긴 항목은 전체 폭을 사용하고 좁은 창에서는 한 열로 전환합니다. 기존 설정·프로필·ON/OFF·색상·미니맵 저장값은 유지합니다.

## 설치

전체 설치 파일은 **`KHQOL-1.11.4.1-아코디언여백-겹침수정.zip`**입니다. 게임 종료 후 기존 KHQOL 및 KHQOL_* 코드 폴더를 AddOns 밖에 백업하고 ZIP의 19개 폴더를 넣습니다. 남은 KH_map도 밖으로 옮깁니다. **WTF와 SavedVariables는 그대로 둡니다.** [설치·확인 안내](INSTALL-GUIDE.md)를 참고하세요.

19개 애드온 폴더 / 271개 파일 / Lua 193개 / XML 5개 / 미디어 32개 / 고유 저장 변수 11개입니다. KH_map과 앞서 감사한 불필요 파일은 포함하지 않습니다.
