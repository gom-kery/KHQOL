# KHQOL 1.10.6 — 일반 편의·기본 UI 통합

기준 버전: 1.10.5.2. TOC·런타임 버전: 1.10.6.

- 일반 > 모듈 관리: 편의 기능의 ‘일반 편의’, 인터페이스의 ‘기본 UI’. 2열 구성 및 설정 이동 버튼.
- 편의 기능 > 일반: 기존 대화창·아이템 파괴·판매·수리·창 이동 유지. 새 전체 사용은 초대·채집·상점 확장·습득 표시만 관리.
- 인터페이스 > 기본 UI: 가방·메뉴바 기본/숨김/마우스 오버, 숨김 지연, 플레이어·대상 간결한 배치 및 개별 수치 표시.
- 기존 파티·길드 초대 거절 저장값 보존. 결투 거절, 유형별 알림, 파티 친구·길드 예외 추가.
- 채집 추적은 사망 시 저장 선택을 유지하고 부활 후 제한적으로 복원. 수동 선택 우선.
- 상점 확장: 네 열·다섯 행. native 상품 버튼·구매·툴팁·수량 구매 경로 유지. 상점 변경 충돌 시 적용 중지.
- 도안·탈것의 확인된 습득 결과만 가방·판매 슬롯에 체크 표시. 소지 개수를 습득 판정에 사용하지 않음.
- 옵션은 기존 계정 공용 프로필, 유지할 추적 상태는 기존 캐릭터 데이터 저장소 사용. SavedVariables 추가 없음.
- 새 묶음 기본 ON, 신규 기능 기본 OFF/기본 표시. 이전 개별 옵션은 유지.
- Lua 5.1 구문 87파일, 모의 동작 26그룹 통과. 실제 Forever 게임 실행·외형·보호 UI·서버 동작은 미검증.
- 설치: ZIP의 KHQOL 폴더로 교체. SavedVariables를 삭제하지 않아도 됨.

# KHQOL 1.10.5.1 — 보호 UI 갱신 수정·성능 오버레이 추가 (monitor-fix)

기준·결과 버전 모두 1.10.5.1. 기존 콤보·변신 마나·스킬 등록 개선 포함.

- 마법책 버튼 클릭 뒤 UIParent 전체를 갱신하던 경로 제거. 등록된 KHQOL 설정 컨트롤만 갱신하며 보호된 창 제외.
- 실험실 > 성능 모니터. 기존 개발자 잠금 해제 후 상단 모듈 사용 ON. 기본 OFF.
- 설정창을 닫아도 CPU·메모리 오버레이 유지. 배경 드래그 이동, 우측 하단 ◢ 드래그 크기 조절.
- ESC로 닫기 기본 OFF. 켜면 ESC로 모듈 OFF 및 측정 종료. X도 모듈 OFF. 일반 설정창만 닫아도 모니터는 유지.
- 폭·높이·위치·ESC 설정·CPU 갱신 간격을 기존 프로필에 저장. /reload 후 ON 선택 복원. 로그는 저장하지 않음.
- CPU 최근/세션/보스 평균, 최대, 시간 초과 횟수, 메모리 MiB 및 전체 외부 애드온 대비 비율. 제공 불가 항목은 N/A.
- CPU 기본 1초(1~10초 설정), 메모리 최소 5초 간격. 꺼진 상태에서 타이머 없음. 모니터 자체 측정 비용 포함.
- 로그 복사: 최근 300개 측정값·클라이언트 빌드·활성 모듈을 Ctrl+A → Ctrl+C로 복사. 캐릭터명·노트·채팅·등록 주문 미포함.
- PC 전체 CPU/RAM 점유율과 다름. 구형 CPU API만 있는 환경은 scriptProfile 1 + /reload 필요. 전역 설정 자동 변경 없음.
- 정적·모의 70개 그룹 통과. 실제 Forever의 외형·ESC·CPU/메모리·taint 검증은 미실시.
- 설치 ZIP의 KHQOL 폴더로 교체. SavedVariables 삭제 불필요. 다른 애드온 설치 불필요.
