# KHQOL 1.11.6.0

**실험실 정리·공유 점선 설정·보수적 안정화** · 기준 1.11.5.11 · 2026-10-21.

## 1.11.6.0 변경과 점선 설정

- **실험실 → 프레임 검사기·성능 모니터**를 제거했습니다. 파일·탭·검색·메뉴/명령 별칭·위치 편집·실행 연결을 함께 정리했습니다. 버프 리마인더·발동 알림·오브젝트 강조와 기존 잠금은 유지합니다. 시계의 FPS·지연 정보는 별도 기능으로 유지합니다.
- **퀘스트 → 길 안내 → 표시 → 점선 표시**를 추가했습니다. **노트·저장 경로의 지도 점선 전체**를 켜고 끄며, **편의 기능 → 포에버 노트 → 핀 연결선 표시**와 같은 프로필 값을 사용합니다. OFF여도 지도 핀·핀 순번·화살표·안내 진행·저장된 경로는 유지합니다. KHQOL_Clock이 설치되지 않은 구성에서는 사용할 수 없도록 표시합니다.
- 관련 없는 게임 설정 변경에 따른 노트 지도 전체 갱신을 생략하고, 스톱워치는 표시되는 초가 달라질 때 문구를 갱신합니다. 선택 설치에서 앞선 버튼이 없을 때 뒤의 구형 미니맵 버튼 처리가 누락되던 문제를 수정했습니다.

기존 노트·경로·완료 상태·프로필·캐릭터 데이터·KHQOLMapDB를 유지합니다. 제거한 성능 모니터의 과거 저장 설정은 실행하지 않고 보관하며 강제로 지우지 않습니다. 새 SavedVariables, 새 저장 키, 데이터 마이그레이션은 없습니다.


## 경로 그리기 사용법

1. **/khqol → 편의 기능 → 포에버 노트**에서 노트와 세계지도 핀 표시를 켭니다.
2. **저장된 경로 → 새 경로 그리기**를 누릅니다. 새 경로를 선택하고 세계지도를 엽니다. 기존 경로에 추가하려면 경로를 선택한 뒤 **선택 경로 이어그리기**를 누릅니다.
3. 지도에서 지나갈 지점을 **Shift+우클릭**으로 차례로 찍습니다. 새 핀을 만들면서 선택 경로의 마지막에 바로 등록합니다. 기존에 보이는 핀은 **좌클릭 한 번**으로 추가합니다. 같은 핀을 다시 클릭하면 중복 등록하지 않습니다.
4. 지도 하단에 **경로 이름·등록 개수·그리기 완료·안내 시작**을 표시합니다. 세계지도와 미니맵의 선택 경로 핀에는 **1, 2, 3… 순번**을 표시합니다. 경로 이름은 설정에서 바꿀 수 있습니다.
5. **그리기 완료**는 등록 상태를 유지하며 일반 핀 조작으로 돌아갑니다. **안내 시작**은 그리기를 끝내고 **내 위치→첫 등록 핀→나머지 핀**을 순서대로 안내합니다.

예: 새 경로 그리기 → 지점을 1→2→3→4 순서로 Shift+우클릭 → 안내 시작. 매 핀의 우클릭 메뉴를 열 필요가 없습니다. 이미 핀 네 개가 있다면 첫 핀 우클릭→**새 경로 그리기**로 그 핀을 1번에 등록한 뒤 나머지 핀을 좌클릭하고 안내 시작을 누를 수도 있습니다.

기존 핀 메뉴의 **경로에 추가 (마지막)**, 경유지 순서 앞으로/뒤로·제외, 설정의 저장/삭제·처음부터/가까운 경유지 안내도 유지합니다. 메뉴의 경로 작업과 삭제 작업 구분선도 유지합니다. 경로 삭제·그리기 완료는 노트나 핀을 삭제하지 않습니다.

## 모드 전환과 저장

- **그리기 중:** 지도에 추가하는 새 핀과 클릭한 기존 핀을 선택 경로에 등록합니다. 선택 경로 전체를 미리 보여줍니다. 일반 노트의 현재 목적지·수동 목적지·퀘스트 감시 상태는 바꾸지 않습니다. 기존 순차 경로 안내 중에 그리기를 시작하면 해당 경로 안내를 중지하고 편집합니다.
- **완료 후:** 핀 좌클릭은 기존 일반 목적지 안내로 돌아갑니다. 일반 Shift+우클릭과 명령어/노트에서 만든 핀은 자동으로 경로에 추가하지 않습니다. 명령어/노트로 추가한 좌표는 그리기 중에도 자동 등록하지 않습니다.
- **지도 닫기:** 그리기 세션은 유지하되 표시줄은 숨깁니다. 다시 열면 이어 그릴 수 있습니다. 지도를 닫은 상태의 미니맵 좌클릭은 일반 안내입니다.
- **전투:** 새 핀/경로 등록과 안내 시작을 보류합니다. 그리기 완료는 사용할 수 있습니다. 전투 후 이어그릴 수 있습니다.
- **경로 선택·프로필 변경·선택 경로 삭제·노트/세계지도 핀 표시 OFF:** 그리기를 종료합니다. 이전 메뉴나 버튼으로 다른 경로에 추가하지 않습니다.
- **정상 리로드/재접속:** 등록된 경로와 순서는 유지하지만 그리기 모드·진행 안내를 자동 재시작하지 않습니다. 경로 데이터는 계정 공용이며 편집 즉시 메모리에 반영되고 게임이 정상 리로드/로그아웃 때 디스크에 저장합니다. WTF·SavedVariables를 유지하세요.

일반 ‘지도 Shift+우클릭으로 좌표 추가’가 OFF여도 **그리기 중에만** 해당 입력을 받습니다. 완료하면 원래 설정으로 돌아가며 설정값을 바꾸지 않습니다. 최대 **32개 경로 / 경로당 128개 핀**입니다. 가득 찬 경로에서는 새 지도 핀을 만들기 전에 거절합니다. 기존 핀 ID·원래 지역/좌표·노트·완료 체크·프로필·KHQOLMapDB를 유지합니다.

## 안내 중 표시

그리기를 끝내고 안내하면 **내 위치→현재 핀은 흰 점선**, **현재 핀→남은 경로는 설정한 색상 점선**입니다. 지나온 핀·구간과 현재 핀으로 들어오는 과거 구간을 숨겨 중복 선을 줄입니다. 예를 들어 1번 도착 후 우회 중에는 **내 위치→2→3→4**만 표시하며 저장된 전체 순서는 유지합니다. 이전 경유지·처음부터 재시작으로 다시 표시할 수 있습니다. 안내가 없으면 전체 기본 경로를 표시하며, 기존 도착한 핀 숨김/체크 상태는 유지합니다.

경로를 중간부터 안내하려면 해당 핀 우클릭→**여기로 안내 시작**을 사용합니다. 일반 핀 좌클릭은 순차 경로 시작과 별도입니다. 도착 반경은 기본 10야드, 설정 범위 3~50야드입니다. 일시 정지/재개·이전/다음·종료와 기존 목적지 복귀를 유지합니다.

지역·대륙·전체 지도 투영과 미니맵 표시를 유지합니다. 거리/좌표를 읽을 수 없는 지도·다른 world에서는 가짜 연결이나 도착을 만들지 않습니다. 연결선은 등록한 경유지 사이를 잇습니다. 도로 자동 탐색·장애물 회피는 구현하지 않았으며 기존 ROAD-NAVIGATION-RESEARCH.md는 조사/후속 설계 기록입니다.
