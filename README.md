# KHQOL 1.10.7.1

기준 1.10.7 · 2026-10-12

- 유닛 프레임의 secret 너비 전달 오류 수정. 기본 수치 모드에서 불필요한 글자 층/너비 측정 제거.
- 사용자 수치는 바의 좌우 앵커로 배치. 공개된 명시적 크기만 저장/복원, 확인 불가 시 보류.
- 플레이어·대상 각각 자원 바 ON/OFF, 체력 높이 8~100px, 자원 높이 4~100px 추가.
- 간격 0~20px. 0px은 바 사이 여백 없음. 높이/간격 조절은 간결한 프레임 사용 시 적용.
- 기존 총 높이 유지. 개별 높이를 조정하기 전에는 기존 높이 분할 그대로 사용. OFF한 자원 높이/표시 방식 보존.
- 인터페이스의 기본창 이동을 기본 UI 본문으로 병합. 가방·메뉴바와 이동 스위치/초기화/저장 범위는 독립 유지.
- 지역 자동 펼치기 + 자동 퀘스트 선택 ON이면 대기 후 현재 지역의 추적 퀘스트를 자동 안내.
- 자동 순서: 낮은 퀘스트 레벨 → 같은 레벨에서는 가까운 목표. 수동 선택·사용자 핀·노트 수동 안내·반납 안내 우선.
- 기존 SavedVariables·프로필·기본값·노트/등록 자료 유지. 새 옵션은 사용자가 변경할 때 해당 프로필에 저장.

설정: `/khqol` → 인터페이스 → 유닛 프레임 / 기본 UI. 퀘스트 자동 안내는 퀘스트에서 두 기존 옵션을 함께 켭니다.
유닛 프레임은 기존 실험실 실행 제한을 유지합니다. 전투/기본 프레임 정보 확인 불가 시 크기 변경은 안전하게 보류합니다.
설치 후 `/reload`. 정적·모의·회귀 검사 146개 그룹 통과. 실제 Forever 인게임 검증은 미실시입니다.

이하 내용은 이전 버전 기록입니다.

# KHQOL 1.10.7

기준 버전: 1.10.6.8. 단일 KHQOL 설치 구조와 기존 테마·설정·사용자 데이터를 유지합니다.

- 목적별 메뉴 8개, 세부 설정 24개. 시계·정보 표시/기본창 이동은 인터페이스, 위협 수치는 알림, 퀘스트는 독립 메뉴.
- 일반 화면의 기능별 바로가기와 현재 프로필 표시. 짧은 옵션 2열, 긴 등록·설명 전체 폭, 비활성 이유 안내.
- 위치 편집에 가로 경험치 바, 환경 타이머와 HUD 텍스트 추가. 선택 정보·위치 초기화·완료 후 크기·모양 설정 제공.
- 시계 도구·노트 등 직접 이동의 DB/프로필 저장 경로 통일. 설정창 이동 위치는 계정 공용으로 저장.
- 일반 입력은 Enter/포커스 종료로 확정, ESC/화면 종료로 미확정 내용 취소. 등록·주문 검증의 적용/저장 단계 유지.
- 버프의 확인 불가 상태를 없음과 구분. 보호된 정보에 대한 만료 오탐·오래된 시간 표시 방지.
- 지정한 알림의 겹침을 표시 중에만 완화. 기존 알림 사용 여부·소리·색상·반복 제한 유지.
- 기존 SavedVariables 이름과 신규 설치 기본값 유지. 데이터 통합·외부 라이브러리·추가 이미지 없음.

## 처음 설정하기

1. `/khqol` 또는 KHQOL 미니맵 버튼으로 설정 열기.
2. 일반에서 사용할 기능 확인. 오른쪽 화살표로 해당 설정 이동.
3. 위치 편집에서 드래그 → 완료 / 잠금. 취소 또는 ESC는 진입 전 상태 유지.
4. 해당 메뉴에서 폭·높이·글자(px), 배율·투명도(%) 조정.
5. 왼쪽 아래 프로필 버튼에서 사용 프로필 확인. 개인 조정은 현재 설정 복사 후 진행.

체크박스·슬라이더·선택 항목은 즉시 적용됩니다. SavedVariables 파일은 `/reload`·로그아웃 시 게임이 저장합니다. 전투 제한이 있는 기본 UI 변경은 기존 정책대로 전투 후 적용됩니다.

전체 초기화는 노트·등록 목록·프로필까지 삭제합니다. 위치 초기화와 모듈 설정 초기화는 별도 동작입니다.
