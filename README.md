# KHQOL 1.11.1.2 — 툴팁 ID 정보

인터페이스 → 툴팁 설정 → 표시 정보 아래에 **ID 정보**를 추가했습니다. **주문 ID / 아이템 ID / NPC ID**는 각각 기본 OFF이며 기존 ON/OFF 버튼으로 3열 배치합니다. 좁은 설정 창에서는 공통 반응형 배치를 따릅니다. 켠 종류의 ID만 툴팁 맨 아래에 빈 줄 하나를 두고 표시합니다. NPC는 공개된 Creature/Vehicle GUID에서 식별자를 읽으며 플레이어·Pet GUID와 보호된 값은 표시하지 않습니다.

공통 기반 1개와 기능 애드온 17개, 기존 파일·저장 변수·리소스를 유지합니다. 툴팁 모듈에 `Tooltip/IDInfo.lua` 하나를 추가해 전체 268개 파일이며, 테스트 도구는 설치 ZIP에 포함하지 않습니다. 모든 TOC와 내부 버전은 1.11.1.2입니다. 이름 +2pt, 전문화 번역, 대상 행과 기존 아이템 추가 정보 기능은 유지합니다.

전체 Lua 5.1 구문 검사와 ID 기본값·개별 토글·하단 여백/순서·중복 방지·보호 값·기존 이름/전문화·3열 설정 연결의 격리 모의 검사를 수행했습니다. 실제 WoW의 화면·입력·전투·성능과 다른 애드온 동시 실행은 인게임 확인이 필요합니다. 아래 과거 검증 문서와 docs의 결과는 그 버전의 기록으로 보존합니다.

`KHQOL_UnitFrames`는 대상 시전바가 유닛프레임의 오라 위치·장식 복원과 기본 UI 속성 복원을 직접 사용하므로 하나의 설치 단위로 유지합니다. 내부 사용 토글은 종전처럼 각각 독립입니다. 개인 프레임을 꺼도 파티 모듈을 자동으로 끄거나 켜지 않습니다.

시계와 노트는 `ForeverClockDB`와 실행 메서드를 함께 사용합니다. 무기 안내는 기존 툴팁 정보 제공자입니다. 각각 따로 쪼개지 않았습니다. PvP 묶음 안의 `Range.lua`는 PvP 자체 판정기로, `KHQOL_Range`가 필요하지 않습니다.

## 지원 조합과 빠진 모듈

- 공통 기반만, 공통 기반+위 표의 단일 기능 폴더, 임의 부분 설치, 전체 설치를 지원하도록 구현했습니다. 기반 없는 기능 실행은 TOC 필수 의존성으로 차단합니다.
- 파티만 사용하려면 `KHQOL`과 `KHQOL_PartyFrames` 두 폴더만 있으면 됩니다. 개인 프레임·시전바·사거리 폴더는 필수가 아닙니다. 사거리가 없으면 파티가 자체 휠 주문 등록창을 엽니다.
- 시계·노트만 사용해도 공용 길 안내 HUD를 사용할 수 있습니다. 퀘스트 모듈을 설치할 필요는 없습니다.
- 사거리↔파티 마법책, 자원/스윙바↔시전바 연결은 양쪽이 설치된 경우에만 동작합니다. 시전바는 자원바가 없으면 저장된 자유 위치로 표시합니다.
- **미설치·게임 목록 비활성 모듈의 설정·탭·검색·위치 대상은 숨깁니다.** 일반 페이지의 설치 상태에서 미설치/비활성/로드되지 않음을 구별합니다. 설치 조회 API가 없는 클라이언트는 상태 확인 불가로 표시합니다.
- 설치됐지만 모듈 OFF, 실험실 잠금, 게임 API 미지원, 전투 중 변경 보류는 해당 상태로 안내합니다. API 미지원 때문에 다른 모듈을 켜거나 기본 바인딩을 바꾸지 않습니다.
- 폴더 설치/활성 상태 변경은 게임의 UI 다시 로드 또는 재접속으로 반영합니다. 실행 도중 임의 핫로드는 지원하지 않습니다. 새 LoadOnDemand는 없습니다.

## 저장·프로필·재설치

**저장 파일의 로더는 계속 `KHQOL/KHQOL.toc` 하나입니다.** 계정 변수 7개와 캐릭터 변수 3개의 이름·범위·최종 쓰기 파일이 바뀌지 않습니다. 기능 애드온은 같은 변수를 중복 선언하지 않습니다. 폴더가 나뉘어도 기능별 WTF 파일로 복사하는 이관은 필요하지 않습니다.

프로필 생성·복사·전환·모듈 초기화는 미설치 모듈의 DB와 저장된 프로필 스냅샷을 보존합니다. 재설치하면 현재 선택한 프로필의 설정이 복원됩니다. 노트 본문·페이지·그룹·체크 상태·알람 문구, 버프/NPC/발동 목록, 캐릭터 기준 주문과 다른 캐릭터의 색상, 파티 휠 주문과 역할 프로필을 유지합니다.

프로필 문자열 내보내기는 종전과 같이 **지원되는 표시 설정만** 대상입니다. 미설치 기능과 알 수 없는 키는 호환성 검사에서 제외될 수 있고 내용 데이터도 포함하지 않습니다. 전체 데이터 복구용 백업은 기존 WTF 파일 사본입니다. 전체 데이터 초기화 버튼은 종전처럼 미설치 데이터를 포함해 모든 KHQOL 데이터를 지우므로 업그레이드 해결책으로 사용하지 않습니다.

## 비활성화·복귀

설치된 기능의 사용 토글을 먼저 끄고 복원이 끝난 뒤 게임 애드온 목록에서 끄거나 폴더를 별도 보관하세요. 파티 휠 임시 바인딩과 기본 프레임 복원은 기존 기능이 처리합니다.

실험실의 오브젝트 강조를 제거할 때는 가능하면 먼저 OFF하여 그래픽 복원을 확인합니다. 실험실 폴더를 바로 빼도 공통 기반이 기존 그래픽 복원 기록으로 복원을 시도합니다. 전투/다른 애드온 충돌/API 실패/알 수 없는 기록이면 원본 기록을 보존하고 보류합니다. 다른 곳에서 변경한 값은 덮어쓰지 않습니다. 시각 효과 해제에는 게임 재시작이 필요할 수 있습니다.

1.10.10으로 돌아가려면 게임 종료 후 이번 `KHQOL`과 `KHQOL_*` 17개를 AddOns 밖에 보관하고, 원본 1.10.10의 `KHQOL` 폴더를 복원합니다. 저장 이름과 파일 소유권을 유지했으므로 같은 저장 파일을 읽을 수 있습니다(모의 복귀 검사 통과). 예전 상태를 정확히 되돌리려면 업그레이드 전 저장 백업도 복원합니다. 백업 시점 이후의 수정은 그 백업에 없습니다.
