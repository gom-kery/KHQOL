# KHQOL 1.10.5.1 — 보호 UI 갱신 수정·성능 오버레이 추가 (monitor-fix)

기준·결과 버전 모두 1.10.5.1. 기존 콤보·변신 마나·스킬 등록 개선 포함.

- 마법책 버튼 클릭 뒤 UIParent 전체를 갱신하던 경로 제거. 등록된 KHQOL 설정 컨트롤만 갱신하며 보호된 창 제외.
- 실험실 > 성능 모니터. 기존 개발자 잠금 해제 후 상단 모듈 사용 ON. 기본 OFF.
- 설정창을 닫아도 CPU·메모리 오버레이 유지. 배경 드래그 이동, 우측 하단 ◢ 드래그 크기 조절.
- ESC로 닫기 기본 OFF. 켜면 ESC로 모듈 OFF 및 측정 종료. X도 모듈 OFF. 일반 설정창만 닫아도 모니터는 유지.
- 폭·높이·위치·ESC 설정·CPU 갱신 간격을 기존 프로필에 저장. /reload 후 ON 선택 복원. 로그는 저장하지 않음.
- CPU 최근/세션/보스 평균, 최대, 시간 초과 횟수, 메모리 MiB 및 전체 외부 애드온 대비 비율. 제공 불가 항목은 N/A.
- CPU 기본 1초(1~10초 설정), 메모리 최소 5초 간격. 꺼진 상태에서 타이머 없음. 모니터 자체 측정 비용 포함.
- 로그 복사: 최근 300개 측정값·클라이언트 빌드·활성 모듈을 Ctrl+A → Ctrl+C로 복사. 캐릭터명·노트·채팅·등록 주문 미포함.
- PC 전체 CPU/RAM 점유율과 다름. 구형 CPU API만 있는 환경은 scriptProfile 1 + /reload 필요. 전역 설정 자동 변경 없음.
- 정적·모의 70개 그룹 통과. 실제 Forever의 외형·ESC·CPU/메모리·taint 검증은 미실시.

# KHQOL 1.10.5.1 — 콤보·변신 마나·스킬 등록 개선

기준 1.10.5.0 → 결과 1.10.5.1 (2026-10-11).

- 비전투 무대상에서 빈 콤보 슬롯 표시. 드루이드는 표범 상태만. 최대값 불명·전투 중 읽기 제한에서는 숨김.
- 마지막 포인트 활성 색상 설정. 실제 최대 5/6 등에 따라 마지막 슬롯에 적용. 신규 색 초기값은 기존 활성 색 복사.
- 콤보는 도적/드루이드, 영혼의 조각은 흑마법사, 탄약은 도적/전사/사냥꾼만 설정 가능. 다른 직업에서 OFF·비활성 표시하며 저장값 보존.
- 바 설정 > 자원/스윙 > 드루이드 변신 마나 > 변신 중 마나바 표시. 기본 OFF. 기력/분노와 함께 아래쪽에 파란 보조 마나바 표시. 읽기 제한 때 숨김.
- 마법책 검색창 오른쪽 끝 아래에 KHQOL / 사거리 설정 2줄 버튼. 패널은 책 오른쪽 바깥에 유지.
- 목록 선택 또는 스킬명/SpellID 조회 후 등록. 마법책의 스킬을 근거리/원거리 등록 버튼으로 끌어 놓아도 등록. 전투 중 드래그 등록 차단. 실패 시 기존 등록·커서 보존.
- 58개 정적·모의 검사 그룹 PASS. 실제 Forever 인게임 검증 미실시. 설치 후 배치·드래그·전투 마나 확인 필요.

# KHQOL 1.10.5.0 — 자원/스윙바·사거리 측정 확장

기준: 사용자 지정 1.10.4.1 → 결과: 1.10.5.0 (2026-10-10).

- 바 설정 > 자원/스윙: 도적·표범 드루이드 콤보 분할 바/원형 구슬, 위/아래/자유 배치, 크기·간격·색상·잠금.
- 자유 배치 콤보는 통합 위치 편집 지원. 자원바 연결 배치는 자원바와 함께 이동.
- 탄약 사용 상태·실제 장착 무기를 확인해 지원 직업의 아이콘과 전체 소지량 표시. 기존 독립 탄약 좌표 유지.
- 흑마 영혼의 조각 아이템 수량·아이콘: 클라이언트에서 후보 ID 6265의 실제 아이템명을 확인한 경우에만 표시.
- 인터페이스 > 사거리 측정: 근거리·원거리 판정 주문 각 1개. 스킬북 옆 KHQOL 패널의 자체 목록/ID 입력으로 등록.
- 기존 사냥꾼 데드존·참조 주문·설정·HUD·노트·프로필 보존. 등록 주문은 캐릭터별 보존.
- 투척 소비 규칙 미확정으로 투척 수량은 표시하지 않음. 비전 작렬은 조사만 수행, UI 없음.
- 정적·모의 40개 검사 그룹 통과. 실제 Forever 인게임 검증 미실시. 특수 가방 합산·조각 ID·전투/PvP·스킬북 실제 외형/API/taint는 확인 필요.
