## 주요 업데이트 — 1.11.4.7~1.11.4.13

| 버전 | 주요 변경 |
|---|---|
| **1.11.4.13** | 전투 종료 시 중복 재적용과 반복 설정 검사 축소. 잡템 판매에 **기본 UI 일괄 판매 우선 적용**, 미지원 환경에서는 기존 방식 유지. |
| **1.11.4.12** | 체력·자원 수치 정렬 변경 즉시 반영. X/Y를 정렬 기준 **−50~+50**으로 제한하고 보호 디버프의 제외 불가 안내 개선. |
| **1.11.4.11** | 설정 아코디언 접기·펼치기 후 표시와 스크롤 갱신 개선. 파티·공격대 탭 진입 오류 수정. |
| **1.11.4.10** | 플레이어의 **직업 보조 표시**에 토템·탄약·영혼의 조각 설정 통합. 체력·자원 수치 정렬과 좌표 설정, 파티·공격대 디버프 주문 ID 제외 기능 추가. 잡템 판매 진행 개선. |
| **1.11.4.9** | 위치 편집 격자 표시·간격 조절 추가. X/Y를 화면 중앙 `(0, 0)` 기준으로 변경하고 조작 창을 90% 크기로 축소. |
| **1.11.4.8** | 편집 테두리를 실제 체력·자원 바 크기에 맞추고, 드래그 중 이동 미리보기와 없는 유닛의 임시 프레임 추가. 드루이드 변신 마나 설정 위치 정리. |
| **1.11.4.7** | 영혼의 조각 문구 표시, 최대 보관 수량, 초과 조각 클릭 파괴 추가. 간결한 유닛 프레임 5종의 전용 위치 편집 지원. |
- 영혼의 조각 파괴는 **보조 표시 위치 잠금 ON·비전투 상태**에서 클릭당 초과분 1개만 처리합니다.
- 게임이 보호하는 디버프는 주문 ID를 등록해도 제외되지 않습니다.
