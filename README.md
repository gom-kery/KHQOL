# KHQOL 1.11.2 — 미니맵 통합·파티 프로필 계정 공유

KH_map을 선택 설치할 수 있는 KHQOL 모듈로 통합했습니다. 왼쪽 메뉴의 **미니맵**은 **인터페이스 바로 아래**에 있습니다. 기존 **미니맵 / 버튼 정리** 두 탭과 설정 항목·기능을 유지하고, 글꼴·색·버튼·입력·반응형 배치는 KHQOL의 기존 Design System v2.0 공통 컨트롤을 사용합니다.

**파티·공격대 → 프로필의 목록과 표시·배치는 계정 공용입니다.** 한 프로필의 파티·10·20·40인 설정을 다른 캐릭터에서도 선택하고 편집할 수 있습니다. 사용할 프로필, 역할 자동 선택, 휠 주문은 캐릭터별로 유지합니다. 같은 공용 프로필의 수정·초기화·삭제는 그 프로필을 사용하는 다른 캐릭터에도 반영됩니다.

업데이트 후 기존 설정이 있는 **A 캐릭터에 먼저 접속하고 정상 로그아웃한 뒤 B 캐릭터에 접속**하세요. 각 캐릭터의 기존 프로필은 그 캐릭터가 처음 접속할 때 공용 목록에 합칩니다. 같은 이름·같은 설정은 하나로 합치고, 이름이 같지만 설정이 다르면 캐릭터명이 붙은 별도 이름으로 보존합니다. 이미 합친 옛 데이터 때문에 삭제한 공용 프로필이 다시 생기지 않도록 이전 여부를 기록합니다. 옛 캐릭터별 프로필 원본도 복귀용으로 남깁니다.

공통 기반 1개와 선택 기능 18개, **19개 설치 폴더 / 281개 파일 / Lua 192개**입니다. 이번 패키지는 원래 KHQOL 268개 파일과 KH_map 13개 파일의 경로를 그대로 사용합니다. 테스트 도구는 ZIP에 넣지 않습니다. 19개 TOC와 두 내부 표시 버전은 모두 1.11.2입니다.

자동·모의 검사 **312/312 통과**입니다. 실제 게임의 화면·입력·전투·보호/taint·디스크 저장은 별도 확인이 필요합니다. 검사 범위는 [변경·검증 보고서](CHANGE-VALIDATION-REPORT.md)에 있습니다.

`KHQOL_UnitFrames`는 대상 시전바가 유닛프레임의 오라 위치·장식 복원과 기본 UI 속성 복원을 직접 사용하므로 하나의 설치 단위로 유지합니다. 내부 사용 토글은 종전처럼 각각 독립입니다. 개인 프레임을 꺼도 파티 모듈을 자동으로 끄거나 켜지 않습니다.

시계와 노트는 `ForeverClockDB`와 실행 메서드를 함께 사용합니다. 무기 안내는 기존 툴팁 정보 제공자입니다. 각각 따로 쪼개지 않았습니다. PvP 묶음 안의 `Range.lua`는 PvP 자체 판정기로, `KHQOL_Range`가 필요하지 않습니다.

## 지원 조합과 빠진 모듈

- 공통 기반만, 공통 기반+위 표의 단일 기능 폴더, 임의 부분 설치, 전체 설치를 지원하도록 구현했습니다. 기반 없는 기능 실행은 TOC 필수 의존성으로 차단합니다.
- 파티만 사용하려면 `KHQOL`과 `KHQOL_PartyFrames` 두 폴더만 있으면 됩니다. 개인 프레임·시전바·사거리 폴더는 필수가 아닙니다. 사거리가 없으면 파티가 자체 휠 주문 등록창을 엽니다.
- 시계·노트만 사용해도 공용 길 안내 HUD를 사용할 수 있습니다. 퀘스트 모듈을 설치할 필요는 없습니다.
- 사거리↔파티 마법책, 자원/스윙바↔시전바 연결은 양쪽이 설치된 경우에만 동작합니다. 시전바는 자원바가 없으면 저장된 자유 위치로 표시합니다.
- **미설치·게임 목록 비활성 모듈의 설정·탭·검색·위치 대상은 숨깁니다.** 일반 페이지의 설치 상태에서 미설치/비활성/로드되지 않음을 구별합니다. 설치 조회 API가 없는 클라이언트는 상태 확인 불가로 표시합니다.
- 설치됐지만 모듈 OFF, 실험실 잠금, 게임 API 미지원, 전투 중 변경 보류는 해당 상태로 안내합니다. API 미지원 때문에 다른 모듈을 켜거나 기본 바인딩을 바꾸지 않습니다.
- 폴더 설치/활성 상태 변경은 게임의 UI 다시 로드 또는 재접속으로 반영합니다. 실행 도중 임의 핫로드는 지원하지 않습니다. 새 LoadOnDemand는 없습니다.

## 저장·프로필·재설치

기존 KHQOL의 계정 변수 7개와 캐릭터 변수 3개는 계속 `KHQOL/KHQOL.toc`만 선언합니다. 추가된 `KH_map/KH_map.toc`은 종전의 계정 변수 `KHminimapDB` 하나만 선언합니다. 중복 선언이나 WTF 파일 이름 변경은 없습니다. 공용 파티 프레임 프로필은 계정 `KHQOLDB.globalData.partyFrameProfiles`에 저장하며 캐릭터 `KHQOLPartyCharDB`에는 선택·역할 연결·휠 주문과 이전 원본을 보관합니다.

프로필 생성·복사·전환·모듈 초기화는 미설치 모듈의 DB와 저장된 프로필 스냅샷을 보존합니다. 재설치하면 현재 선택한 프로필의 설정이 복원됩니다. 노트 본문·페이지·그룹·체크 상태·알람 문구, 버프/NPC/발동 목록, 캐릭터 기준 주문과 다른 캐릭터의 색상, 파티 휠 주문과 역할 프로필을 유지합니다.

프로필 문자열 내보내기는 종전과 같이 **지원되는 표시 설정만** 대상입니다. 미설치 기능과 알 수 없는 키는 호환성 검사에서 제외될 수 있고 내용 데이터도 포함하지 않습니다. 전체 데이터 복구용 백업은 기존 WTF 파일 사본입니다. 전체 데이터 초기화는 공용 파티 프로필을 포함한 KHQOL 데이터를 지우며, KH_map이 로드되어 있으면 미니맵 데이터도 지웁니다. 업그레이드 해결책으로 사용하지 않습니다. 미니맵 세부 설정과 공용 파티 프로필은 전체 프로필 문자열의 내보내기·가져오기 대상이 아닙니다.
