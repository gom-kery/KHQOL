# KHQOL 1.10.4.1 — 버프 리마인더 메뉴 이동

기준 1.10.4.0 → 결과 1.10.4.1 (2026-10-10).

- 설정 경로: 알림 > 버프 → 실험실 > 버프 리마인더.
- 실험실 잠금 해제 후 버프 설정·사용 토글·모듈 초기화 가능.
- `/kh buff`, 버프 전용 명령과 미니맵 진입은 새 메뉴로 연결.
- 기존 알림 실행·ON/OFF·위치·색상·직업별 등록 버프와 프로필 보존.
- 실험실 잠금으로 기존 실행 중인 버프 알림을 정지하지 않음. 메뉴 이동만 적용.
- 신규 저장 키·기본값 변경·설정 초기화·데이터 마이그레이션 없음.
- 실제 Forever 인게임 검증은 미실시. 설치 후 설정 표시·직접 진입·재오픈·재잠금 확인 필요.

# KHQOL 1.10.4.0 — 검증용 최종 후보

첨부 배포본 1.10.3.3의 기능·설정 화면·기본값·저장 구조를 유지하는 최종 안정화 작업입니다. 새로운 기능이나 메뉴는 추가하지 않았습니다.

- 설치: 전체 ZIP의 `KHQOL` 폴더를 `Interface/AddOns/KHQOL`에 배치합니다. 기존 사용자 SavedVariables는 그대로 사용하며, 초기화나 별도 데이터 이전은 필요하지 않습니다.
- 모듈·프로필의 같은 목적 목록과 API 호출 보호를 정리하고, 퀘스트 추적 목록 표시와 안내 후보 판단을 분리했습니다.
- 모닥불 Aura 인자·필드 읽기 보호·첫 혜택 감지·종료 콜백과 초기화 중복을 보강했습니다. 불확실한 Aura는 없음으로 확정하지 않습니다.
- 469개 정적·모의·회귀 검사 그룹 통과. 실제 Forever 실행 검증은 **미실시**입니다. 지도·기본 편집 모드·실제 Aura 제한·판매/수리 등은 인게임 확인이 필요합니다.
- `WeaponGuide/`는 메인 TOC에서 실행하지 않는 보존용 구형 코드입니다. 현재 통합 무기 안내는 Tooltip 제공자가 담당합니다.
