# KHQOL 1.10.9.6

2026-10-15 · **1.10.9.5 기준 1.10.9.6 전체 설치본**입니다. 파티·공격대 세 탭, 공통 직업색, 프로필 창 표시 순서와 미리보기·위치 편집 화면을 개선했습니다.

WoW Forever용 통합 편의 애드온입니다. 기본 UI 꾸미기, 유닛 프레임, 시전·자원 바, 알림, 퀘스트 목록·길 안내와 노트를 한 설정창에서 관리합니다.

기준 설치본: **1.10.9.5** (공통 기반 1.10.9.0-fix) · 수정본 정리: **2026-10-15** · 대상 인터페이스: **16001** · **전체 설치본**.

이 README는 **현재 버전의 사용 안내**입니다. 최초 보관본 1.1.0부터의 변경 기록과 수정본은 [CHANGELOG.md](CHANGELOG.md), 향후 작업은 [ROADMAP.md](ROADMAP.md)에 정리했습니다.

## 설치·업데이트

1. 게임을 종료한 뒤 ZIP 안의 `KHQOL` 폴더로 기존 애드온 폴더를 교체합니다.
2. 최종 경로가 `Interface/AddOns/KHQOL/KHQOL.toc`인지 확인합니다. `KHQOL/KHQOL`처럼 폴더가 한 단계 더 들어가면 인식되지 않습니다.
3. 캐릭터 선택 화면에서 KHQOL을 켜고 접속합니다. 게임이 실행 중이었다면 `/reload` 또는 재접속합니다.
4. `/khqol`, `/kh` 또는 KHQOL 미니맵 버튼으로 설정창을 엽니다.

기존 SavedVariables·프로필·노트·등록 목록은 유지합니다. **업데이트를 위해 SavedVariables를 삭제하거나 전체 초기화할 필요가 없습니다.** 별도 외부 애드온 설치는 필요하지 않습니다. 기본 게임 프레임/API가 없는 기능은 해당 설정에서 보류 안내를 표시합니다.

## 프로필 백업 및 복원

설정창 **프로필 → 프로필 백업 및 복원**에서 사용합니다. 내보내기·가져오기 창은 KHQOL 설정창 위에 표시되어 창을 옮기지 않고 복사·붙여넣기를 할 수 있습니다. 기존 생성·복사·선택·삭제와 문자열 포맷은 유지합니다.

1. 백업할 **활성 프로필**을 선택합니다. 편집 중인 입력은 먼저 확정합니다.
2. **프로필 내보내기 → 전체 선택 → Ctrl+C**로 문자열을 복사하고 별도 문서에 보관합니다. 운영체제 클립보드에 자동 저장하지 않습니다.
3. 다른 설치에서 **프로필 가져오기**를 열어 문자열 전체를 붙여 넣고 **검사**를 누릅니다.
4. 원본 이름·버전과 **정상 / 부분 호환 / 가져오기 불가** 결과를 확인합니다. 제외·환경 차이 상세는 가져오기 버튼에 마우스를 올려 확인합니다.
5. **새 프로필로 가져오기**를 누르면 `원본명 (가져옴)`으로 추가합니다. 중복 이름에는 번호를 붙이고 한글 포함 24자 이내로 맞춥니다. 기존 프로필을 덮어쓰거나 현재 선택을 자동으로 바꾸지 않습니다.
6. 사용하려면 **활성 프로필**에서 직접 선택합니다. 파일 저장은 게임의 `/reload`·로그아웃 시 이루어집니다.

포함: 기존 프로필 소유 모듈 ON/OFF·일반 옵션, HUD 위치·크기·색상·잠금, 바·툴팁·사거리 표시·알림 설정, 노트 외형·길 안내 옵션, 기존 프로필 정책의 자원/커서 사용자 색상입니다. 기본값 밖에 처음 편집 시 생기는 도구 창·환경 HUD 글자·완료 알림 위치도 포함합니다.

제외: 노트 본문·체크리스트·완료/진행 상태, 알람 문구, 공용 버프/NPC/발동 등록 목록, 캐릭터 사거리 기준 주문, 파티·공격대 독립 역할 프로필·휠 주문, 계정 공용 창 위치/편집 선호, 실험실 잠금·그래픽 복원 기록과 캐릭터 연결 정보입니다. **해당 데이터는 1.10.9.4부터 전체 프로필 밖에서 관리하므로 이번 백업에 포함하지 않으며 가져오기에서도 변경하지 않습니다.** 기존 SpellID를 포함하는 독립 목록은 따로 백업해야 합니다. 이 기능은 SavedVariables 전체 백업을 대체하지 않습니다.

서로 다른 애드온/게임 빌드는 부분 호환으로 안내합니다. 인식하지 못하거나 타입·기본 안전 범위가 맞지 않는 설정은 제외하고, 누락된 설정은 현재 기본값을 사용합니다. `정상 설정`은 통과한 실제 값의 수, `제외`는 제외된 값의 수, `확인 필요`는 애드온/게임 환경 비교 경고 수입니다. API·SpellID의 게임 내 유효성을 검증했다는 뜻은 아닙니다. 정식 클라이언트가 공개되기 전에는 베타 → 정식 완전 복원을 보장할 수 없습니다.

전투 중·통합 위치 편집 중에는 실행하지 않습니다. 문자열을 수정하거나 프로필 상태가 바뀌면 다시 검사해야 합니다. 포맷이 더 최신이거나 손상된 문자열은 저장 전에 거절합니다. 다른 사람의 설정은 사용 기능과 위치를 확인한 뒤 선택하세요.

문자열은 `KHQOL1:<Adler-32>:<Base64>` 형식입니다. 애드온 버전과 별개로 포맷/설정 범위 버전을 관리합니다. 안전한 데이터 전용 파서를 사용하며 Lua 코드를 실행하지 않습니다. 압축 라이브러리가 없어 외부 의존성 없이 직렬화·Base64를 사용합니다. 원문 최대 256 KiB, 입력 문자열 350,000자, 개별 문자열 8 KiB, 중첩 20단계/30,000노드 제한입니다. 무결성 검사는 손상 탐지용이며 암호화·서명은 아닙니다.

Lua 5.1 문법·모의 검증은 수행했으며, 실제 게임에서 긴 문자열 복사·붙여넣기와 화면 배치·저장/재접속은 추가 확인이 필요합니다.

## 파티·공격대 모듈

1.10.9.6에는 **공통 / 파티·공격대 / 프로필** 세 탭을 제공합니다. 실제 Forever의 시전·전투·입력·렌더링 확인 전 검증용이며 3단계 시작 기준은 아직 보류입니다.

| 탭 | 설정 항목 |
|---|---|
| 공통 | 공통 표시, 체력·자원 바, 닉네임 위치, 체력 텍스트 위치, 대상 징표, 역할 마크, 디버프 위치 |
| 파티·공격대 | 크기·위치·배치와 미리보기. 파티/10인/20인/40인을 선택해 조절합니다. |
| 프로필 | 클릭 시전·휠 주문과 역할 프로필 생성·복사·선택·삭제·자동 선택 |

### 빠른 사용법

1. `/kh party` 또는 `/kh raid`를 입력하거나, 설정창 왼쪽 **파티·공격대**으로 들어갑니다. 개인 유닛프레임 메뉴와 분리했습니다.
2. 상단 **모듈 사용**을 켭니다. 기본값은 OFF이며 개인 유닛프레임·기본 UI·실험실 스위치와 별도로 동작합니다.
3. **프로필** 탭의 **사용할 프레임 프로필**에서 기본·탱커·딜러·힐러 등을 선택합니다. 새 이름으로 현재 설정을 복사하거나 기본값으로 만들 수 있습니다.
4. **파티·공격대** 탭의 **편집할 프레임**에서 파티 / 10인 / 20인 / 40인을 선택하고 **미리보기**를 누릅니다. 설정창을 열어 둔 채 크기·간격·프레임 정렬을 조절합니다. 미리보기 프레임을 끌면 위치가 즉시 저장됩니다.
5. **미리보기 종료** 또는 ESC로 종료합니다. 이미 변경한 설정·드래그 위치는 유지합니다. 전투가 시작되면 미리보기만 종료하며 실제 표시를 유지합니다. 샘플의 이름·체력·사망·자리 비움·디버프는 배치 확인용 예시입니다.
6. **프로필** 탭에서 휠 사용과 클릭 시전을 설정합니다. 휠 주문은 **마법책 → KHQOL 설정 → 휠 클릭 시전**에서 등록칸으로 스킬을 끌어 놓고 **프레임 안 휠 시전 사용**을 켭니다. 휠 업·다운을 따로 등록하며 **해제**는 해당 방향만 지웁니다.

미리보기 도구창도 끌어 옮길 수 있습니다. 모듈 OFF에서도 미리보기를 열 수 있으며 실제 프레임을 자동으로 켜지는 않습니다. 통합 위치 편집은 기존 전체 화면 요소를 함께 이동하는 용도로 유지합니다. 전용 미리보기의 드래그는 즉시 저장이고, 통합 편집은 완료/취소 방식입니다.

### 표시와 인원수별 배치

1인 플레이어부터 최대 40인 공격대까지 지원합니다. 솔로 표시 옵션을 켜면 실제 플레이어 한 명을, 파티 2~5인은 플레이어를 포함한 총인원을 표시합니다. 공격대는 게임의 8개 하위 그룹을 따릅니다.

| 실제 상태 | 적용할 배치 |
|---|---|
| 솔로·일반 파티 2~5인 | 파티 |
| 공격대 6~10인 | 10인 공격대 |
| 공격대 11~20인 | 20인 공격대 |
| 공격대 21~40인 | 40인 공격대 |
| 공격대로 전환한 5인 이하 | 10인 공격대 |

각 배치에 폭·높이·인원 간격·프레임 정렬·X/Y를 별도로 저장합니다. 공격대는 한 줄의 하위 그룹 수와 파티 사이 가로·세로 간격도 따로 설정합니다. 인원이 경계를 넘으면 자동 적용하며, 전투 중 보호된 크기·위치 변경은 종료 후 마지막 인원수에 맞춰 적용합니다. 그동안 게임의 보안 그룹 헤더가 실제 인원 변경을 계속 표시하고 체력·자원을 갱신합니다. 인원이 있는 하위 그룹만 모아 배치하고 실제 파티 번호는 유지합니다. 같은 인원이라도 여러 하위 그룹에 흩어져 있으면 그만큼의 그룹 영역을 사용합니다.

### 기준점·오른쪽 배치

**기준점**에서 화면의 모서리·가운데 등 9개 위치를 선택합니다. **X 좌표**는 오른쪽으로 +, **Y 좌표**는 위로 +이며, 선택한 기준점으로부터의 거리입니다. 기준점을 바꾸면 X·Y를 0으로 맞춥니다. 이미 저장된 왼쪽 위 좌표는 업데이트 시 그대로 유지합니다.

10인/20인 공격대를 화면 오른쪽에 붙이려면 다음처럼 설정하세요.

1. **편집할 프레임**에서 10인 또는 20인을 선택합니다.
2. **기준점 → 오른쪽 위**, **1파티 정렬 기준 → 오른쪽**, **X 좌표 → 0**으로 설정합니다. Y는 원하는 높이로 조절합니다.
3. **한 줄의 하위 그룹 수**를 10인은 최대 2, 20인은 최대 4로 설정합니다. 40인은 최대 8입니다.
4. **미리보기**에서 확인하고 끌어서 미세 조절합니다. 이동 후에도 선택한 기준점을 유지합니다.

왼쪽 정렬은 `1 2 3 →`, 오른쪽 정렬은 `← 3 2 1` 순서입니다. 가로 프레임 정렬에서는 각 파티 안의 인원도 선택한 방향으로 자랍니다. 파티 간격은 가로/세로를 각각 0~100으로 조절하며 세로 간격과 별도로 그룹 이름 영역 18을 확보합니다. 미리보기와 통합 위치 편집도 선택한 10·20·40인 구간의 최대 인원을 사용합니다. 화면보다 큰 배치는 폭·높이·한 줄 그룹 수를 줄여 조절하세요.

### 공통 표시 옵션

**공통** 탭의 아래 값은 **현재 역할 프로필** 안의 파티·10인·20인·40인 배치에 함께 적용됩니다. 닉네임 뒤의 별도 배경 띠는 제거했고 흰 글자·검정 윤곽·그림자는 유지합니다.

| 설정 | 사용 방법 |
|---|---|
| 체력 바 배경 색·투명도 | 색상 선택창에서 배경 RGBA를 조절합니다. 취소하면 이전 값으로 복원합니다. |
| 체력 수치 표시 | 숫자만 켜거나 끕니다. 사망·자리 비움·오프라인 문구는 별도로 표시합니다. |
| 낮은 체력일수록 빨간색으로 표시 | 기본 OFF. 켜면 직업색에서 체력이 낮을수록 #FF0000에 가까워집니다. 사망 시 체력 영역은 #353535입니다. |
| 닉네임 위치 / 체력 텍스트 위치 | 각 체력 바의 9개 기준점과 X/Y로 조절합니다. 상태 문구는 체력 텍스트 위치를 공유합니다. |
| 대상 징표 / 역할 마크 | 각각 표시 ON/OFF, 기준점·X/Y·크기(8~40)를 설정합니다. 역할은 게임의 탱커·힐러·딜러 아이콘입니다. |
| 자원 바 | 표시 ON/OFF와 높이(1~24)를 설정합니다. 글자·자원 바가 겹치지 않도록 프레임 최소 높이를 보정합니다. |
| 파티원 디버프 표시 | 기본 OFF. 최대 개수(1~12), 크기(8~48), 한 줄 개수, 간격, 위/아래/좌/우/프레임 안 위치와 X/Y를 조절합니다. |

체력·자원의 제한된 수치는 Lua 산술·문자열 가공 없이 내장 위젯으로 전달합니다. 그라데이션은 게임 색상 곡선으로 계산하고, 디버프는 게임 기본 보안 표시기에 맡깁니다. 애드온이 오라 목록을 직접 읽거나 전체 유닛의 오라를 반복 조회하지 않습니다. 디버프의 툴팁·지속 시간·선별은 게임 기본 표시 정책을 따릅니다. 필요한 API가 없으면 해당 기능의 보류 사유를 표시하고 기본 프레임 표시는 계속 유지합니다. 이 경로의 실제 Forever 렌더링·보호 동작은 게임 확인 전입니다.

### 전용 프레임 프로필

**파티·공격대 → 프로필**에서 관리합니다. 프레임 전용 프로필은 **캐릭터별**이며 KHQOL 전체 프로필의 선택·복사와 별개로 유지합니다. 각 프로필에는 공통 표시 옵션과 파티·10인·20인·40인 네 배치를 저장합니다. 기본·탱커·딜러·힐러는 처음에 같은 설정으로 시작하므로 각각 원하는 모습으로 조정하세요.

**역할에 따라 탱커·딜러·힐러 프로필 자동 선택**은 게임이 지정한 역할을 사용합니다. 역할이 없거나 해당 이름의 프로필을 삭제했다면 직접 선택한 프로필을 사용합니다. 프로필을 직접 선택하면 자동 선택을 끕니다. 특성 추론이나 직업에 따른 역할 추정은 하지 않습니다. 전투 중 수동 프로필 생성·선택·삭제는 제한하며 자동 역할 변경의 보호된 적용은 종료 후 처리합니다.

업데이트 시 처음 활성화된 KHQOL 프로필의 기존 표시·배치를 네 전용 프로필로 복사합니다. 기존 KHQOL 프로필 데이터는 원래 저장소에 남깁니다. 다른 옛 프로필을 이후에 선택해도 전용 프레임 프로필을 다시 덮어쓰지 않습니다. 다른 옛 배치가 필요하면 그 값을 전용 프로필에 따로 설정하세요.

### 마법책·클릭 시전·휠

마법책의 기존 **KHQOL 사거리 설정** 버튼을 **KHQOL 설정**으로 바꾸고 **사거리 설정 / 휠 클릭 시전** 두 탭을 제공합니다. 사거리 모듈이 OFF여도 공유 버튼과 휠 탭을 사용할 수 있습니다. 사거리 기준 주문 등록은 사거리 모듈을 켠 뒤 사용합니다. 기존 사거리 등록값은 유지합니다.

휠 등록칸으로 마법책의 학습한 주문을 끌거나, 주문을 집은 상태로 해당 칸을 클릭합니다. 게임 커서가 제공한 정확한 주문 ID와 등급을 저장하며 성공할 때만 커서를 비웁니다. 잘못된 커서·미습득 주문·읽을 수 없는 정보는 이전 등록을 보존합니다. 전투 중 드래그 등록은 제한합니다. 같은 직업의 다른 캐릭터도 주문 저장은 각각 따로입니다.

기존 이름/ID 입력도 보조 수단으로 유지하며 빈 입력으로 해제할 수 있습니다. 휠 기본값은 OFF입니다. 등록 후 켜야 실제 적용됩니다. 대상 선택·오른쪽 메뉴·게임 기본 클릭 시전은 기본 SecureUnitButton 경로를 유지하며 **게임 클릭 시전 설정** 버튼으로 게임 설정을 엽니다.

| 입력 위치/설정 | 동작 정책 |
|---|---|
| 자체 파티·공격대 프레임 밖 | 기존 휠 단축키 |
| 프레임 안·휠 ON·해당 방향 주문 등록 | 그 유닛에 등록 주문 |
| 한 방향 미등록·휠 OFF·적용 불가 | 기존 단축키 |

일반 단축키 재배정·저장, 사용자 매크로·보조키 조합·자동 주문/대상 대체는 제공하지 않습니다. Clique/Clicked/HealBot/VuhDo/Cell 또는 외부 ClickCastFrames 소유자를 감지하면 휠 적용을 보류합니다. 모든 외부 애드온의 호환성을 보증하지는 않습니다. 실제 시전·가림/자식 영역·중복 입력·보조키·전투 중 해제 및 휠 복원은 게임에서 확인해야 합니다.

상시 `현재 ON · 휠 현재 … / 저장 …` 문구는 제거했습니다. 실패·입력 오류·전투 보류 같은 조치가 필요한 안내만 표시합니다. 전투 중 주문 변경·삭제가 보류되면 주문 안내에서 저장한 주문과 현재 적용 ID를 확인할 수 있습니다.

### 기본 프레임·저장·초기화

자체 프레임 준비가 성공한 뒤에만 기본 PartyFrame/CompactRaidFrameContainer를 자기 숨김 부모로 옮깁니다. 모듈 OFF·게임 편집 모드에서는 자기 변경을 조건부 복원하며 다른 애드온의 부모 변경을 보존합니다. 준비 실패 때 기본 표시를 먼저 숨기지 않습니다. 기본 게임 스크립트·이벤트·게임 편집 모드 설정과 일반 키 저장은 덮어쓰지 않습니다.

| 데이터 | 저장 소유권 |
|---|---|
| 모듈 ON/OFF | KHQOL 전체 프로필의 `KHQOLDB.enabled.partyFrames` |
| 전용 프로필·표시·네 배치 | 캐릭터별 `KHQOLPartyCharDB.frameProfiles` |
| 수동 프로필 선택·역할 자동 선택 | 캐릭터별 `KHQOLPartyCharDB` |
| 휠 사용·업/다운 정확한 주문 ID | 캐릭터별 `KHQOLPartyCharDB` |
| 이전 표시 설정 | 기존 `KHQOLDB.modules.partyFrames` 및 이전 프로필에 보존 |
| 게임 클릭 주문·일반 단축키·기본 배치 | 게임 소유 |

프레임 전용 프로필은 KHQOL 전체 프로필 변경에도 유지되지만 **모듈 ON/OFF는 기존 전체 프로필 정책**을 따릅니다. 새 전체 프로필에서 표시가 꺼지면 모듈 사용을 켜세요. 모듈 초기화는 현재 전용 프레임 프로필의 표시·배치만 초기화하며 다른 전용 프로필·알 수 없는 설정 키·휠 주문·다른 모듈 데이터를 보존합니다. 기본 전용 프로필은 삭제할 수 없습니다. 명시적인 전체 데이터 초기화는 이 새 캐릭터 저장소도 삭제합니다.

기존 SavedVariables 삭제나 전체 초기화 없이 업데이트하세요. 실제 `/reload`·재접속 저장 확인은 게임 체크리스트에 남아 있습니다.

## 1.10.9.0-fix에서 유지한 공통 기반

- **프로필 전환 C stack overflow 수정:** 대상/주시대상 체력 글자의 원본 투명도 훅과 복사 글자 훅 사이 재진입을 차단했습니다. 기존 복원 투명도 값도 보존합니다. 같은 1.10.9.0 버전의 수정 설치본이며 파일 해시로 이전 ZIP과 구분합니다.

- **유닛프레임을 실험실에서 분리했습니다.** 개발자 잠금 해제 없이 누구나 유닛프레임 설정·사용·검색·위치 편집·초기화를 사용할 수 있습니다. 기존 유닛프레임 사용 ON/OFF와 각 유닛의 설정은 유지합니다. 다른 실험 기능의 잠금은 유지합니다.
- 모듈 실행과 프로필·설정·검색·위치 편집을 연결하는 작은 공통 등록 방식을 추가했습니다. 단일 설치 폴더와 기존 SavedVariables 이름·내용 데이터의 소유 범위를 유지합니다.
- 프로필에서 알 수 없는 설정 키와 미등록 모듈 데이터를 보존합니다. 신규 설치용 기본값과 기존 누락 키 보충 정책을 구분합니다.
- OFF에서 등록 작업을 정리하고, BasicUI의 전투 보류는 소유 모듈·프로필·최신 요청을 확인합니다. 유닛프레임 OFF에서 일반 값 갱신 이벤트를 해제하고 남은 복원만 처리합니다.
- 좌표를 읽지 못한 위치 편집 값을 0으로 저장하지 않습니다. 프로필 변경 후 숨은 설정 페이지 전체를 갱신하지 않습니다.

새 연결 사용법과 유지한 예외는 [MODULE-CONNECTIONS.md](MODULE-CONNECTIONS.md)에 있습니다. 1.10.9.6에는 위 파티·공격대 설정과 표시를 개선했으며 설치 폴더 분리는 아직 진행하지 않았습니다. 이전 상점 장식·폭·재매입 복원, 체력 글자 대비·전투 중 값 갱신과 탭/위치 편집 동작은 유지합니다.

## 유닛 프레임

### 모양·체력·자원

유닛별로 간결한 프레임 사용, 폭·높이, 체력·자원 바 높이와 간격, 자원 표시, 배경 불투명도, 사각 테두리와 수치 표시를 조정합니다. 소환수·대상의 대상·주시대상은 실제 기본 부품이 확인될 때 적용합니다. 기본 레벨 글자가 없는 프레임에는 레벨을 새로 만들지 않습니다.

플레이어 모양 복사는 호환되는 크기·글자·배치 설정을 복사합니다. 유닛별 색상 정책, 전체 프레임 위치, 토템·오라 등 전용 기능은 각 유닛에 유지합니다. 선택한 유닛의 모양 초기화와 모듈 전체 초기화는 별도입니다.

플레이어 체력 색은 기본색 / 직업색 / 사용자 지정색을 선택합니다. 간결한 모드의 위협 장식과 붉은 체력 감소 표시가 선택색을 가리는 것을 방지합니다. 대상 사망 시 사용자 체력 숫자 `0`을 겹쳐 표시하지 않고 기본 죽음 상태 표시를 사용합니다.

간결한 프레임이나 별도 체력 색을 사용하는 경우 기본 체력 숫자의 글자 크기를 유지하면서 두꺼운 검정 윤곽과 그림자를 적용합니다. KHQOL 수치와 대상·주시대상의 기본 수치 복사에도 같은 대비를 사용합니다. 모듈을 끄면 변경한 기본 글자 스타일을 복원하며, 기본 글자 스타일 변경은 전투 종료 후 적용합니다.

대상·주시대상의 별도 체력 표시는 **전투 중 체력 값 갱신을 계속하면서 표시/숨김 변경만 보류**합니다. 전투 종료 후 최신 표시 상태를 적용하며, 전투 중 간결한 모드나 모듈을 끈 경우에도 종료 후 숨깁니다.

### 이름·레벨

위 / 내부 / 아래 / 왼쪽(외부) / 오른쪽(외부), 글자 크기와 X/Y를 조정합니다. 이름 구석 정렬은 위·아래에서 활성화되며, 첫 글자 또는 끝 글자를 프레임의 해당 끝에 맞춥니다. **이름 위치 또는 구석 정렬을 변경하면 이름 X/Y가 함께 0으로 초기화됩니다.** 같은 선택을 다시 누르거나 레벨 설정만 바꾸면 이름 좌표를 유지합니다.

플레이어·대상은 이름과 레벨에 각각 기본색 / 사용자 지정색 및 색 선택을 제공합니다. 정수 단위 글자 크기·좌표는 정수로 표시합니다. 배율·투명도·갱신 간격 등의 소수 단위 설정은 그대로 유지합니다.

### 상태·징표·토템

- **플레이어 → 상태·징표:** 휴식 상태, 전투 상태, 대상 징표에 각각 X/Y·드래그·위치 초기화를 제공합니다.
- **대상 → 상태·징표:** 기본 대상 프레임의 대상 징표를 개별 이동합니다. 기본 대상 프레임에는 플레이어 전용 휴식·전투 아이콘이 없습니다.
- **전체 위치 편집:** 개별 아이콘과 기존 상태·징표 전체 그룹을 선택할 수 있습니다. 이전 공통 보정과 개별 보정은 함께 적용됩니다.
- **토템·임시 소환:** 확인된 기본 TotemFrame과 하단 정보의 위치를 보정하며, 위치 확인용 예시를 제공합니다. 실제 직업별 표시가 다른 프레임이면 지원 확인이 필요합니다.

### 버프·디버프

내 캐릭터의 버프·디버프는 **플레이어** 탭에서 각각 설정합니다. **대상** 탭에서는 아군 대상 플레이어 / 공격 가능한 NPC 중 적용 유형을 선택합니다. 두 유형의 설정은 독립적으로 저장되며 같은 설정 묶음을 한 번씩 표시합니다.

1. 선택한 유형의 **버프/디버프 설정 사용**을 켭니다.
2. 표시 여부, 아이콘 크기와 공통 위/아래·X/Y를 조정합니다.
3. 따로 배치하려면 **버프·디버프 개별 위치 사용**을 켜고, 대상 버프·대상 디버프의 위치·X/Y·드래그를 각각 조정합니다.
4. **행·확장 설정 사용**을 켜면 종류별로 행당 **3~10개**, 최대 **1~4행**과 확장 방향을 설정합니다. 방향은 오른쪽 이후 위로 / 오른쪽 이후 아래로 / 왼쪽 이후 위로 / 왼쪽 이후 아래로입니다.

개별 위치 사용의 기본값은 OFF입니다. 처음 켤 때 기존 공통 위치를 바탕으로 개별 위치를 만들며, 다시 끄면 보존한 공통 배치로 돌아갑니다. 개별 좌표와 행·확장 선호도는 유지됩니다. 행 설정과 개별 위치 사용은 별도 옵션입니다.

기본 게임의 오라 목록·필터·아이콘·타이머를 사용합니다. 행당 개수 × 최대 행 수로 표시 한도를 정하며, 플레이어는 기본 아이콘 한도 안에서 표시합니다. 필요한 기본 오라 API를 확인할 수 없으면 기존 표시를 유지합니다. 적에게 먼저 공격받아 전투 중 대상을 선택하는 경우에는 직전에 적용한 크기를 사용하고, 새 크기·위치 변경은 전투 종료 후 적용합니다.

## 전체 위치 편집

설정창의 **위치 편집** 또는 각 기능의 **드래그 이동**으로 엽니다. 세부 설정의 **통합 위치 편집**은 그 설정의 유닛·모듈 그룹을 기본 선택합니다. 상단의 전체 위치 편집은 모든 그룹으로 열리며, 편집기 안에서도 필터를 변경할 수 있습니다. 실제 상태가 없어도 지원되는 시전바·상태 아이콘·오라·토템 등에 위치 확인용 예시와 경계를 표시합니다. 예시 아이콘·문구는 실제 효과나 남은 시간 표시가 아닙니다.

1. 대표 프레임 / 선택 그룹 / 선택 부품 / 전체 부품을 선택합니다.
2. 분류·유닛/모듈 필터, 검색과 대상 목록으로 겹친 프레임을 선택합니다.
3. 드래그, 1 UI px 이동 또는 X/Y 임시 보정으로 배치합니다.
4. **완료 / 잠금**으로 저장합니다. 취소·ESC는 편집 전 배치를 복원합니다. 전투 진입·모듈 OFF는 편집을 취소합니다. 편집 중 프로필 변경은 먼저 완료하거나 취소하도록 제한하며, 외부 프로필 세대 변경은 기존 편집을 무효화합니다.

미리보기와 위치 편집의 제목·설명·주요 버튼은 중앙으로 정렬했습니다. 위치 편집의 선택 경로/미세 이동 요약, **완료 후 크기·모양 설정** 버튼과 하단 중복 임시 위치 문구는 제거했습니다. **완료 / 잠금**, **취소**, **선택 위치 초기화**는 한 줄에 모았습니다. X/Y와 방향키 버튼, 목록 검색·필터는 유지합니다.

**모든 유닛·그룹**에서 특정 항목을 선택하면 목록은 선택한 경로 다음 부분만 표시합니다. 예: **바 설정 > 환경타이머** 선택 시 `환경 타이머 · 그룹`, `환경 · 호흡 텍스트`, `환경 · 피로도 텍스트`를 표시합니다. 전체 그룹에서는 전체 경로를 표시하며, 검색과 툴팁은 계속 전체 경로를 사용합니다. 표시 이름만 줄이고 실제 대상 ID·저장 위치는 바꾸지 않습니다.

편집 목록에는 켜진 모듈·하위 기능·직업·실험실·지원 API에 맞는 대상만 나타납니다. 모든 항목이 한 캐릭터에게 항상 표시되는 것은 아닙니다. 새 드래그 좌표는 최종 저장 단위에서 정수로 반올림합니다.

전체 기본 유닛 버튼의 위치는 게임의 기본 편집 모드를 사용합니다. KHQOL 편집기의 해당 대표 경계는 읽기 전용이며 부품 이동을 지원합니다. **대상의 대상** 프레임은 별도의 X/Y·드래그 이동을 제공합니다. 커서 툴팁·마우스오버 사거리 문구는 편집용 고정 예시에 대한 상대 보정을 저장합니다.

- **시전 → 플레이어:** 진행 방향, 독립 배치 또는 자원/스윙바 위·아래 연결, 바·아이콘·스킬명·시간·색상과 미리보기를 설정합니다. 독립 배치에서는 드래그 이동을 제공합니다.

- **환경타이머:** 호흡·피로도·죽은척 타이머, 표시 형태·경고와 HUD 텍스트를 설정합니다.

시전의 플레이어·대상 하위 탭은 스크롤해도 고정됩니다. 마지막 선택을 기억하고 검색·위치 편집에서 돌아올 때 해당 탭을 엽니다. 대상 시전바의 새 배치 변경은 전투 종료 후 적용합니다.

## 편의·인터페이스·알림

일반 편의에는 아이템 파괴 확인 자동 입력, 잡템 자동 판매·판매 금액 표시, 자동 수리·길드 자금 우선, 결투·파티·길드 초대 자동 거절과 친구/길드원 허용, 채집 추적 유지, 상인 판매목록 확장과 이미 습득한 아이템 표시가 있습니다. 각 기능을 개별 선택합니다.

상인 판매목록 확장은 기본 폭 336 UI px의 작은 소수점 오차를 허용합니다. 측정값 `336.00003051758`도 기본 폭으로 취급하고 OFF에서 원래 소수점 폭으로 복원합니다. 다른 애드온의 확장 슬롯·폭·배치를 감지하면 기존 충돌 안내를 유지합니다. 하단 장식은 Atlas의 원본 이미지 영역만 복사하며 버튼 주변 크기를 유지합니다. 수리·전체 수리·잡템 판매 버튼의 기본 동작과 표시 조건은 유지합니다. 원본 이미지 정보를 읽지 못하면 확장 보류 사유를 표시합니다.

**기본 대화창 편의**를 켜면 입력 커서 방향키, ↑/↓ 이전·다음 대화, 링크 툴팁과 URL 복사를 개선합니다. 이전 대화는 게임의 입력창 기록을 사용합니다. 자동완성 목록이 열려 있을 때에는 목록 선택 동작을 유지하며, 편의 기능을 끄면 기본 방향키 처리를 복원합니다.

인터페이스에서 기본창·가방·메뉴바, 툴팁의 커서 위치·글자·무기 전문가 안내, 마우스 잔상, 대상/마우스오버 사거리와 시계·정보 표시를 설정합니다. 사거리는 등록한 기준 주문으로 판정하며, 판정할 수 없는 경우를 공격 불가와 구분합니다. 실제 공격 성공이나 시야·방향·자원까지 판정하는 기능은 아닙니다.

**시계·정보 표시 → 전문기술**은 기본 전문기술과 배운 보조 기술을 표시합니다. 응급치료가 기본 전문기술 목록에서 빠지면 지원되는 기술 API로 실제 숙련도를 보충하며, 배우지 않은 기술은 만들지 않습니다. 위치 잠금은 체크 버튼이나 레이블로 켜고 끕니다.

**기본 UI → Blizzard 기본 프레임 이동**은 지도 · 캐릭터 창 · 특성 · 마법책 · 매크로창을 지원합니다. 공통 색상 견본 옆의 **변경** 버튼으로 색상 창을 엽니다.

알림에는 전투 시작·종료, 위협 수치·95% 음성·인스턴스 역할 조건, 수동 등록 위험 NPC, 적 플레이어 접근·주시·시전과 모닥불 알림이 있습니다. 등록 목록, 개별 사용 조건·문구·소리·색·위치를 해당 메뉴에서 설정합니다.

## 퀘스트·노트

**퀘스트 목록 (목표 추적기)**에서 지역 그룹화·접기·자동 펼치기·레벨/유형·글씨·표시 폭을 설정합니다. 게임 추적기의 기존 클릭·아이템·완료 표시를 사용하며, 목록 배치는 전투 종료 후 적용합니다.

**길 안내**에서 추적 퀘스트 자동 선택·완료 후 동작과 화살표 HUD 위치·크기·방향·정보 표시를 설정합니다. 두 탭은 기존 퀘스트 모듈 사용과 저장값을 공유합니다. 지역 자동 펼치기와 자동 퀘스트 선택을 함께 켜면 지역 전환 대기 후 낮은 레벨·가까운 목표 순으로 안내합니다. 직접 선택한 퀘스트·사용자 핀·노트 안내·반납 안내는 우선 유지합니다.

길 안내의 **퀘스트 이름 글자 크기**와 **진행도 글자 크기**는 각각 8~30 px이며 기본값은 14/12 px입니다. 이름 크기는 완료 안내 제목에도 적용합니다. 목표 추적기 글씨 크기는 별도이며, 같은 화살표 HUD를 사용하는 노트 안내에도 HUD 글자 설정이 적용됩니다.

**포에버 노트**는 페이지·메모·체크리스트·완료 상태와 좌표/mapID 기반 길 안내를 제공합니다. 퀘스트와 노트는 같은 화살표 HUD를 공유합니다. 위치·기능 설정을 바꿔도 작성한 노트와 완료 상태를 지우지 않습니다.

## 프로필·저장·초기화

프로필은 계정 공용이며 캐릭터마다 사용할 프로필을 선택합니다. 같은 프로필을 사용하는 캐릭터는 기능 설정을 공유합니다. 기본값으로 생성 / 현재 프로필 복사 / 선택 / 삭제를 제공하며, 기본 프로필은 삭제할 수 없습니다. 전투 또는 위치 편집 중에는 프로필 전환을 제한합니다. 특성별 자동 프로필 선택은 아직 제공하지 않습니다.

| 저장 범위 | 항목 |
|---|---|
| 현재 프로필 | 모듈 설정, 유닛 프레임·오라·상태·시전 배치, 설정창 배율·배경 불투명도 등 기존 기능 선호 |
| 계정 공용 | 프로필 목록, 기본창·설정창 위치, 설정창 크기·최근 유닛/부품/시전 탭·편집 표시 선호, 노트·공용 등록 목록 |
| 캐릭터별 | 사용하는 프로필 선택, 사거리 기준 주문, 수동 마우스 잔상색과 기존 캐릭터 완료/추적 상태 |

기존 SavedVariables 이름과 데이터 구분을 유지합니다. 설정창 크기와 최근 선택 등 UI 선호는 `KHQOLDB.toolWindows.preferences`, 유닛 설정은 기존 `KHQOLDB.modules.unitFrames`를 사용합니다. 런타임 프레임 원본·미리보기·검색 결과는 프로필 데이터로 저장하지 않습니다.

메뉴·하위 탭 이동과 선택창 열기는 기능 설정의 전체 프로필을 다시 저장하지 않습니다. 일반 체크·슬라이더·선택은 즉시 적용합니다. 텍스트 입력은 Enter 또는 포커스 종료로 확정하며 ESC·화면 종료는 미확정 초안을 취소합니다. 위치 편집은 완료 전까지 저장하지 않습니다. 파일 저장은 게임이 `/reload`·로그아웃 시 수행합니다.

위치 초기화, 선택한 유닛 모양 초기화, 모듈 설정 초기화는 적용 범위가 다릅니다. 모듈 초기화는 해당 프로필 설정을 복원하고 별도 공용 등록 목록을 유지합니다. **전체 초기화는 프로필·노트·등록 목록까지 지우므로**, 단순 업데이트에는 사용하지 않습니다.

## 설정창 조절·명령

오른쪽 아래 모서리를 드래그하여 창 크기를 변경합니다. 본문은 폭에 맞춰 1열/2열로 재배치됩니다. 왼쪽 아래 **투명도**는 배경에만 적용하며 글자·컨트롤은 선명하게 유지합니다. **배율**은 창의 글자와 컨트롤 전체 크기에 적용합니다.

| 명령 | 동작 |
|---|---|
| `/khqol`, `/kh` | 일반 설정 열기 |
| `/khqol unitframes` | 개인 유닛 프레임 설정 |
| `/khqol party`, `/khqol raid` | 파티·공격대 설정 |
| `/khqol cast`, `/khqol resource` | 시전 / 자원·스윙바 설정 |
| `/khqol quest` | 길 안내 설정 |
| `/khqol quest status`, `layout`, `auto` | 안내 상태 / 추적기 배치 / 지역 자동 펼치기 진단 |
| `/khqol threat` | 위협 수치 설정 |
| `/khqol tooltip`, `range`, `clock`, `todo` | 해당 기능 설정 |
| `/khqol labs` | 실험실 접근·설정 |

## 검증·지원 범위

기준 1.10.9.0-fix의 과거 409개 검사는 이전 단계 기록입니다. 이번 수정본은 최종 ZIP의 전체 TOC·구문·공통 연결·파티 상태·편집기와 사용자 피드백 회귀를 새로 검사합니다. 최종 ZIP의 검사 수·SHA-256은 별도 검증 보고서와 tests.json에 기록합니다. 과거 결과를 이번 결과로 재사용하지 않습니다.

**실제 Forever 게임 클라이언트 검증은 미실시입니다.** 실제 솔로/그룹·시전·전투·보호/secret/taint·휠 입력과 저장 복원·렌더링·성능은 동봉 게임 체크리스트 확인이 필요합니다. 모의 통과는 인게임 정상 동작을 뜻하지 않으며, 확인 전 3단계 진행은 보류합니다.

자연 기력 회복 주기 표시는 공개된 동기화 근거를 확인하지 못해 지원 보류를 유지합니다. 특성별 자동 프로필과 설치 모듈 분리는 [ROADMAP.md](ROADMAP.md)의 향후 항목입니다. 개발 구조는 [DESIGN.md](DESIGN.md), 연결 계약은 [MODULE-CONNECTIONS.md](MODULE-CONNECTIONS.md)를 참고하세요.
