# KHQOL 1.11.8.23 — 전문기술 공통 확장 레벨·결과 메뉴

## 변경과 근거

실제 기준은 1.11.8.22 Full이며 SHA256은 20f1e8617372b474b6a250311fa16042e40fa6ca31f0bdc2cbeb40d4bd017e1a입니다. 이전 ZIP·sources/·설치본은 바꾸지 않았습니다.

사용자가 제공한 서버 공통 요구 레벨을 12개 전문기술의 다음 36단계에 적용했습니다.

| 다음 숙련 상한 | 요구 레벨 |
|---|---|
| 150 | 10 |
| 225 | 20 |
| 300 | 35 |

이 값은 **사용자 제공 공통 규칙(USER_CONFIRMED)**입니다. 이전 웹 자료의 미표기 또는 상이한 레벨은 진단용 levelReference에 남기고 이번 실제 표시/판정에는 공통 규칙을 우선합니다. levelStatus=VERIFIED는 기존 조건 판정이 읽는 상태이며 별도 웹 검증을 주장하는 뜻이 아닙니다. 확장 상한 75나 미지원 다음 단계·읽기 불가 현재 값은 추측하지 않습니다. 정상적으로 지원하는 150/225/300 다음 단계의 요구 레벨은 더 이상 하이픈이 아닙니다.

요리도 기존 미확인 레벨 때문에 막히던 습득처 표시가 열립니다. 레벨 23·요리 기본 숙련 150/상한 150의 얼라이언스 모의 결과는 다음과 같습니다.

```text
요리

레벨 23 (20)
숙련 150/150 (125)

225 숙련
실바람 산장(잿빛 골짜기) · 샨드리나
'고급 요리책' 1[게임 기본 골드 아이콘] 구입

우클릭 시, 좌표등록
```

호드의 같은 조건에서는 그늘수렵 마을(잊혀진 땅)의 울란과 고급 요리책·같은 원래 가격이 표시됩니다. NPC·지역·한글 책 이름·가격·퀘스트·요구 숙련·좌표는 기존 검증 자료를 수정하지 않았습니다. 표시한 습득처와 등록 대상이 같은 기존 경로를 유지합니다.

## 우클릭 결과 메뉴

등록/중복 확인 뒤 메뉴에서 ‘ForeverNote 열기’ 항목과 note→ToggleTodo 분기를 제거했습니다. **‘등록된 노트 위치 길 안내’ 한 개만 남습니다.** 두 후보 선택 메뉴에서 등록 결과 메뉴로 바뀔 때 이전 두 번째 행도 숨깁니다. 길 안내는 사용자가 남은 메뉴를 선택할 때만 시작합니다.

좌표 등록은 기존처럼 한 장소 즉시/두 장소 선택입니다. 레벨·기본 숙련, 표시한 후보, 프로필/진영/다음 단계 변경 재검증, 노트 미설치/비활성·지도/좌표 제한, 중복 항목/기존 메모 보존, 실제 Note/map pin provider는 같은 구현을 사용합니다. 3곳은 상한까지, 일반 교관 장소가 4곳 이상이면 대도시 상급자로 요약하고 등록 메뉴를 제공하지 않는 정책도 같습니다.

## 실제 게임 확인 — NOT TESTED

실제 WoW의 글꼴/화면과 클릭, 지도 핀과 리로드 유지는 수행하지 않았습니다. 아래를 확인하면 됩니다.

1. 요리·약초채집·응급치료·낚시와 다른 기술에서 현재 숙련 상한 75/150/225일 때 괄호 요구 레벨이 10/20/35인지 확인합니다.
2. 요리 레벨 23·150/150에서 요구 레벨 20, 다음 225 숙련, 현재 진영 판매처·고급 요리책·원래 가격이 보이는지 확인합니다. 조건 부족 시 상세 습득처는 없어야 합니다.
3. 등록 가능한 상세 장소에서 우클릭하여 실제 노트/지도 핀을 확인하고, 결과 메뉴는 길 안내 한 개인지 확인합니다. 두 장소 선택 후에도 ‘ForeverNote 열기’가 남지 않아야 합니다.
4. 같은 위치를 다시 등록해도 기존 메모·완료 상태를 보존하며 리로드 후 유지되는지 확인합니다. DevTools ON/OFF/비활성에서 동일 동작과 기존 보호 동작을 확인합니다.
