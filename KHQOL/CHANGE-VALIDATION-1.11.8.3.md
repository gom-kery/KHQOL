# KHQOL 1.11.8.3 변경·검증 보고서

기준 ZIP은 `KHQOL-1.11.8.2-Full.zip`이며 결과 ZIP은 `KHQOL-1.11.8.3-Full.zip`입니다. 대상은 WoW Forever 1.60.1, 빌드 70938, Interface 16001입니다.

## 변경

- `KHQOL_Convenience/UI/ConvenienceDetails.lua`에서 **버프 알림 위치 편집** 버튼이 해당 파일에 정의된 `KHQOL` 참조를 사용하도록 수정했습니다. 이전 콜백은 정의되지 않은 전역 `K`에 접근했습니다.
- 같은 파일의 **말머리·자동 인사** 화면에서 **파티 자동 인사**와 **버프 감사 알림**을 독립적인 접기·펼치기 섹션으로 분리했습니다. 공격대 자동 인사와 인사말 입력은 **파티 자동 인사**에 들어갑니다.
- `KHQOL_Convenience/UI/SearchIndex.lua`와 `KHQOL_Convenience/Modules/BuffThanks.lua`의 설정 이동 경로를 갱신했습니다.
- 애드온 TOC 19개와 런타임 표시 버전, README와 변경 이력 및 설치 안내를 갱신했습니다.

## 검증

- 전역 `K`가 없는 모의 환경에서 1.11.8.2의 클릭 오류를 재현했습니다. 수정 후 버튼을 눌러 위치 편집창이 열리고 버프 감사 알림 미리보기가 선택되는 것을 확인했습니다.
- 각 섹션을 따로 접고 펼 수 있고, 검색 결과가 해당 섹션을 펼치는 것을 확인했습니다. 버프 감사 알림을 끄면 위치 편집이 열리지 않습니다.
- 정적 검사에서 Lua 234개, XML 8개, TOC 19개, SavedVariables 선언 12개를 확인했습니다. 설치 구성 다섯 가지에서 모의 검사 1,559건을 통과했습니다.
- **인게임 미검증.** 실제 클라이언트에서의 편집창 표시와 클릭은 실행하지 않았습니다.
