# KHQOL 1.11.7.7 변경·검증 보고서

기준은 KHQOL 1.11.7.6 전체 설치 ZIP입니다. WoW Forever 1.60.1 / 빌드 70938 / Interface 16001용 1.11.7.7로 패키징했습니다. 사용자 스크린샷과 피드백으로 1.11.7.6에서는 하급·일반을 선택한 드롭에서 기본 확인창이 열리고, **예**를 선택하면 아이템이 파괴된 것을 확인했습니다.

## 드롭 처리

- 선택한 등급을 휴지통에 드래그해 놓으면 실제 입력 처리기 `OnReceiveDrag`에서 `DeleteCursorItem`을 한 번 호출합니다. 커서에 올린 아이템을 일반 클릭으로 놓거나 미선택 등급을 드롭하면 기본 확인창이 열립니다.
- 게임이 파괴를 완료하면 별도의 팝업을 열지 않습니다. 게임이 자체 확인을 요구하면 해당 창을 그대로 사용합니다. 요청이 거부되고 같은 아이템과 수량이 커서에 남아 있으면 기본 확인창을 엽니다. 다음 프레임 확인에는 파괴 API를 다시 호출하는 경로가 없습니다. [커서 파괴 API](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/GameCursorDocumentation.lua#L49-L55) · [게임 확인창 경로](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_Game/Mainline/EventImplementation.lua#L289-L303)
- 보호 아이템은 파괴 요청 전에 차단하고, 퀘스트 아이템은 기존 퀘스트용 확인창을 사용합니다. 분할한 아이템은 집은 수량이 확인되면 커서만 대상으로 요청합니다.

## 표시

- 기존 다섯 등급의 글자에 게임 등급 색상을 적용했습니다. **휴지통 아이콘 크기**는 슬라이더 위 한 줄에 배치했습니다.
- **화면에 직접 배치**는 현재 캐릭터의 기본 통합·개별 가방이나 Baganator 단일·카테고리 가방을 열었을 때 휴지통을 표시합니다. 다른 인벤토리 애드온은 게임에서 가방이 열렸다고 보고하는 경우 표시합니다. KHQOL 위치 편집에서는 편집용 손잡이를 사용합니다.
- 보호·해제 시 아이템 이름을 화면 메시지와 채팅에 남깁니다. 보호된 아이템의 가방 툴팁에는 자물쇠와 보호 문구가 표시되며, 마우스를 올린 채 단축키를 누르면 툴팁을 다시 읽습니다. 설정에는 보호 목록의 등록 수가 표시됩니다.
