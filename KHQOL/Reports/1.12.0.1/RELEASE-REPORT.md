# KHQOL 1.12.0.1 변경·검증 보고서

캐릭터·전투를 캐릭터와 전투로 분리하고, 보고된 다섯 메뉴의 3Depth를 구분선 아래 별도 영역으로 이동했습니다. 기준은 1.12.0 전체 ZIP이며 원본 ZIP·작업본은 보존했습니다.

## 결과

- 최상위 6개: 캐릭터, 전투, 퀘스트·지도, 생활·소통, 화면·정보, 설정·프로필.
- 캐릭터 하위 5개: 유닛프레임, 파티·공격대 프레임, 경험치·평판, 환경·보호막 타이머, 버프·휴식 알림.
- 전투 하위 4개: 시전바, 자원·스윙바, 거리·사거리, 전투·위협 알림.
- 구분선 아래 배치: 파티·공격대 프레임, 전투·위협 알림, 버프·휴식 알림, 채팅·말머리, 숙련·전문기술.
- 표시 순서: 2Depth → 구분선 → 3Depth → 실제 소유자 사용 상태 → 기존 유닛/부품 선택·잠금·본문.
- 선택 탭·반복 열기·입력 취소·공유 초기화·사용 상태·저장 범위·실험실 조건 유지. 새 게임 모듈이나 SavedVariables 없음.
- DevTools 0.4.0 전체 파일은 기준본과 동일합니다. Full ZIP에 포함합니다.

레이아웃 검사는 80/100/120%와 650×480, 980×720, 1600×1200 조건에서 실제 SetPoint 앵커 오프셋·공통 부모·프레임 높이를 대조했습니다. 기존 fixture의 GetTop은 고정값이므로 렌더링 좌표로 사용하지 않았습니다. 게임 픽셀·폰트 측정·실제 스크롤 가시성을 확인했다는 뜻이 아닙니다.

회귀 기대값은 승인된 버전 1.12.0.1과 거리·사거리의 이동된 battle 헤더 참조만 갱신했습니다. 기능 검증 조건은 유지했고 해당 5개 suite를 재실행하여 전체 36개가 통과했습니다. 처음의 레이아웃 진단은 fixture의 고정 GetTop 한계를 확인한 뒤 공통 부모의 실제 앵커 오프셋으로 수정했습니다.

## 변경 범위

실제 Lua 변경은 Bootstrap.lua의 승인 버전, SettingsScreens.lua의 표시 분류/이전 경로, SettingsPresenter.lua의 세부 탭 소유 프레임, SettingsUI.lua의 배치/수명/Refresh, ResourceSwing의 기존 명령어 화면 판정입니다. 나머지 선택 패키지는 TOC 버전만 갱신합니다. 코드·기능 데이터·보호 정책을 새로 설계하지 않았습니다.

Reports/1.12.0.1의 Markdown/JSON은 메뉴·소유권·검증 증거입니다. TOC에 추가하지 않아 게임에서 로드하지 않습니다. README/CHANGELOG/DESIGN은 최신 결정을 추가하고 과거 기록을 유지했습니다. 이번 변경에는 새 런타임 파일이나 로드 순서 변경이 없습니다.
