# KHQOL 1.12.0.2 구현·검증 보고서

기준: KHQOL 1.12.0.1 Full. DevTools 0.4.0 / Interface 16001 유지.

## 구현

1. 강조 이미지 4번을 하단 화살표로 교체하고 이전 선택값만 이관했습니다. 원본 TGA(256×256, RGBA, 262188 bytes)는 변형하지 않았습니다.
2. 공통 슬라이더를 크기·투명도 / X·Y의 2열로 정렬했습니다.
3. 강조 이미지 반짝임(기본 OFF)과 전체 주기 0.5/1.0/1.5/2.0초를 추가했습니다. 사용자 alpha를 유지하며, 기존 타깃 갱신이 점멸을 재시작하지 않습니다.
4. 충분한 휴식 버프 만료 2분 전 메시지(기본 ON)를 추가했습니다. 침낭 아이콘 OFF에서도 동작하며 버프 유지 알림과 현재 직업의 침낭 버프를 켜야 합니다. 3초 표시, 접속 중 같은 기한 중복 방지, 공개 시각이 없는 경우 추정 금지, 연장 후 재알림을 적용했습니다.
5. 새 설정의 프로필 전환·백업·가져오기·모의 재접속을 확인했습니다. 기존 기능 설정과 등록 문구를 일괄 수정하지 않았습니다.

## 검증 결과

- PASS: Lua 5.1 문법 274개 / XML 8개 / 기존 TOC 연결.
- PASS: 기존 회귀 36개 검사 묶음. 업그레이드 검사의 기대 버전만 1.12.0.2로 갱신했고 기능값 검증은 유지했습니다.
- PASS: 새 기능 6설치 조합. 전체/DevTools 미설치/유닛프레임 미설치/Labs 미설치/Convenience 미설치/코어만 설치. 미설치 기능은 생성하지 않았습니다.
- PASS: 카테고리·기존 경로 9설치 조합, 구분선 아래 3Depth 배치 7조합. 배율 80/100/120%와 창 크기 3조건은 모의 앵커 검사입니다.
- PASS: SHAMAN 전체 모의 생성 전후 각 113분기, 생성 실패 0. 검색/등록 1387→1390, 실제 컨트롤 1037→1040. 기존 1037개 컨트롤의 논리 ID·소유자·진단 ID가 같습니다.
- PASS: 점멸 그룹 재사용·주기 변경·종료와 기본 alpha 분리. 알림의 실제 기존 타이머 경로에서 UNIT_AURA 추가 이벤트 없이 120초 경계에 도달함을 확인했습니다.
- PASS: 중복 갱신·버프 연장·UNKNOWN·만료/무기한·아이콘 OFF·알림 OFF·직업 설정 OFF·모듈 OFF·프로필 전환과 임시 알림 정리.
- PASS: 개인정보 없는 비어 있지 않은 값(크기135/alpha.65/X43/Y-27/점멸2초/만료알림OFF)으로 내보내기·검사·가져오기·새 런타임 SavedVariables 복원을 확인했습니다.
- PASS: DevTools 전체 파일과 코어의 진단 카탈로그가 기준본과 바이트 단위로 같습니다. 기록 ON/OFF는 기존 회귀에 포함됩니다. 신규 3개 설정과 새 메시지의 개별 진단 집계는 이번에 추가하지 않았습니다.
- NOT TESTED: 실제 게임에서 이미지/Alpha 애니메이션 렌더링, 점멸 주기 체감, 한글 줄바꿈, 실제 전투와 서버 버프 이벤트/API 공개 상태.

## 설치·제한

게임을 종료하고 Full ZIP의 19개 폴더를 AddOns에 교체하세요. 사용자 WTF/SavedVariables와 원본 ZIP, sources/는 변경하지 않았습니다. 새 런타임 파일·필수 패키지·TOC 로드 항목은 없습니다. 미디어 TGA와 이번 Reports 문서만 새 파일입니다.

버프 만료 시각을 읽을 수 없을 때는 알리지 않습니다. 이후 정상 관측이 2분 이내이면 한 번 알립니다. 접속/리로드 후 이미 2분 이내인 경우도 한 번 알릴 수 있습니다. 만료 메시지 위치는 기존 침낭 획득 메시지와 같습니다. 새 점멸은 기본 OFF이므로 기존 강조의 상시 표시를 유지합니다.

## 인게임 확인 체크리스트

- [ ] 약초·채광·물체 각각의 4번 선택이 하단 화살표이며 다른 이미지/색상/좌표가 유지됨.
- [ ] 공통 설정이 크기·투명도 / X·Y 순서이고 창 크기·배율을 바꿔도 입력란이 겹치지 않음.
- [ ] 반짝임 OFF 및 0.5/1.0/1.5/2.0초 모두 동작하고 강조 투명도/상호작용 거리 감쇠를 유지함.
- [ ] 대상 이탈·대상 변경·모듈 OFF·전투 숨김 후 점멸이 정리되고 다시 대상 선택 시 정상 재개됨.
- [ ] 충분한 휴식 버프가 2분 남았을 때 메시지 1회, 이후 UNIT_AURA/설정 이동에 중복 없음. 버프 연장 후 새 만료에 1회.
- [ ] 침낭 아이콘 OFF에서도 만료 알림 가능, 만료 알림/현재 직업의 침낭 버프/버프 유지 알림 OFF이면 새 메시지 없음.
- [ ] 기존 침낭 설치·3중첩 진행·획득 메시지·음식/포만감·마법책 버프 드래그 등록 정상.
- [ ] /reload·프로필 전환 뒤 반짝임 주기와 만료 알림 설정이 유지되고 이전 메시지가 남지 않음.
