상태 문구: 새 침낭 메시지 `침낭 버프가 2분 이내에 만료됩니다.`를 추가합니다. 기존 `침낭 버프 획득`, 중첩/추정/서버 갱신 대기, 충돌/복원/게임 재시작 경고는 유지합니다. 반짝임 주기의 설명은 해당 슬라이더 툴팁, 침낭 알림 설명은 해당 체크박스 툴팁에 둡니다.

미검토 범위: 실제 엔진의 한글 줄바꿈, 반짝임 체감 및 텍스처 블렌딩, 서버 버프 API 공개 여부와 전투 이벤트 타이밍. 미설치/읽기 불가/꺼짐/전투 분기는 새 기능 테스트와 기존 회귀에서 모의 확인했습니다. 진단 ID가 없는 신규 컨트롤은 NEW-CONTROLS.json에 표시합니다.
