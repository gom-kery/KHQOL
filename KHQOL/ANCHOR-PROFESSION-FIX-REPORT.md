# KHQOL 1.11.8.22 — 앵커·파티 잠금·전문기술 보완

## 기준과 변경

기준은 실제 최신 1.11.8.21 Full입니다. SHA256: d584cb3b1842d5fa715903f11972c7f79bb55affdc7b1074b8c2176ba782c32f. 이전 작업/ZIP·sources/·실제 게임 설치본을 바꾸지 않고 baseline/과 full/을 분리했습니다.

1. 공통 위치 잠금 OFF 테두리 내부의 sample 문구를 제거했습니다. 앵커 위 이름만 표시하며 word wrap OFF와 자체 글자 폭을 사용합니다. 작은 플레이어 휴식/전투/징표·대상 징표 폭 때문에 글자가 세로로 쌓이지 않습니다. 유닛 Position Editor sample의 ‘위치 미리보기’와 Threat의 같은 표시 문구도 정리했습니다. 가상 위협도 데이터 표시는 실제 정보로 오인하지 않도록 ‘가상 데이터’를 유지합니다.
2. 파티·공격대 > 파티·공격대 탭 아래에 `파티 [ON] 위치 잠금`, `공격대 [ON] 위치 잠금` 두 행을 추가했습니다. 각각 독립 해제/이동합니다. 모듈 사용과 기존 좌표·크기·미리보기·초기화는 남아 있습니다.
3. 알 수 없는 요구 값의 em dash가 사용자 화면에서 깨졌습니다. 이 표시에만 글꼴 호환성이 높은 ASCII `-`를 사용합니다. 중립색·UNKNOWN 상태를 유지하며 조건 없음/NONE이나 숫자 0으로 해석하지 않습니다.
4. 낚시 수습 최대 150/숙련 최대 225에 요구 레벨 10/20을 보완했습니다. 요구 기본 숙련 50/125, 기존 책·NPC·가격·지도는 유지합니다.
5. 조건 충족·검증된 일반 교관 습득 장소가 4곳 이상이면 `대도시 {전문기술} 상급자`를 표시합니다. 정확히 3곳은 상한까지만, 1~2곳은 기존 상세 장소입니다. 책/퀘스트가 섞인 다수 장소를 ‘대도시 상급자’로 바꾸지 않습니다.

## 전문기술 자료와 표시

낚시 숙련 225의 레벨 20·기본 숙련 125와 헤밍 판매 1골드는 [Method의 Forever 낚시 안내](https://www.method.gg/wow-forever/fishing-in-wow-forever-leveling-guide-fishing-items-trainers)에서 명시적으로 확인했습니다. 한글 책 이름 ‘고급 낚시정보’, 노인 헤밍, 무법항/가시덤불 골짜기와 원래 좌표는 [WOWF 숙련 단계](https://wowf.io/ko/professions/fishing/ranks)의 기존 검증 자료를 유지합니다. 추가 출처/확인일은 정적 데이터 필드와 research/22-supplement.json에 보존했습니다. 예시 숫자로 채운 값이 아닙니다.

[ForG 전문기술 목록](https://www.forg.gg/en/forever/professions)도 확인했으나 낚시 상세 페이지는 조회되지 않아 변경한 요구 조건의 검증 근거로 사용하지 않았습니다. 낚시 최대 300의 요구 숙련은 WOWF 200과 Method 225가 달라 기존 검증값 200을 이번 범위에서 변경하지 않았습니다. 다른 전문기술의 미표기도 추측해 보완하지 않았습니다.

현재 레벨 23, 낚시 기본 숙련 125/상한 150이면 아래 내용이 표시되며 두 수치 행은 초록색입니다.

```text
낚시

레벨 23 (20)
숙련 125/150 (125)

225 숙련
무법항(가시덤불 골짜기) · 노인 헤밍
'고급 낚시정보' 1[게임 기본 골드 아이콘] 구입

우클릭 시, 좌표등록
```

골드 아이콘은 문구 대신 기존 MoneyFrame texture를 사용하고 0인 은/동은 생략합니다. 요구 조건 부족/불가, 위치 표시 설정 OFF, 후보 자료 미확인에서는 상세 정보와 등록을 숨깁니다. 수집 장소 수는 현재 진영/중립·바로 다음 단계·검증된 실제 장소 중복 제거와 기존 원문 목록 서명을 사용합니다. NPC 수와 좌표 등록 가능 수를 장소 수와 혼합하지 않습니다.

| 상태 | 표시와 우클릭 |
|---|---|
| 조건 부족 또는 불가 | 기술명·레벨·숙련, 미확인 값은 중립 `-`, 등록 없음 |
| 조건 충족·1~2곳 | 다음 상한·장소·NPC·책/가격/퀘스트. 등록 가능한 노트/좌표가 있으면 짧은 우클릭 안내 |
| 조건 충족·3곳 | 다음 상한까지, 등록 없음 |
| 조건 충족·4곳 이상 일반 교관 | 다음 상한 + 대도시 전문기술 상급자. NPC 목록/선택/등록 없음 |
| 불완전한 후보·혼합 습득 방법 다수 | 임의로 특정 소수 장소나 대도시 교관으로 단정하지 않음 |

## 우클릭 등록 상태

기존 .21에도 등록은 구현되어 있었지만 낚시는 미확인 요구 레벨 때문에 표시 조건에 막혀 있었습니다. 이번 보완은 같은 Presentation/Ticket/Register 경로를 사용합니다. 한 곳 즉시, 두 곳 선택이며 표시한 후보와 등록 좌표가 같습니다. 좌표·지도 검증, 노트 미설치/비활성 제한, 기존 메모/완료 상태/중복 보존, 프로필/진영/숙련/다음 단계 변경 시 재확인을 유지합니다.

낚시의 실제 배포 데이터를 사용해 생산용 AddTodoCoordinate와 Note map pin provider를 호출하여 노트와 보이는 핀을 모의 환경에서 확인했습니다. 다른 기존 등록 노트는 전체 SavedVariables를 새 런타임에 복원해 핀 재생성도 검사했습니다. **실제 WoW Forever에서 마우스 우클릭과 지도 핀을 확인한 것은 아닙니다. 인게임 NOT TESTED입니다.**

## 파티·공격대 저장·이동

새 `positionLocks.party/raid`는 기존 계정 공용 프레임 프로필 안에 저장하며 기본 ON입니다. KHQOL 전체 프로필의 모듈 사용 값과 별개입니다. 공격대 OFF 앵커는 ‘편집할 프레임’의 raid10/20/40 배치를 사용합니다. 편집 대상이 파티일 때는 현재 인원에 맞는 공격대 배치를 사용합니다. 선택한 배치의 기존 X/Y writer·RequestApply를 호출하므로 인원에 따라 나뉜 좌표를 덮어 합치지 않습니다.

수동 프레임 프로필/배치 전환 전에 진행 중인 드래그를 마치고, 오래된 대상은 프레임 프로필 객체·현재 배치로 재검증합니다. 역할 자동 선택/인원 변경은 기존 이벤트와 공통 앵커 재배치로 처리합니다. 전투 진입 시 미완료 드래그를 취소하고 전투 종료 시 OFF 앵커를 복원합니다. 기존 전역 위치 편집 ID/완료·취소와 미리보기 기능을 유지하며 새 OnUpdate/반복 타이머는 없습니다.

잠금은 기존 setting change로 계측합니다. 새 통계 ID는 `setting.partyFrames.party.positionLocked`, `setting.partyFrames.raid.positionLocked` 두 개이며, 기존 1,635개 카탈로그 행을 필드별 대조해 보존했습니다. 헤더 잠금 목록은 48개, DevTools 0.3.4/catalog revision 6/Usage v0.1/schema 1/protocol 1입니다. 좌표 원본/프로필명은 수집하지 않습니다. 앵커 표시/드래그는 Position Editor start로 집계하지 않습니다. 툴팁 Refresh와 등록 요청/완료의 계측 의미도 같습니다.

1. 플레이어 휴식/전투/징표와 대상 징표 잠금을 풀고 내부 문구 없음·가로 제목이 앵커 위에 표시됨·드래그 저장·ON 종료를 확인합니다. UI 배율/긴 이름/여러 제목의 겹침도 확인합니다.
2. 파티와 공격대 잠금을 독립 해제하고 파티/10/20/40인 배치를 각각 이동합니다. 기준점·가로/세로·우측 정렬·스케일·좌표·크기·초기화, 솔로/실제 로스터에서 적용을 확인합니다.
3. 계정 프레임 프로필 선택/역할 자동 선택·드래그 중 전투·배치 전환·리로드/접속 종료 후 위치와 잠금 상태를 확인합니다.
4. 레벨 20 이상/낚시 기본 125/상한 150에서 헤밍·책·1골드와 등록 안내를 확인하고, 실제 우클릭→노트→해당 지역 지도 핀→리로드 유지/중복 메모 보존을 확인합니다. 조건 부족/노트 OFF/잘못된 지도에서는 등록되지 않아야 합니다.
5. 확인된 일반 교관 장소 4곳 이상은 대도시 상급자로 표시하고 3곳은 상한까지만 표시하는지 확인합니다. 미확인 요구 값의 `-`와 숫자 색상을 확인합니다.
6. DevTools ON/OFF/비활성에서 같은 기능을 확인합니다. 잠금은 설정 변경, 명시적 전역 위치 편집만 start, Refresh는 새 조회가 아니어야 합니다. 이전 마법책/게임 메뉴 접속 종료 차단도 인게임 회귀가 필요합니다.
