# KHQOL 1.11.3

기준 1.11.2.5 Full · 결과 1.11.3 · 인터페이스 16001 · 2026-10-18.

파티·공격대 설정에 **[공통] [파티·공격대] [버프·디버프] [프로필]** 네 탭을 제공합니다. 기존 디버프 아이콘 설정은 버프·디버프 탭으로 옮겼으며, 크기·간격 및 X·Y를 두 열로 배치합니다. 좁은 창에서는 한 열로 바뀝니다. 기존 아이콘 설정값을 유지합니다.

디버프 종류에 따라 체력이 차 있는 부분의 색을 변경합니다. 기본색은 저주 #9600FF, 질병 #966400, 마법 #3296FF, 독 #009600, 출혈 #C80000입니다. 각 색과 투명도를 변경하고 기본색으로 복원할 수 있습니다. 여러 디버프가 겹치면 게임 표시기가 우선순위에 따라 한 종류를 선택하며, 해제되면 기본 체력 색으로 돌아옵니다.

같은 탭에 보호막 오버레이 ON/OFF, 보호막 무늬·흡수 무늬·단색 텍스처, 색·투명도 선택을 추가했습니다. 흡수량은 최대 체력 대비 비율로 체력 바 오른쪽에서 왼쪽으로 표시합니다. 정상 상태와 디버프 다섯 종류를 함께 보는 예시 및 보호막 비율 슬라이더가 있으며, 기존 파티·공격대 전체 배치 미리보기에도 반영합니다.

새 색상 표시와 보호막의 기본값은 ON이며 파티·공격대 모듈이 켜져 있을 때 적용합니다. 디버프 아이콘의 기존 ON/OFF는 유지합니다. 설정은 계정 공용 프레임 프로필에 저장하므로 같은 프로필을 선택한 다른 캐릭터에서도 사용합니다.

## 설치

게임을 종료하고 기존 KHQOL 및 KHQOL_* 코드 폴더를 AddOns 밖에 백업한 뒤 ZIP의 19개 폴더를 넣습니다. 남아 있는 KH_map도 AddOns 밖으로 옮깁니다. **WTF와 SavedVariables는 그대로 둡니다.** [설치·사용 안내](INSTALL-GUIDE.md)에 확인 절차가 있습니다.

공통 기반 1개 + 선택 기능 18개, **19개 폴더 / 271개 파일 / Lua 193개 / XML 5개 / 고유 저장 변수 11개**입니다. KH_map과 앞서 감사한 미사용·과거 파일은 포함하지 않습니다.
