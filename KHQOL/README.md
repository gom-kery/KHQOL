# KHQOL 1.11.2.5

기준 1.11.2.4 Full · 결과 1.11.2.5 · 인터페이스 16001 · 2026-10-18.

재접속 후 기본 플레이어 체력 바의 크기·위치를 읽을 수 없으면 간결한 프레임 전체가 적용되지 않던 문제를 수정했습니다. 간결한 체력 표시는 자체 바에서 그리며, 기본 체력 바의 크기·위치는 읽거나 변경하지 않습니다. 체력 수치·최대치는 기존 바에서 받아 표시합니다. 플레이어 이름·레벨·자원·상태 표시도 새 체력 표시를 기준으로 배치합니다.

설정 헤더의 대상 버프 분류는 `대상 > 버프·디버프`에서만 표시합니다. 플레이어 기본 화면은 `유닛프레임 > 플레이어 > 기본`으로 표시합니다.

미니맵 자유 드래그·36px 트레이·채팅창 앞 표시·계정 KHQOLMapDB·파티/10·20·40인 공유 프로필은 유지합니다. KH_map 호환 폴더와 감사에서 확인한 미사용 파일 4개·과거 기록 9개는 전체 설치 ZIP에서 제외했습니다. 변경 이력은 이번 버전만 동봉합니다.

## 설치

이전 파일까지 정리하려면 게임 종료 후 기존 KHQOL 및 KHQOL_* 애드온 폴더를 AddOns 밖에 백업하고, ZIP의 19개 폴더를 새로 넣습니다. 기존 KH_map도 AddOns 밖으로 옮깁니다. WTF는 그대로 둡니다. 기존 KHQOLMapDB 설정을 사용하며 이전 설정(호환) 항목은 이번 구성에 없습니다. 자세한 절차는 [설치 안내](INSTALL-GUIDE.md)를 따릅니다.

공통 기반 1개 + 선택 기능 18개, 총 **19개 폴더 / 268개 파일 / Lua 191개 / 고유 저장 변수 11개**입니다.
