# KHQOL 1.11.8.12 변경·검증 보고서

## 기준·결과

- 기준: 실제 **KHQOL-1.11.8.11-Full.zip**, TOC 19개에서 버전 1.11.8.11과 Interface 16001 확인.
- 기준 SHA-256: `a9df8bd44a794419a190143fd830dbc6ce97a13e8a6e9e6268369455a89e6c71`.
- 결과: **1.11.8.12**. 별도 버전 지정이 없어 다음 패치 번호를 사용했습니다.
- 원본 ZIP·기존 결과물·읽기 전용 sources를 보존하고 작업 사본에서 수정했습니다. Git commit/push와 실제 게임 설치 폴더 변경은 하지 않았습니다.
- 대상: Forever **1.60.1 / 빌드 70938 / Interface 16001**. 실제 게임 프로세스가 없어 실기 실행 빌드는 없습니다. 모든 실제 클라이언트 항목은 **인게임 미검증**입니다.

## 핵심: 근접·원거리 스킬의 유효 거리

사용 목적은 근접 딜러의 근접 스킬과 주로 사용하는 원거리 스킬의 최대 사거리 및 대상의 사거리 진입 여부를 명확하게 확인하는 것입니다. 숫자 구간과 함께 아래에 다음 정보를 표시합니다.

`근접 최대 5yd · 안 / 원거리 최대 30yd · 밖`

실제 표시에는 안(초록)·밖(빨강)·미확인(중립)을 각각 적용합니다. 대상과 마우스오버는 각 유닛 토큰으로 따로 검사합니다.

- **등록한 근접/원거리 ID를 각각 사용**합니다. 모든 학습 주문 중 하나가 성공했다는 이유로 주 스킬이 사거리 안이라고 표시하지 않습니다.
- 최대 사거리는 `C_Spell.GetSpellInfo().maxRange`, 구형 정보 API 호환 경로의 공개 값입니다. 소수 최대값은 정수 상한 앞에 ~를 붙입니다. 반환값이 없거나 0이면 최대 미확인입니다.
- 안/밖은 기존 `Range:CheckReferenceSpell`의 `C_Spell.IsSpellInRange`, 스킬북/구형/등록된 액션 슬롯 호환 경로를 사용합니다. nil·제한 값·미등록·습득하지 않은 주문은 미확인입니다. 0 사거리의 다음 공격형 주문도 유효 근접 거리로 오해하지 않도록 미확인으로 표시합니다.
- 이 상태는 자원·재사용 대기시간·시야를 포함하는 **시전 가능 여부가 아닙니다**. 최소 사거리가 있는 스킬의 ‘밖’에는 너무 가까운 상태도 포함됩니다. ‘밖’을 무조건 최대 사거리 초과로 해석하지 않습니다.
- 스킬 최대값은 **API 원래 단위 yd**로 명시합니다. 숫자 거리의 m/yd 환산은 이전 요구대로 1yd=0.9144m입니다. 예를 들어 API 최대 30yd는 약 27.432m입니다. 숫자 추정 구간과 스킬 최대 숫자의 단위 차이를 혼동하지 않도록 안내합니다. 숫자 단위 미표시는 숫자 줄의 접미사만 제거하며 스킬 줄의 원래 단위는 유지합니다.
- 실제 대상의 크기·도달 거리·특성 등 조건에서 API의 최대 정보와 사거리 검사 결과가 어떻게 제공되는지는 클라이언트에서 확인해야 합니다. 숫자 추정치를 주 스킬의 확정 경계로 간주하거나 30으로 강제 자르지 않습니다.

## 정수 설정과 정렬

거리 색상 구간은 0~200의 정수만 입력합니다. 소수·잘못된 입력·역전된 최소/최대는 이전 값을 유지하며 안내합니다. 구형 소수 설정은 현재 단위에서 가장 가까운 정수로 맞추고 **실제 판정 값도 화면과 같게** 저장합니다. 예: 기존 4.57m → 5m, 27.43m → 27m. 원거리 최대를 30으로 직접 지정하면 실제 설정도 정확히 30입니다.

단위 변경 시 색상 구간과 표시 상한을 새 단위의 정수로 반올림합니다. 이 때문에 기존의 정확한 물리적 상한에서 최대 약 반 단위 정도 달라질 수 있습니다. 표시 상한은 m 50~100 / yd 55~109, 1단위 조절입니다. 숨은 소수 값으로 판단하지 않습니다. 내부 API 비교는 계속 yd를 사용합니다.

각 행을 최소·구분 기호·최대·색상 버튼의 공통 열로 배치했습니다. 근접 최대, 데드존 최대, 원거리 최대는 같은 X에 놓이고 색상 버튼은 중립 행까지 같은 X를 사용합니다. 480px/680px 설정 폭에서 정렬과 우측 경계 검사를 통과했습니다.

## 숫자 구간과 단일 값

사용자가 제안한 27~30 / 31~34 방식으로 원거리 최대에 맞춰 구간을 나눕니다. 기본 간격은 **4**, 설정 범위는 정수 **1~10**입니다. 최대 30일 때 구간은 …23~26 / 27~30 / 31~34… 입니다.

| 실제 제공 정보 | 범위 형식 | 단일 형식, 실측 불가 |
| --- | --- | --- |
| 27~30 | 27~30 | ~30 |
| 31~34 | 31~34 | ~34 |
| 28~33 | 27~34 · 30 경계 | ~34 · 30 경계 |

여러 구간에 걸친 결과는 해당 구간을 합쳐서 원래 측정을 모두 포함합니다. 작은 한 구간에 임의로 넣지 않습니다. 28~33을 27~30이나 31~34로 축소하면 30 안/밖의 잘못된 확신을 줄 수 있기 때문입니다. 정수화는 바깥쪽 반올림으로 하며 근접 안으로 확인된 결과는 설정한 근접 최대 이내에서 표시합니다.

유효한 공개 실측값이 있으면 두 형식 모두 이를 사용할 수 있습니다. 단일 형식은 실제 숫자 하나, 범위 형식은 해당 실측값을 포함하는 구간을 사용합니다. 실측 30.1을 정수 30으로 표시할 때는 `30 · 30+`로 경계 밖이라는 정보를 유지합니다. 기존 ‘이하’는 사용하지 않습니다.

색상과 표시 상한은 확장된 표시 구간이 아니라 원래 측정으로 판단합니다. 원거리 최대에 걸쳐 안/밖이 불명확하면 경계 안내를 붙입니다. 50m 상한에 실제 60m이거나 범위 40~60m이면 숨기고 정확히 50m이면 표시합니다. 시각 구간 확장으로 끝 숫자가 표시 상한보다 커질 수 있으나, 그 숫자를 실제 거리로 확정한 것은 아닙니다.

이번 요청과 구간 제안에 따라, 원거리 최대를 넘은 모든 결과를 기존 50+ 같은 표시 상한 라벨로 합치던 동작을 **확인 가능한 거리 구간 표시**로 변경했습니다. 예를 들어 원거리 최대 30·표시 상한 50에서 확인된 31~34는 31~34로 표시합니다. 표시 상한은 별도로 숨김에 사용합니다.

## 활·총·석궁 데드존

직업 이름 조건을 장비 조건으로 확장했습니다. 현재 장착 슬롯 18(클래식 원거리)과 16(주장비)에서 아이템 메타데이터를 확인하며, classID 2의 활 2·총 3·석궁 18만 적용합니다. 가방에만 있는 무기, 지팡이·마법봉·투척 무기는 포함하지 않습니다. 제한·미로딩 데이터로 자격을 확정하지 않습니다. 필요하면 아이템 데이터 로딩을 요청합니다.

- 숫자 데드존 색상은 장비 자격, 공격 가능한 대상, 설정 데드존 안에 완전히 포함된 원래 측정, 근접·원거리 검사 모두 false를 확인합니다. 하나라도 판정 불가이면 데드존을 확정하지 않습니다.
- 다른 직업의 근접은 등록한 근접 스킬을 검사합니다. 사냥꾼의 랩터/날개 절단·5yd 보조 경로는 기존대로 유지합니다.
- 스킬 유효 거리와 마우스오버 텍스트에도 같은 장비 조건을 사용합니다. 두 스킬이 실패했을 때 기존 보수적 근거리 확인을 거쳐 데드존과 먼 거리를 구분합니다.
- 메뉴는 **원거리 무기 판정**, 색상 행은 **원거리 무기 데드존**입니다. 장비 교체 시 표시·설정 활성화를 갱신합니다. ‘데드존 감지 사용’ OFF는 숫자 데드존 색상도 끕니다.
- 저장 키 `hunterMeleeAsAttack` 등은 호환성을 위해 유지합니다. 무기 장착 자체가 공격 스킬 습득을 의미하지 않으며, 관련 스킬을 등록해야 합니다.

## 설정 구조와 저장

- 표시 방식 **기존 스킬 판정 → 스킬 유효 거리**. 내부 값 skills/distance는 유지합니다.
- 대상 거리 모드에서는 기준 주문 입력·적용·스킬북 등록 버튼과 공통 등록 함수를 비활성화합니다. 기존 등록값은 보존하고 스킬 판정에 사용합니다. 변경하려면 스킬 유효 거리 모드로 전환합니다.
- 지원하지 않는 마우스오버 위치 편집 버튼·검색 항목·편집 핸들을 제거했습니다. 툴팁 아래/왼쪽/커서 옆 및 기존 X/Y 보정·초기화는 유지합니다.
- 고정 대상 위치 편집은 기존 엔진을 사용합니다. 스킬 정보 줄을 포함하도록 대상 프레임과 위치 예시의 영역 크기를 조정했습니다.
- 신규 SavedVariables 선언은 없습니다. 기존 `FRangeDB.distance`에 `bucketSize=4`만 보충합니다. 정수 구간, 표시 형식·단위·좌표는 기존 프로필 저장/전환을 사용합니다. 기준 주문은 종전 캐릭터 소유 정책을 유지합니다.
- 반복 갱신기를 추가하지 않았습니다. 거리·스킬 정보는 기존 약 0.08초 검사에서 갱신하고 커서는 매 프레임 따라갑니다. 모듈 OFF 시 두 표시와 반복 검사를 중단합니다. 같은 글자/정보의 반복 쓰기와 불필요한 배치를 피합니다.

## 인게임 검증과 재현

다음 항목은 모두 **인게임 미검증 / LIMITED GO**입니다. 모의 검사는 실제 사거리 제한·클라이언트의 maxRange 수정값·장비 슬롯 제공·스킬별 API 결과·게임 글꼴 렌더링을 보증하지 않습니다.

1. 스킬 유효 거리에서 직접 대상 사거리가 있는 주 근접·원거리 스킬을 등록합니다. 대상 거리로 전환해 등록값 보존과 입력 비활성화를 확인합니다.
