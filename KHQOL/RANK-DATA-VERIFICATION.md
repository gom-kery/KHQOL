## 지도·책·퀘스트 의미

- source UI map labels는 49개이며 모든 숫자를 클라이언트 ID로 무조건 허용하지 않습니다. C_Map.GetMapInfo의 mapID, 동일 한글 이름, Zone/City 종류를 확인합니다. 다른 언어/변경된 지도/이름 불일치/접근 불가는 등록하지 않습니다. 월드/대륙/던전/모호한 지역으로 대체하지 않습니다.
- 234명 중 233명은 원문 좌표와 지도 label이 있고, 울다만 안노라 1명은 PARTIAL입니다. 이는 source 상태이며 실제 NPC에 도착했음을 뜻하지 않습니다.
- 백분율 X/Y는 등록 때 각각 100으로 나눕니다. 노트의 기존 구조화된 API를 사용하므로 쉼표 좌표 파서와 무관합니다.
- 책: 요리 고급 요리책(얼라이언스 샨드리나/호드 울란), 응급치료 고급 응급치료서(데네브 워커/발라이 로크웨인), 낚시 고급 낚시정보(공통 노인 헤밍). 원문 책 가격을 교관 교육 비용과 구별합니다.
- 전문 요리 조개 별미, 진영별 응급 치료, 낚시의 달인 내트 페이글 경로를 보존합니다. 낚시는 호드 교관 카툼과 공통 퀘스트를 모두 유지하며 1금은 교관 비용입니다.
- 단계명 숙련/전문과 책 이름의 고급을 혼동하지 않습니다. 알려지지 않은 레벨/선행 조건/책 소지 여부는 UNKNOWN이며 무료·조건 없음으로 안내하지 않습니다. 완료 플래그는 공개 C_QuestLog 값이 있을 때 별도로 표시합니다.
- 근거리/최단 경로/상인 재고/접근 안전을 판정하지 않습니다. 원문에서 해당 단계를 제공하는 같은 진영/공통 후보를 안정된 순서로 제시합니다.

## 출처·사용 범위

이 표와 애드온 데이터는 사용자 제공 문서와 WOWF의 게임 사실 정보를 대조해 작성했습니다. WOWF는 비공식 팬 사이트이며 게임 데이터 권리는 Blizzard에 있습니다. 출처와 확인일을 남기며 별도 오픈 라이선스나 Blizzard의 보증을 주장하지 않습니다. 원문 HTML·지도 이미지·Blizzard UI 구현 전체는 배포 ZIP에 복제하지 않았습니다. Beta 정보 변경 가능성과 실제 게임 미검증 상태를 구분합니다.
