# KHQOL 1.11.9.2 — 사거리·환경 HUD 결과

작성일2026-11-20. 기준: 실제 최신1.11.9.1 Full(430개 파일). 결과: KHQOL1.11.9.2 / DevTools0.3.8 / catalog10 / schema1·protocol1. 이전 결과와 sources/는 변경하지 않았다.

## 핵심 지원 범위

**모든 대상의 5야드 구간 측정을 실제1단위로 전환하는 방법은 확인하지 못했다. 이 항목을 완전히 해결했다고 보고하지 않는다.** 공개 정확한 거리 값이 있는 대상은1단위 정수 표시를 지원한다. 새 `정확한 거리만 · 1단위`는 지원되는 정확한 값만 사용하고 미지원 대상은 -로 표시한다. 자동 모드는 기존 추정 구간을 사용한다. 실제 NPC에서 정확한 API가 반환되는지는 인게임 NOT TESTED다.

그 외 정수 입력/표시, 최대 표시 거리45~80·5단위, 초과 상한+ 및 최대 거리 색상, 보호막 HUD 좌우/전투 표시, 개별 텍스트 좌표·색상·핸들·초기화를 구현했다.

## 사용 방법

인터페이스 → 사거리 측정 → 대상 거리에서 측정 방식을 선택한다. 정확한 거리만을 선택하면 단일 값·간격1을 설정한다. 값이 -이면 해당 대상의 정확한 거리 API를 읽지 못한 상태다. 자동 모드의 ~는 구간 상한이며 정확한 측정값이 아니다. `미표시` 단위는 접미사만 숨기고 마지막 m/yd 기준을 유지한다.

최대 표시 거리를45~80에서 고른다. 기존 범위 밖 상한은 새 범위에 맞추고5단위로 정규화한다. m/yd 전환은 기존 물리 단위 변환 후 새 범위·5단위를 적용한다. 사용자 구간의 기존 경계·이름·배치는 보존한다. 옛4.68/21.87 값은5/22로 표시하지만 편집하지 않으면 내부 정밀도를 유지한다. 실제 새 입력은 정수다.

바 설정 → 환경 타이머에서 HUD형을 선택하고 보호막 연동을 켠다(보호막 연동 자체는 여전히 기본OFF). 보호막 HUD 방향과 전투 중 보호막 표시를 선택한다. 개별 흡수량은 지원하지 않고 이전처럼 첫 보호막에 전체 흡수 합계를 한 번 표시한다. 합계 미확인은 -이다.

위치 잠금을 풀면 그룹과 개별 텍스트 이동 테두리가 나타난다. 텍스트 섹션에서 편집할 텍스트를 고르고 X/Y·색상을 바꿀 수도 있다. 색상을 고르면 고정 색상, 선택 텍스트 초기화는 선택한 텍스트의 위치/색상을 기본·상태색으로 되돌린다. 색상 취소는 원래의 고정색 여부까지 복원한다. 좌표·색상은 프로필/리로드에 보존한다. 전투 중에는 편집할 수 없고 공개 실제 HUD만 표시한다.

## 조사 근거·제한

[Forever Unit API 추출 자료](https://raw.githubusercontent.com/Atraeau/WoW-Addons/main/docs/api/Units-Combat-PvP/Unit.md)는 UnitDistanceSquared의 checkedDistance 및 UnitPosition 좌표를 제공한다. 임의 거리1단위 검사 인자는 확인되지 않았다. ClosestUnitPosition은 선택 대상과 같은 NPC라는 보장이 없는 최근접 creatureID 함수여서 채택하지 않았다. 공개 API 자료와 현재 화면의 구간 추정 상태로 볼 때 일반 NPC의 정밀 측정은 지원이 제한될 수 있다는 판단이며, 모든 대상에서 불가능하다고 실측한 결론은 아니다.

[Forever C_UnitAuras 추출 자료](https://raw.githubusercontent.com/Atraeau/WoW-Addons/main/docs/api/Spells-Auras-Talents/C_UnitAuras.md)의 GetAuraDataBySpellName(unit,spellName,filter)을 이용한다. 공개된 이름/실제 랭크 ID/시간만 사용한다. API가 존재하지 않으면 기존 Read, 이름 조회 자체가 실패하면 UNKNOWN이다. 비공개 오라 우회·과거 타이머를 현재값으로 위장하는 처리는 하지 않는다. 두 자료의 추출 빌드는70790이며 사용자70959의 실동작 보증은 아니다.

카탈로그10은 이전 고정 등록1,716행을 보존하고 설정7개만 추가했다. 편집 대상 선택은 보기 상태이고 통계 설정값이 아니다. 최대 거리의 기존 setting.range.control008/009를 새 제목에서도 사용한다. 위치 잠금은 설정 변경, 반복 Refresh/렌더는 새 조회/변경으로 집계하지 않는다. 기존 로그·기본OFF 기록·schema/protocol을 유지하며 수치/좌표/색상을 수집하지 않는다.
