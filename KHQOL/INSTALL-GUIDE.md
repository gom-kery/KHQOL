# KHQOL 1.11.2 설치·프로필 이전 안내

2026-10-17. 기준 KHQOL 1.11.1.2 Full과 KH_map 1.0.0입니다. 이 개발 작업에서는 실제 게임 폴더나 WTF 파일을 수정하지 않았습니다.

## 업데이트

1. 게임을 완전히 종료합니다. 기존 AddOns와 WTF의 사본을 AddOns 밖에 보관합니다.
2. `KHQOL-1.11.2-Full.zip`을 임시 폴더에 풉니다.
3. ZIP 안의 `KHQOL`, 사용 중인 `KHQOL_*`, `KH_map`을 `Interface/AddOns`에 덮어씁니다. 전체 설치는 19개 폴더입니다. 부분 설치는 기반과 원하는 기능만 설치합니다.
4. **기존 폴더를 먼저 삭제할 필요는 없습니다.** 같은 경로의 파일을 이번 파일로 교체합니다. ZIP 이름의 폴더를 AddOns 아래에 통째로 넣지 않습니다.
5. 게임 애드온 목록에서 KHQOL과 기능들을 켭니다. 미니맵 항목은 `KHQOL | 미니맵 · 버튼 정리`이며 폴더명은 계속 `KH_map`입니다. 19개 항목 모두 기존 KHQOL 미니맵 그림을 목록 아이콘으로 사용합니다.
6. `/kh` → 인터페이스 바로 아래 **미니맵**에서 두 탭을 확인합니다. `/khmap`, 비어 있으면 `/kh_map`·`/khminimap`도 공통 설정창으로 연결됩니다.

기존 KH_map 1.0.0 설치자는 같은 KH_map 폴더를 이번 것으로 덮어씁니다. `WTF/Account/<계정>/SavedVariables/KH_map.lua`와 내부 변수 `KHminimapDB`는 그대로 유지합니다. **KH_map 폴더 이름 변경, 저장 파일 이동·삭제, 별도 구버전 동시 설치가 필요하지 않습니다.**

## A와 B의 파티·공격대 프로필 공유

1. 기존 설정이 있는 **A 캐릭터에 먼저 접속**합니다. KHQOL과 KHQOL_PartyFrames를 활성화해야 합니다. 모듈의 사용 토글이 OFF여도 목록 이전은 진행합니다.
2. `/kh` → 파티·공격대 → 프로필에서 기존 프로필과 파티·10·20·40인 배치를 확인합니다.
3. A 캐릭터에서 **정상 로그아웃**해 계정 데이터를 저장한 뒤 B 캐릭터로 접속합니다.
4. 같은 프로필 목록에서 A가 쓰던 프로필을 선택합니다. B에서 그 공용 프로필을 수정하면 A가 다시 접속할 때도 반영됩니다. 캐릭터마다 다른 배치를 원하면 공용 목록에서 프로필을 복사한 뒤 각각 선택합니다.
5. 이미 다른 설정을 쓰던 B의 옛 프로필도 합칩니다. 같은 이름·같은 설정은 합치고 다른 설정은 `프로필명 (캐릭터명-서버)` 형태로 구분합니다. 24자 한도에 맞게 이름 일부를 줄이고 이미 쓰는 이름이면 번호를 붙입니다.
6. 기존 프로필을 가진 다른 캐릭터도 각각 한 번씩 접속합니다. **현재 접속하지 않은 캐릭터의 저장 파일은 게임이 이 애드온에 로드하지 않으므로, 그 캐릭터의 이전은 접속할 때 이루어집니다.**

프로필 목록·공통 표시·파티·10·20·40인 배치는 계정 공용입니다. 사용할 프로필과 역할 자동 선택, 휠 사용·업/다운 주문은 캐릭터별입니다. 이전에 자동 역할 선택을 쓰던 캐릭터는 이름 충돌로 별도 보존된 자신의 역할 프로필을 계속 사용합니다. 정식 `탱커/딜러/힐러` 프로필을 직접 선택하면 해당 역할 연결을 공용 정식 이름으로 바꿀 수 있습니다.

같은 공용 프로필의 **편집·초기화·삭제는 다른 캐릭터에도 반영**됩니다. 삭제된 프로필을 선택했던 다른 캐릭터는 다음 접속 시 기본 프로필을 사용합니다. 옛 원본에서 이미 삭제한 공용 프로필이 반복 생성되지는 않습니다.

## 저장·선택 설치·복귀

- 계정 파티 프로필: KHQOL의 기존 계정 저장 파일 안 `KHQOLDB.globalData.partyFrameProfiles`. 기존 캐릭터 저장 파일의 프로필 원본은 남겨 둡니다. 새 저장 파일을 수동 작성하거나 복사하지 않습니다.
- 미니맵: 기존 `KHminimapDB` 계정 공용. 모듈 사용 토글은 KHQOL 전체 프로필에 저장하지만, 지도·버튼 설정과 위치는 전체 프로필을 바꿔도 유지됩니다.
- 파티만 사용: `KHQOL` + `KHQOL_PartyFrames`. 미니맵만 사용: `KHQOL` + `KH_map`. 기본/개인 유닛프레임과 사거리 애드온은 필수 기능 의존성이 아닙니다.
- 기능을 뺄 때는 사용을 OFF하고 전투 종료 후 복원을 확인한 다음 게임을 종료해 해당 폴더를 AddOns 밖에 보관합니다. 공용 파티 프로필과 기존 저장 파일은 유지됩니다.
- 이전 버전으로 복귀하려면 게임 종료 후 1.11.1.2와 필요 시 KH_map 1.0.0 설치 폴더를 복원합니다. 캐릭터별 옛 파티 원본을 읽을 수 있지만 1.11.2의 추가 공용 편집은 옛 원본에 역복사하지 않습니다. 완전한 시점 복구는 업데이트 전 WTF 백업을 사용합니다.

## 인게임 확인

미니맵 모양·크기·드래그·주변 아이콘, 버튼 보관/제외/클릭, 모듈 OFF와 편집 모드 복원, 전투 중 변경 보류를 확인합니다. 파티 프로필은 A→B→A 순서로 파티·10·20·40인 값과 재접속 유지, 이름 충돌, 역할 선택, 서로 다른 휠 주문을 확인합니다. 실제 게임 검증은 이 패키지를 만든 환경에서 수행하지 않았습니다.
