# KHQOL 1.11.4.6 설치·사용 안내

기준 1.11.4.5 · 전체 설치 ZIP: **`KHQOL-1.11.4.6-탭설명-토템위치편집.zip`**.

## 설치

1. 게임을 완전히 종료합니다.
2. AddOns의 기존 `KHQOL`과 `KHQOL_*` 코드 폴더를 AddOns 밖에 백업합니다. 남아 있는 옛 `KH_map` 코드 폴더도 밖으로 옮깁니다.
3. ZIP 안의 19개 폴더를 `Interface/AddOns` 바로 아래에 넣습니다. 다른 애드온은 유지합니다.
4. **WTF 폴더와 SavedVariables 파일은 삭제·이동·이름 변경하지 않습니다.** 기존 전체/파티 프로필·노트·등록 목록·KHQOLMapDB를 유지합니다. 설정 초기화는 필요하지 않습니다.
5. `KHQOL`과 사용할 기능을 켭니다. 미니맵은 `KHQOL` + `KHQOL_Map`을 사용합니다.

이번 ZIP에는 KH_map 호환 폴더가 없으며 함께 활성화할 필요가 없습니다. 덮어쓰기만 하면 옛 불필요 파일이 남을 수 있으므로 코드 폴더를 교체합니다. `KHQOL/Bindings.xml`은 기본 자동 로더용 빈 호환 파일이며 유지합니다.

## 토템만 이동

1. 설정 → 유닛프레임 → 플레이어 → **토템 프레임**으로 이동합니다. 간결한 프레임 사용이 켜져 있어야 합니다.
2. **프레임 위치 확인**을 ON으로 켭니다. 기본값은 OFF입니다.
3. 화면에 나타난 토템 테두리를 왼쪽 버튼으로 끌어 이동합니다. 전체 편집 모드에 진입하지 않으며 토템만 이동합니다. 실제 토템이 없으면 예시 테두리를 사용합니다.
4. **프레임 X 좌표 / 프레임 Y 좌표**는 -3000~3000px입니다. X는 오른쪽, Y는 위쪽이 +입니다. **프레임 확장 방향**은 왼쪽 또는 오른쪽을 선택합니다.
5. 확인을 OFF로 끄면 테두리가 사라지고 정한 위치는 유지합니다. 전투 시작·메뉴 이동·창 닫기·프로필 변경 시 확인 모드가 종료됩니다.

좌표와 방향은 현재 전체 프로필에 저장되며 복사·가져오기에 포함됩니다. 기존 X/Y 저장값은 유지합니다. 이번에 위치 기준을 일시적인 프레임 측정값에서 고정 배치로 변경했으므로 원하는 최종 위치는 전용 테두리에서 조절할 수 있습니다. **토템 위치 초기화**는 X/Y·확장 방향·직접 배치를 초기화하고 기본 게임 배치로 복원합니다.

## 탭 설명

2·3단계 탭 아래의 공통 프로필 문구를 해당 기능의 짧은 설명으로 바꿨습니다. 유닛/부품, 대상 버프 유형과 플레이어/대상 시전바를 전환하면 설명도 바뀝니다. 모듈 OFF·전투 중 변경 보류·적용 실패 안내와 저장 범위 툴팁은 유지합니다.

## 실제 게임 확인

- 재접속 직후 리로드 전에 토템 프레임 위치를 확인합니다. 토템 없는 상태 → 전투 중 첫 소환 → 전투 종료 → 2개 중 1개 만료 → 전체 만료/재소환 순서로 첫 아이콘 위치를 비교합니다.
- 토템 전용 테두리 드래그, 좌우 확장, X/Y 범위, 창 닫기/전투 시 종료, 프로필 변경·재접속 후 저장과 초기화를 확인합니다.
- 하위 탭의 설명이 탭 전환·새로고침·재진입 후 맞게 유지되는지 확인합니다.

자동·모의 검사 **599/599 PASS**. Lua 193개 문법 검사와 XML 5개 파싱을 통과했습니다. 실제 클라이언트의 전투 보호/taint·화면·파일 저장·성능은 **IN-GAME REQUIRED**입니다. 개발 중 실제 AddOns/WTF와 이전 배포 ZIP은 변경하지 않았습니다.
