# KHQOL 1.11.4.13 설치·사용 안내

전체 설치 ZIP: **`KHQOL-1.11.4.13-전투종료최적화-기본일괄판매.zip`** · 기준 1.11.4.12.

## 설치

1. 게임을 완전히 종료합니다.
2. 기존 `KHQOL`·`KHQOL_*` 코드 폴더를 AddOns 밖에 백업하고 새 코드로 교체합니다. 옛 `KH_map` 코드 폴더가 남아 있으면 밖으로 옮깁니다.
3. ZIP의 19개 폴더를 `Interface/AddOns` 바로 아래에 넣습니다. 다른 애드온은 유지합니다.
4. **WTF·SavedVariables는 삭제·이동·이름 변경하지 않습니다.** 프로필·노트·등록 목록·KHQOLMapDB를 유지합니다.
5. `KHQOL`과 사용할 기능을 켭니다. 미니맵은 `KHQOL_Map`으로 제공하며 KH_map 호환 폴더는 필요하지 않습니다.

빈 `KHQOL/Bindings.xml`은 기본 로더용 호환 파일이므로 유지합니다.

## 이번 변경과 게임 재확인

1. 설정창을 닫고 여러 차례 전투를 시작·종료하여 순간 끊김이 줄었는지 확인합니다. 실제 배치 변경이 없으면 파티 전체 배치를 다시 적용하지 않습니다. 유닛 체력/글자·토템·포만감 등 전투 후 표시 복원은 유지합니다.
2. 전투 중 변경한 설정과 모듈 OFF는 종료 후 최신 값으로 한 번 적용되는지 확인합니다. 파티 역할 프로필·공격대 규모 변경도 확인합니다.
3. 토템 X/Y·확장 방향, 전체 유닛 위치와 체력 표시가 전투 전후 동일한지 확인합니다.
4. **잡템 자동 판매 ON**에서 상점을 열어 기본 일괄 판매와 자동 수리를 확인합니다. 사용 중인 클라이언트가 기본 기능을 지원하지 않으면 기존 개별 판매를 사용합니다. 옵션을 추가로 켤 필요는 없습니다.

자동·모의 **781/781 PASS**. 실제 Forever에서 새 버전을 실행하지 않았습니다. 실제 순간 끊김·FPS·보호 API/taint·재접속·파일 저장·메모리는 **IN-GAME REQUIRED**입니다. 호출 수 개선은 실제 FPS 개선율이 아닙니다.

## 직업 보조 표시

**유닛 프레임 → 플레이어 → 직업 보조 표시**에서 탄약, 영혼의 조각, 보조 표시 위치, 토템·임시 소환 위치를 설정합니다. 이전 ‘토템 프레임’ 탭의 이름을 바꿨으며 탄약·영혼의 조각 설정은 자원/스윙바에서 옮겼습니다. 저장값과 위치는 유지됩니다.

- 해당 직업에서 탄약·영혼의 조각 표시를 ON/OFF합니다. 영혼의 조각 문구 OFF는 아이콘과 숫자만 표시합니다.
- **보조 표시 위치 잠금 ON · 비전투**에서 아이콘 좌클릭당 최대 수량을 넘는 조각 **1개**를 확인창 없이 파괴합니다. 숫자 우클릭은 최대 보관 수량 입력입니다. 위치 잠금 OFF·위치 편집 중에는 두 클릭 기능을 차단합니다.
- 최대 수량은 일반·영혼 가방의 전체 칸 수 이내입니다. 이벤트에 의한 자동 파기는 하지 않습니다.
- 위치 잠금 OFF에서 탄약/조각 표시를 드래그합니다. 같은 페이지에 위치 초기화·X/Y·글자 크기가 있습니다. 토템의 위치 확인·좌표·좌우 확장 기능도 유지됩니다.
- 자원바 모듈 초기화는 옮겨진 값을 유지하고, 유닛 프레임 모듈 초기화는 보조 표시도 기본값으로 돌립니다.

## 체력·자원 수치 위치

**유닛 프레임 → 플레이어 또는 대상 → 체력·자원**에서 간결한 프레임의 체력과 자원 수치를 각각 설정합니다.

정렬은 **중앙(기본) / 왼쪽 / 오른쪽**, X/Y는 기본 **0/0**, 범위는 선택한 정렬 기준 **-50~+50 UI px**입니다. 선택 즉시 위치가 바뀝니다. 기존 범위 밖 값은 가장 가까운 경계값으로 조정합니다. 오른쪽 X·위쪽 Y가 양수입니다. 현재 프로필에 저장되며 위치 편집용 모양에도 반영됩니다. 수치 형식·숨김과 자원바 OFF 조건은 유지됩니다. 소환수·대상의 대상·주시대상에는 새 수치 위치 옵션을 추가하지 않았습니다.

## 자동판매

**편의 기능 → 일반 편의 → 아이템 → 잡템 자동 판매**의 기존 ON/OFF를 사용합니다. 지원되는 클라이언트에서는 상점을 열 때 **기본 UI 일괄 판매**를 한 번 요청합니다. 판매 대상은 기본 게임의 잡템 판정에 따릅니다. 완료를 확인한 뒤 자동 수리 설정을 적용합니다.

기본 판매 기능/API가 미지원이면 기존의 확인 기반 개별 판매를 사용합니다. 일괄 판매를 이미 요청했다면 오류/응답 지연이 있어도 개별 큐로 바꾸거나 다시 판매하지 않습니다. 상점 닫기·옵션 OFF에서 애드온의 후속 작업을 중단합니다. 실제 처리 속도는 클라이언트·서버 응답에 따라 달라집니다. [기본 판매 API](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/MerchantFrameDocumentation.lua).

## 파티·공격대 디버프 제외

**파티·공격대 → 버프·디버프 → 디버프 필터**에서 주문 ID를 입력하고 **제외 목록에 추가**를 누릅니다. 등록된 제외 주문을 선택한 뒤 **선택한 주문 삭제**로 되돌립니다. 기본 목록은 비어 있으며 중복·잘못된 숫자는 등록하지 않습니다.

**게임이 보호하는 디버프는 ID로 제외할 수 없습니다.** 공개된 주문에만 적용되며 등록 목록에서 ‘제외 가능’ / ‘게임 보호 · 제외 불가’ / ‘게임 판정에 따름’을 안내합니다. 목록에 등록되어도 게임 보호 주문은 계속 표시됩니다. 클라이언트 API가 없으면 목록을 보존하고 기본 아이콘을 표시합니다.

제외 목록은 **계정 공용 파티·공격대 프레임 프로필**에 저장합니다. 해당 프로필을 공유하는 캐릭터에도 적용됩니다. 기존 정책대로 전체 프로필 문자열 전송에는 파티 프레임 프로필을 포함하지 않습니다. 디버프 체력 색상·보호막에는 영향을 주지 않으며, 고정 예시 미리보기는 실제 주문 ID 제외 결과를 보여주지 않습니다.
