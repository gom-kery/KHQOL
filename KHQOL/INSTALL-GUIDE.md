# KHQOL 1.11.1.0 설치·업그레이드·비활성화·재설치·복귀

2026-10-16. 버전은 1.11.1.0이며 실게임 검증 대기 상태입니다. 게임 설치 폴더나 실제 WTF 파일은 이번 개발 작업에서 수정하지 않았습니다.

## 기존 1.11.0.1에서 1.11.1.0으로 업데이트

1. 게임을 완전히 종료합니다. 사용 중인 KHQOL 설치 폴더와 계정/캐릭터 저장 파일은 AddOns 밖에 사본을 보관합니다.
2. `KHQOL-1.11.1.0-Full.zip`을 임시 폴더에 풉니다.
3. 기존에 설치한 `KHQOL`과 기능 `KHQOL_*` 폴더들을 `Interface/AddOns`에 덮어씁니다. 전체 설치 사용자는 18개 전부를 적용합니다. 부분 설치 사용자는 기존에 사용하던 폴더만 선택합니다.
4. 이번 버전은 상대 경로와 파일 267개가 같으므로 구형 모듈화 폴더나 WTF를 삭제할 필요가 없습니다. 저장 이름·형식·이관 정책도 그대로입니다.
5. 게임을 다시 실행해 애드온 목록의 1.11.1.0, 미니맵 아이콘, 기존 단축키, 선택 프로필과 노트·등록 목록·캐릭터 주문을 확인합니다.

실제 게임 확인은 별도로 제공한 `KHQOL-1.11.1.0-IN-GAME-CHECKLIST.md`를 따릅니다. 새 보고서·시험 코드·시험 데이터·검증 출력물은 이 설치 ZIP에 넣지 않습니다.

## 새 설치 / 전체 설치

게임 종료 → ZIP 풀기 → 최상위 18개 폴더를 `Interface/AddOns` 바로 아래로 복사 → 게임 애드온 목록에서 KHQOL과 기능 항목 켜기 → `/kh` 확인 순서입니다. 폴더명은 바꾸지 않습니다. 이중 상위 폴더를 만들지 않습니다.

## 기존 1.10.10에서 업그레이드

1. 현재 프로필 이름과 주 캐릭터의 파티 역할 프로필·휠 주문을 확인합니다. 전투와 위치 편집을 끝냅니다.
2. 가능하면 오브젝트 강조를 OFF하고 복원 상태를 확인합니다. 게임을 종료합니다.
3. 원본 전체 ZIP과 기존 `Interface/AddOns/KHQOL`을 AddOns 밖에 보관합니다.
4. 계정 `WTF/Account/<계정>/SavedVariables/KHQOL.lua`와 `.lua.bak`, 각 캐릭터 `WTF/Account/<계정>/<서버>/<캐릭터>/SavedVariables/KHQOL.lua`와 `.lua.bak`을 사본으로 보관합니다. 실제 클라이언트의 WTF 위치를 사용합니다.
5. 새 ZIP의 `KHQOL`과 원하는 기능 폴더를 AddOns에 넣습니다. 구형 폴더와 합쳐 오래된 실행 파일을 남기는 설치는 피합니다.
6. 애드온 목록에서 기반과 필요한 기능을 켭니다. 기존 저장 파일의 삭제·내용 수정·이름 변경은 필요하지 않습니다.
7. 로그인 후 일반의 설치 상태, 프로필 이름, 각 기능의 위치, 노트와 등록 목록, 캐릭터 주문과 파티 휠을 확인합니다. `/reload` 후 같은 값이 남는지 확인합니다.
8. 다른 캐릭터로 로그인해 캐릭터별 주문·색·역할 프로필과 휠이 각자 유지되는지 확인합니다. 첫 캐릭터 성공으로 다른 캐릭터까지 확인 완료로 간주하지 않습니다.

## 선택 설치

필수 `KHQOL` + 원하는 `KHQOL_*` 폴더만 둡니다. 기반을 빠뜨리거나 비활성화하면 기능 애드온은 필수 의존성 누락으로 로드되지 않습니다. 기반을 다시 설치·활성화합니다.

- 파티 전용: `KHQOL` + `KHQOL_PartyFrames`.
- 노트/시계 전용: `KHQOL` + `KHQOL_Clock`.
- 툴팁/무기 안내: `KHQOL` + `KHQOL_Tooltip`.
- 개인 프레임/시전바/기본 UI: `KHQOL` + `KHQOL_UnitFrames`.
- 사거리, 자원바, 경험치, 환경 타이머와 각 알림은 해당 폴더를 추가합니다.

설치하지 않은 기능은 메뉴·탭·검색·위치 편집에 나타나지 않습니다. 기존 DB와 프로필 스냅샷은 남습니다. 사용자 모듈 ON/OFF와 게임 애드온 목록의 활성 상태는 서로 다른 항목입니다.

## 비활성화와 제거

기능 사용 OFF → 전투 종료 후 복원 완료 확인 → 게임 종료 → 애드온 목록 비활성 또는 해당 기능 폴더를 AddOns 밖에 보관합니다. 파티 휠과 원래 단축키, Blizzard 기본 프레임 복원을 실제 게임에서 확인합니다. 저장 파일은 유지합니다.

실험실을 바로 제거한 경우에도 기반의 그래픽 복원 서비스가 기존 기록으로 복원을 시도합니다. 복원 보류가 표시되면 충돌 애드온/전투/API 상태를 해소하고 필요하면 실험실을 재설치해 상태를 확인합니다. 기록을 직접 지우거나 WTF 전체 초기화로 해결하지 않습니다. 공통 기반까지 제거하면 복원 코드가 없으므로 제거 전에 복원을 끝내는 것이 좋습니다.

## 재활성·재설치

기반을 유지한 채 같은 버전 기능 폴더를 다시 넣고 목록에서 켠 뒤 UI를 다시 로드합니다. 현재 선택한 프로필의 값이 복원됩니다. 미설치 동안 프로필을 바꿨다면 그 프로필의 저장 설정이 사용됩니다. 모듈 데이터 파일을 따로 찾아 옮길 필요가 없습니다.

## 구형 전체본으로 복귀

게임 종료 → 이번 18개 폴더를 AddOns 밖에 보관 → 원본 1.10.10의 KHQOL 폴더만 복원 → KHQOL 활성 → 같은 저장 파일로 로그인합니다. 새 기능 폴더와 구형 전체본을 동시에 켜지 않습니다.

같은 저장 변수 이름/계정·캐릭터 범위/로더 폴더를 유지했고, 실제 1.10.10 코드를 다시 실행하는 모의 검사에서 프로필·노트·주문·파티 휠을 읽었습니다. 실제 게임 저장 파일 직렬화와 보호 동작의 복귀 검사는 남아 있습니다. 정확한 업그레이드 전 상태가 필요하면 미리 보관한 저장 파일 사본을 복원합니다.
