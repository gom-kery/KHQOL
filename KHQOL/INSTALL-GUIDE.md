# KHQOL 1.11.3 설치·사용 안내

2026-10-18 · 기준 1.11.2.5 Full. 작업 중 실제 게임 AddOns와 WTF를 변경하지 않았습니다.

## 설치

1. 게임을 완전히 종료합니다.
2. AddOns의 기존 `KHQOL`과 `KHQOL_*` 코드 폴더를 **AddOns 밖**에 백업합니다. 예전 `KH_map`이 남아 있다면 함께 밖으로 옮깁니다. 다른 애드온은 그대로 둡니다.
3. `KHQOL-1.11.3-Full.zip`의 19개 폴더를 `Interface/AddOns` 바로 아래에 넣습니다. ZIP 이름의 상위 폴더가 한 겹 더 생기지 않도록 합니다.
4. **WTF 폴더와 SavedVariables 파일은 삭제·이동·이름 변경하지 않습니다.** 기존 전체/파티 프로필과 KHQOLMapDB를 그대로 사용합니다.
5. KHQOL 공통 기반과 사용할 기능을 활성화합니다. 파티·공격대 기능에는 `KHQOL` + `KHQOL_PartyFrames`가 필요합니다.

덮어쓰기만 하면 이전 설치의 불필요 파일은 남습니다. 코드 폴더 교체 방식으로 정리하고 설정 저장소인 WTF는 유지합니다. 이번 ZIP에는 KH_map 호환 폴더가 없으며 함께 활성화할 필요가 없습니다. 미니맵은 KHQOL + KHQOL_Map입니다. 이미 사용 중인 KHQOLMapDB가 우선이며, 옛 저장 파일을 새 이름으로 바꾸지 않습니다.

## 새 설정 위치

`/kh` → **파티·공격대 → 버프·디버프**.

- **디버프 아이콘**: 기존 표시 ON/OFF, 최대 개수·한 줄 개수, 크기·간격, 위치·X·Y. 크기·간격과 X·Y는 두 열이며 창을 좁히면 한 열로 표시합니다.
- **디버프 종류별 체력 색상**: ON/OFF 및 저주·질병·마법·독·출혈의 색·투명도. 각 색의 변경 버튼에서 불투명도를 조절합니다. 불투명도 0은 투명, 100%는 완전한 색상 표시입니다. 기본값 복원 버튼도 있습니다.
- **보호막 흡수량 오버레이**: ON/OFF, 보호막 무늬·흡수 무늬·단색, 색·투명도. 현재 최대 체력에 대한 총 흡수량 비율을 바 오른쪽에서 왼쪽으로 표시하며, 최대 체력보다 큰 흡수량은 전체 바까지 표시합니다.
- **디버프·보호막 미리보기**: 정상과 디버프 5종을 나란히 표시합니다. 예시 보호막 비율은 0~100%로 조절합니다. 예시 비율은 이번 실행의 표시값이며 저장하거나 실제 캐릭터에게 보호막·디버프를 걸지 않습니다. 현재 ON/OFF와 색·텍스처·아이콘 배치를 반영합니다.

색상 변경과 보호막은 기본 ON이며, 디버프 아이콘은 이전 ON/OFF를 그대로 유지합니다. 모듈 자체가 OFF면 실제 프레임에 적용하지 않습니다. 미리보기 비율은 모듈 OFF에서도 바꿀 수 있습니다. 파티·10·20·40인에 공통으로 적용하며, 다른 캐릭터에서는 프로필 탭에서 같은 계정 공용 프레임 프로필을 선택합니다.

전투 중 변경한 실제 프레임 설정은 전투 종료 후 최신값을 적용합니다. 디버프·흡수량 자체의 갱신은 계속됩니다. 여러 디버프가 겹치면 게임 표시기가 선택한 한 종류의 체력 색을 표시합니다. 해제 후에는 직업 색·체력 그라데이션 등 기존 기본 체력 색으로 돌아옵니다. 사망 음영과 이름·수치는 위에 표시합니다.

## 게임에서 확인

1. `/reload` 전에 문제가 있던 캐릭터로 재접속해 플레이어 간결한 프레임과 헤더 표시를 확인합니다. 이 부분은 1.11.2.5 수정을 유지합니다.
2. 새 탭에서 정상·디버프 5종의 기본색, 색·투명도 변경, 색상 기본값 복원을 확인합니다.
3. 보호막 텍스처 3종을 바꾸고 예시 비율 0·25·100%와 ON/OFF를 비교합니다.
4. 파티에서 실제 보호막의 생성·소모·해제와 디버프 종류 변경·해제를 확인합니다. 전투 중 갱신과 전투 종료 후 설정 적용을 확인합니다.
5. 파티/10/20/40인 표시, 대상 선택·메뉴·클릭/휠 동작과 사망/부활·유닛 교체를 확인합니다.
6. 같은 프레임 프로필을 다른 캐릭터에서 선택하고 정상 로그아웃·재접속 후 설정 유지를 확인합니다. 미니맵 자유 배치와 보관함도 확인합니다.

자동·모의 검사 456/456 통과. 실제 수정판의 게임 화면·보호/taint·정상 로그아웃 디스크 저장은 확인 대기입니다. 지원 API가 없으면 해당 기능의 안내를 표시합니다. 복귀가 필요하면 게임 종료 후 보관한 코드 폴더를 복원하고, 저장 설정까지 되돌릴 때는 해당 시점의 WTF 백업을 사용합니다.
