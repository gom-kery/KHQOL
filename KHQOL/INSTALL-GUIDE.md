# KHQOL 1.11.2.5 설치 안내

2026-10-18. 기준 1.11.2.4 Full. 개발 작업에서 실제 AddOns와 WTF를 수정하지 않았습니다.

## 기존 사용자

1. 게임을 완전히 종료합니다.
2. 이전 파일도 정리하려면 AddOns 안의 기존 `KHQOL` 및 `KHQOL_*` 애드온 폴더를 **AddOns 밖**에 백업합니다. 기존 `KH_map`도 밖으로 옮깁니다. 다른 애드온 폴더는 그대로 둡니다.
3. `KHQOL-1.11.2.5-Full.zip`의 19개 폴더를 `Interface/AddOns` 바로 아래에 넣습니다. 상위 ZIP 이름 폴더가 한 겹 더 들어가지 않도록 합니다.
4. **WTF 폴더와 SavedVariables 파일은 삭제·이동·이름 변경하지 않습니다.** 이미 사용 중인 KHQOLMapDB와 전체/파티 프로필을 그대로 읽습니다.
5. KHQOL 공통 기반과 사용할 기능을 활성화하고 문제가 있던 캐릭터로 접속합니다. `/reload` 전에 플레이어 모양·체력 수치·자원·이름·레벨을 확인합니다.
6. `/kh` → 유닛프레임 → 플레이어 → 기본 헤더에 `공격 가능한 NPC`가 붙지 않는지 확인합니다.
7. 미니맵 자유 위치와 모양·수납 목록을 확인하고 정상 로그아웃 후 재접속합니다.

덮어쓰기만 하면 새 ZIP에서 제외한 옛 파일은 디스크에 남습니다. 위의 폴더 교체 방식이 불필요 파일까지 정리합니다. 설정 저장소는 애드온 코드 폴더와 별개이므로 WTF를 유지합니다.

## 부분 설치와 저장

미니맵은 KHQOL + KHQOL_Map, 개인 프레임은 KHQOL + KHQOL_UnitFrames, 파티는 KHQOL + KHQOL_PartyFrames로 동작합니다. 이번 ZIP에는 KH_map 호환 폴더가 없으며 함께 활성화할 필요가 없습니다. KHQOL의 기존 변수 10개와 KHQOL_Map의 계정 변수 KHQOLMapDB 1개가 각각 한 TOC에서 저장됩니다.

이 안내는 1.11.2.4에서 이미 사용 중인 KHQOLMapDB 기준입니다. 옛 단독 KH_map 저장만 남아 있는 설치의 최초 이전은 이번 정리 설치와 구분해야 합니다. 이미 생성된 새 저장소가 항상 우선이며, 옛 파일을 새 이름으로 바꾸지 않습니다.

## 실제 게임 확인 항목

- 재접속 직후 간결한 플레이어 프레임 적용. OFF→ON, 모듈 OFF→ON, 기본 편집 모드 종료 후 복원.
- 체력 감소·회복·사망/부활, 체력 표시 모드 변경, 전투 중 체력 갱신과 전투 종료 후 크기 적용.
- 이름·레벨·자원·테두리·버프 위치, 대상·주시대상·소환수 외형.
- 플레이어/기본 헤더와 대상/버프·디버프의 분류 표시. 검색으로 진입한 뒤 다른 탭 이동.
- 미니맵 자유 위치·수납 클릭과 파티 계정 공용 프로필 유지.

모의 검사 419/419 통과. 수정본 실게임 검증은 대기 중입니다. 문제가 남으면 `/reload` 전 상태와 Lua 오류를 확인합니다. 복귀는 게임 종료 후 보관한 애드온 폴더를 복원하며, 저장 데이터 복귀가 필요할 때는 해당 시점의 WTF 백업을 사용합니다.
