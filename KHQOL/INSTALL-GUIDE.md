# KHQOL 1.11.4.1 설치·사용 안내

2026-10-18 · 기준 1.11.4. 아코디언의 접힘 여백과 메뉴 재진입 후 펼침 겹침을 수정한 버전입니다.

## 설치

1. 게임을 완전히 종료합니다.
2. AddOns의 기존 `KHQOL`과 `KHQOL_*` 코드 폴더를 **AddOns 밖**에 백업합니다. 예전 `KH_map`이 남아 있다면 함께 밖으로 옮깁니다. 다른 애드온은 유지합니다.
3. **`KHQOL-1.11.4.1-아코디언여백-겹침수정.zip`**의 19개 폴더를 `Interface/AddOns` 바로 아래에 넣습니다. ZIP 이름의 상위 폴더가 한 겹 더 생기지 않도록 합니다.
4. **WTF 폴더와 SavedVariables 파일은 삭제·이동·이름 변경하지 않습니다.** 기존 전체/파티 프로필과 KHQOLMapDB를 그대로 사용합니다.
5. KHQOL 공통 기반과 사용할 기능을 활성화합니다. 미니맵은 `KHQOL` + `KHQOL_Map`, 파티·공격대는 `KHQOL` + `KHQOL_PartyFrames`로 사용합니다.

덮어쓰기만 하면 이전 설치의 불필요 파일은 남습니다. 코드 폴더 교체로 정리합니다. 이번 ZIP에는 KH_map 호환 폴더가 없으며 함께 활성화할 필요가 없습니다. 이 파일은 전체 설치용이며 파일명의 마지막 부분은 핵심 변경 요약입니다.

## 전체 설정 배치

`/kh`로 설정을 엽니다.

- **[▼/▶] 섹션명**: 제목 앞 작은 화살표만 클릭합니다. **▼**는 펼침, **▶**는 접힘이며 제목은 일반 글자입니다. 접으면 아래 내용이 빈 공간 없이 올라옵니다.
- 기본 섹션은 처음에 펼쳐집니다. 기존 고급 설정의 기본 접힘은 유지합니다. 탭·메뉴를 오가는 동안 상태를 유지하며 게임 재시작·리로드 후 초기 상태로 돌아갑니다.
- 슬라이더·드롭다운·입력 옵션과 짧은 스위치·색상 항목은 두 열을 사용합니다. 화면이 좁거나 글자가 긴 항목은 한 열로 표시합니다. 목록·편집기·긴 설명·미리보기는 전체 폭을 유지합니다.
- 색 항목은 이름 옆 **[■ 변경]**으로 표시합니다. 지원하는 항목에서는 기존과 같이 투명도를 조절합니다.
- 접기는 화면 표시만 바꿉니다. 기능 ON/OFF나 프로필 설정은 바꾸지 않습니다. 미확정 숫자 입력은 접을 때 취소되므로, 적용하려면 먼저 Enter로 확정합니다.
- 검색 결과를 선택하면 해당 항목이 속한 접힌 섹션을 자동으로 펼칩니다. NPC·발동 버프의 등록 목록을 접었다 다시 펴도 열린 편집 초안이 유지됩니다. 저장·취소 버튼의 기존 동작을 사용합니다.

일반, 유닛프레임, 파티·공격대, 편의 기능, 인터페이스, 미니맵, 바 설정, 알림, 퀘스트, 프로필, 실험실의 모든 탭에 적용했습니다. 실험실 잠금 정책은 같습니다.

## 설치 후 확인

1. 자주 사용하는 메뉴에서 작은 화살표를 눌러 섹션을 접었다 펼칩니다. 슬라이더 숫자와 옵션이 유지되는지 봅니다.
2. 유닛프레임의 플레이어·대상·소환수·대상의 대상·주시대상과 각 부품을 전환하고, 이름·레벨과 상태·징표를 확인합니다.
3. 창 폭을 조절해 두 열/한 열 전환과 긴 글자의 줄바꿈을 확인합니다. 접힌 항목을 검색해 자동으로 펼쳐지는지도 봅니다.
4. 파티·공격대 → 버프·디버프에서 정상과 5종 예시 색, 색·투명도 변경/취소, 보호막 ON/OFF·텍스처·미리보기를 확인합니다. 재접속한 직후 리로드 전에도 예시 색을 비교합니다.

실제 유닛·보호막·오라 표시, 미니맵 자유 드래그, 공용 프로필과 계정 설정은 1.11.4의 구현을 유지합니다. 설정 배치 변경을 위해 초기화할 필요는 없습니다.

자동·모의 검사 504/504 통과. 실제 클라이언트의 화면·보호/taint·재접속 후 표시·정상 로그아웃 저장은 확인 대기입니다. 개발 작업에서 실제 AddOns/WTF와 이전 배포 ZIP은 변경하지 않았습니다.


## 이번 수정 확인

1. 유닛프레임 → 주시대상 → 체력·자원에서 두 섹션을 모두 접습니다. 체력·자원 수치 제목이 프레임 크기·모양 제목 바로 아래로 올라오는지 확인합니다.
2. 주시대상 → 이름·레벨에서 두 섹션을 접고, 다른 왼쪽 메뉴로 이동했다 다시 돌아와 하나씩 펼칩니다. 옵션과 다음 제목이 겹치지 않는지 확인합니다.
3. 플레이어·대상·소환수·대상의 대상의 같은 부품에서도 접기·재진입·펼치기를 반복합니다. 창 폭을 바꾸거나 접힌 항목을 검색한 뒤에도 배치가 맞는지 봅니다.
4. 일반·프로필 화면에서 여러 섹션을 접고 펼쳐 스크롤 끝까지 이동해 봅니다. 마지막 옵션까지 보이고 접은 만큼 스크롤 범위가 줄어드는지 확인합니다.

수정 작업은 공용 설정 배치에 한정했습니다. 실제 유닛프레임 모양·기능이나 프로필을 초기화하지 않아도 됩니다.
