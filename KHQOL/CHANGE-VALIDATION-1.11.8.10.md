## 화면과 설정

- 시계 단축키는 기능별 제목 아래에 **보조 [선택] + 마우스 [선택]**을 배치했습니다. 제목은 달력, 포에버 노트, 타이머·알람·스톱워치, 리로드입니다. 기존 저장된 조합과 기능을 사용합니다.
- 사거리 설정 상단에서 **기존 스킬 판정**과 **대상 거리**를 선택합니다. 기존 설치에는 스킬 판정을 기본 선택으로 추가합니다. 기준 주문과 사냥꾼 옵션, 기호·문구·색상·위치·적 툴팁은 기존 저장 경로를 사용합니다.
- 새 거리 모드의 초기값은 범위, m·단위 표시 ON, 28px, 최대 100m, 고정 위치·잠금 ON, 커서 옆 OFF입니다. 글자는 20~40px, 최대 거리는 50~100m의 실제 값으로 저장합니다. yd 슬라이더의 범위는 이에 대응하는 약 54.7~109.4yd이며 입력값을 가장 가까운 1m 단계로 저장합니다.
- 최대 표시 거리 초과를 실제 값 또는 하한으로 확정하면 숨깁니다. 상한에 걸친 구간과 초과 여부를 확정하지 못한 한쪽 경계는 계속 표시합니다. 범위의 하한은 내림, 상한은 올림하며 색상·표시 상한에는 반올림 전 값을 사용합니다.
- 자신은 `0`, 측정 정보가 없으면 중립색 `—`, 대상이 없으면 숨깁니다. 단일 값은 실제 값을 가장 가까운 정수로 표시합니다. 구간의 한쪽 값이나 중간값을 실측으로 사용하지 않습니다.
- 고정 좌표와 커서 옆 배치는 별도로 관리합니다. 커서 옆 표시는 현재 선택한 `target`의 값이며 기존 `mouseover` 적 툴팁의 스킬 문구와 설정을 따로 둡니다. 커서 배치와 위치 잠금 상태에서는 마우스 입력을 받지 않습니다.

## 측정 경로와 제한

### 실측값

단일 값 모드는 `UnitDistanceSquared(target)`가 공개된 0 이상의 유한수이고 `checkedDistance=true`이면 제곱근을 사용합니다. 이 경로가 없으면 플레이어와 대상의 `UnitPosition` 세 좌표와 맵 식별자를 확인합니다. 같은 맵의 공개된 유한 좌표이며 두 위치가 0·0·0이 아닐 때 3차원 거리로 계산합니다. 조건을 충족하지 못하면 거리 구간 검사로 전환합니다. 실제 목표별 제공 여부는 인게임 미검증입니다. [Forever 거리 API](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/UnitDocumentation.lua#L1043-L1056) · [Forever 좌표 API](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/UnitDocumentation.lua#L2566-L2581)

### 구간과 전투 갱신

- 학습한 유효 주문 목록에서 공개된 `minRange`·`maxRange`와 적·아군 사용 구분을 읽습니다. 기존 `Range:IsSpellInRange`의 현대 API, 마법책, 구형 함수 및 액션바 호환 경로를 재사용합니다. 최대 사거리 0인 근접·다음 공격 예약 주문에는 숫자 반경을 지정하지 않습니다. [Forever 주문 범위 API](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/SpellDocumentation.lua#L878-L891)
- LibRangeCheck의 Forever 아이템 표를 사용하고, 게임에서 로딩된 사거리 검사 가능 아이템을 같은 거리마다 최대 두 개 준비합니다. 각 API가 공개적으로 반환한 true·false를 상한·하한으로 결합하고, nil·오류·secret은 제외합니다. 아이템 데이터는 한 번 요청하고 로딩 완료 이벤트에서 다시 준비합니다. 표의 후보 거리는 적 5·10·15·20·25·30·35·40·45·100yd, 아군은 이에 50yd를 포함합니다. 이것은 검사 데이터의 후보 목록이며 실제 지원 구간은 각 클라이언트의 응답에 따라 줄어듭니다. [Forever 아이템 범위 API](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/ItemDocumentation.lua#L1464-L1477)
- 최소 사거리가 있는 주문의 false만으로 먼 거리로 판정하지 않습니다. 다른 검사로 가까운 쪽 또는 먼 쪽이 확정될 때 해당 경계를 좁힙니다. 서로 모순되는 결과는 `—`로 처리합니다. 최소 경계의 포함 여부를 확정할 수 없는 경우에는 해당 경계를 포함한 보수적인 구간을 표시합니다.
- 기존 약 0.08초 갱신 하나를 사용합니다. 전투 여부만으로 검사를 중지하는 조건은 없습니다. 값은 매번 현재 `target`에서 읽고 대상 GUID를 측정값 캐시 키로 사용하지 않습니다. 대상 변경·전투 전환에서 화면의 이전 측정을 제거하고 다시 읽습니다. 커서 위치는 같은 갱신 콜백에서 매 프레임 따라갑니다. 모듈 OFF 또는 target과 기존 mouseover 대상이 모두 없으면 반복 콜백을 해제합니다.
- `CheckInteractDistance`도 조사했습니다. 참고 라이브러리는 종족에 따라 결투·따라가기 반경을 다르게 둡니다. 숫자 거리에는 아이템·주문 검사와 공개 실측값을 사용하며, 기존 사냥꾼의 보수적 근거리·데드존 로직에는 종전 상호작용 검사를 계속 사용합니다.
- 참고 라이브러리는 자체 약 0.1초 GUID 캐시와 반복 갱신기를 가지고 있습니다. 첨부 버전의 secret GUID 처리 분기는 `isMidnight`에 연결되어 있고 Forever에서는 해당 조건을 만족하지 않습니다. 이번 구현은 아이템 데이터 표를 활용하고 KHQOL의 공개 값 검사와 기존 갱신기를 사용합니다. 추가 실행 라이브러리나 LibStub 의존성은 없습니다.

### 색상

원래 야드 기준에서 근접은 5yd 이하, 원거리는 30yd 이하, 먼 거리는 30yd 초과로 나눕니다. 사냥꾼이 공격 가능한 대상을 측정할 때는 5~8yd 사이에 완전히 포함된 결과와 기존 근거리·원거리 검사의 동시 실패를 확인해야 데드존 색상을 사용합니다. 정확히 8yd는 원거리 경계입니다. 여러 색상 구간에 걸치는 구간과 확인할 수 없는 상태에는 중립색을 사용합니다. 각 색상은 새 거리 설정에서 변경할 수 있습니다.

## 인게임 재현 절차

1. 대상 거리에서 범위·yd·최대 100m를 선택하고 적 NPC에 접근·이탈합니다. `/frange api`로 API 지원과 표시 결과 종류를 함께 기록합니다. 필드·던전·적 플레이어에서 각각 비전투와 교전 중을 반복합니다.
2. 같은 대상을 단일 값으로 바꿉니다. 실측이 허용되면 `exact`와 API 이름이 나오며, 제공되지 않으면 `range` 또는 `unknown`으로 바뀌는지 확인합니다. 자신과 우호 플레이어도 각각 시험합니다.
3. 사냥꾼은 근·원거리 기준 주문을 등록하고 5·8·30yd 부근을 오갑니다. 숫자와 스킬 판정을 대조하고, 최소 사거리 주문 실패 시 먼 거리로 잘못 표시되지 않는지 살핍니다.
4. 최대 거리를 50m로 바꾸고 단위를 전환해 상한이 같은 실제 위치에서 적용되는지 확인합니다. 모호한 구간은 표시되는지 확인합니다.
5. 커서 옆 표시를 켠 뒤 이동하고 고정 위치로 복귀합니다. 적 툴팁의 기존 문구, 위치 편집 저장·취소·초기화, 모드·프로필 전환과 `/reload`를 확인합니다. 시계 설정에서는 네 기능의 제목 아래 두 선택 항목이 한 줄에 있는지 확인합니다.
