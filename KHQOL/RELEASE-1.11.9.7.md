# KHQOL 1.11.9.7 수정·검증 보고서

## 기준과 결과

- 입력: 실제 최신 작업본 1.11.9.6. 직전 전체 설치 ZIP과 보존한 baseline96의 파일별 SHA-256을 대조합니다.
- 결과: KHQOL 1.11.9.7. Full 19개 애드온 폴더를 유지하며 유닛프레임·파티·공격대도 설치본에 포함합니다.
- 문서 범위: 유닛프레임·파티·공격대 제외. 편의 기능 > 일반 편의 > 파티 포함. 현재 메뉴 구조를 정리했으며 카테고리 자체를 재분류하지 않았습니다.

## 침낭 오류 원인과 표시 조건

기존 CommonBuffs.lua는 중첩을 읽을 수 없는 nil도 `restCount ~= 3`으로 통과시켰습니다. 전투 중 기존 충분한 휴식이 제한된 정보가 되어 UNKNOWN으로 반환되면 PENDING 침낭 아이콘이 생성됐습니다. 원래 3중첩이 있었어도 이 경로로 아이콘이 다시 나타날 수 있습니다. 원본 코드로 이 경로를 재현했습니다. 실제 클라이언트의 전체 원인 확정은 NOT TESTED입니다.

수정본은 `MISSING` 관측 + 중첩 0 + InCombatLockdown/UnitAffectingCombat 모두 false일 때만 관련 아이콘을 허용합니다. 보호되거나 누락된 결과를 부재로 변환하지 않습니다. 전투 종료 시 기존 이벤트가 다시 확인합니다. 새 OnUpdate·주기 조회를 추가하지 않았습니다.

| 상태 | 침낭/충분한 휴식 관련 아이콘 |
| --- | --- |
| 비전투, 버프 없음 확정 | 표시. 실제 침낭 아이템 아이콘은 보유/기능 사용 조건 추가 |
| 충분한 휴식 1·2·3중첩 보유 | 숨김 |
| 버프 미확인·읽기 제한 | 숨김 |
| 전투 중 | 숨김 |
| 휴식 중, 충분한 휴식 없음 확정 | 비전투에서 컬러 표시. 휴식 중 재사용 행동 없음 |

공개 정보를 이용하는 휴식 타이머와 실제 3중첩 신규 획득 완료 문구는 유지했습니다. 기존 1·2중첩 아이콘 유지 동작은 이번 요청에 따라 숨김으로 변경했습니다.

전투 중 일반 프레임의 시각 정보 표시는 기존 코드에서도 사용합니다. 아이콘이 보인다고 보호된 아이템 동작이나 제한된 버프 데이터를 이용할 수 있는 것은 아닙니다. 기존 안전한 아이템 버튼 경로를 유지하고, 전투 중 사라진 항목의 이전 클릭 영역은 덮개로 차단합니다. 이번 수정은 별도 전투 HUD 기능을 추가하지 않습니다.

## 경험치 설정

ExperienceSettings.lua에서 요청한 긴 갱신 지연 문구와 previewStatus/refreshStatus UI 연결을 제거했습니다. `questPreview.status`와 계산·동기화 로직은 그대로 남습니다. 실제 바의 예상 경험치·수치·색상 및 완료 퀘스트 미리보기는 유지합니다.

## 오브젝트 강조

LabSettings.lua에서 채집 오브젝트 강조 아래에 약초 강조·채광 강조·물체 강조 3행을 배치합니다. 각 행은 사용 토글, 효과 드롭다운, 색상 라벨, 변경 버튼 순서입니다. 정상 폭에서 한 행, 좁은 폭에서는 하단에 효과/색상을 배치합니다. 드롭다운 텍스트 줄바꿈 높이를 행 높이에 반영합니다.

기존 herb/ore/chest 분류와 저장 키, 사용·효과·색상 콜백 및 Usage ID를 유지합니다. 물체는 기존 보물상자의 표시 이름이며 감지 범위를 확장하지 않습니다. 공급 이미지 5종과 기존 Soft Target 제한도 유지합니다. DevTools와 통계 카탈로그 파일은 바꾸지 않았습니다.

## 메뉴·기능 문서

최종 설정 레지스트리와 모의로 실제 생성한 설정 컨트롤을 추출하고 표시 그룹·주요 우클릭 동작을 소스와 대조했습니다. 동일 데이터로 MD와 XLSX를 생성합니다. 기능 묶음 161개, 세부 설정·동작 687개, 구현 모듈 27개입니다. 메뉴·기능 시트는 요청한 1Depth / 2Depth / 3Depth / 기능 목록 4열이며 세부 설정 시트에는 설정·동작, 구현 모듈과 파일을 담았습니다. 표 필터와 헤더 고정을 제공합니다.

사용자 등록 개별 NPC·버프·메모는 수집하지 않습니다. 실험실은 접근 잠금 해제 시의 메뉴이며 미니맵은 독립 카테고리입니다. 별도 선입찰과 DevTools는 KHQOL 설정 카테고리 목록에 합치지 않습니다. Source 경로는 설치본 내부의 상대 경로입니다.
