# KHQOL 1.11.4.6 인계

전체 설치 파일: **`KHQOL-1.11.4.6-탭설명-토템위치편집.zip`**. 검증한 1.11.4.5 배포를 별도 사본에서 수정했습니다. 기존 배포 ZIP·기준 사본·실제 AddOns/WTF는 변경하지 않았습니다.

하위 탭 설명 정리와 토템 위치 안정화, 토템 전용 드래그·확장 방향·좌표 범위 변경을 포함합니다. 자동·모의 **599/599**, 9개 직업의 설정 배치, Lua 193개와 XML 5개 검사 PASS입니다. 1.11.4.5에서 재현한 위치 관련 세 조건은 수정본에서 통과했습니다.

19개 폴더 / 논리 모듈 29개 / 271개 파일 / 미디어 32개 / 고유 저장 변수 11개. KH_map과 기존 불필요 경로 15개를 제외했으며 KHQOLMapDB는 KHQOL_Map이 소유합니다.
