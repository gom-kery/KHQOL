# KHQOL 1.11.4.1 인계

1.11.4 기준. 접기 시 여백과 메뉴 재진입 후 펼침 시 겹침의 원인은 하위 영역 갱신에 바깥 DetailLayout의 행 갱신이 포함되지 않은 데 있었습니다. 활성 설정 화면의 상위 배치까지 갱신하고, 일반·프로필의 스크롤 높이도 현재 Builder 결과로 갱신합니다.

이전 버전에서 관련 모의 검사 4개가 실패하고 수정본에서는 통과합니다. 기존 검사와 전체 메뉴 전환·좌표·높이 검사를 합쳐 자동·모의 504/504 통과. 수정판 실제 게임 화면·보호·재접속 확인은 남아 있습니다.

전체 설치 파일은 `KHQOL-1.11.4.1-아코디언여백-겹침수정.zip`입니다. 19개 폴더 / 271개 파일 / Lua 193개 / XML 5개 / 미디어 32개 / 저장 변수 11개입니다. KH_map과 기존 제외 목록을 유지하고 KHQOLMapDB는 KHQOL_Map이 소유합니다. 이전 배포 ZIP·기준 작업 사본과 실제 AddOns/WTF는 수정하지 않았습니다.
