# KHQOL 1.11.7.6 변경·검증 보고서

기준은 KHQOL 1.11.7.5 전체 설치 ZIP입니다. WoW Forever 1.60.1 / 빌드 70938 / Interface 16001용 후속 버전 1.11.7.6으로 패키징했습니다.

## 사용 방법

**편의기능 → 일반 편의 → 공통 → 아이템 → 확인 없이 파괴할 등급**에서 다섯 등급을 각각 켜고 끌 수 있습니다. 기본값은 모두 미선택입니다. 휴지통을 꺼 둔 상태에서도 편집할 수 있고 프로필마다 선택이 저장됩니다.

현재 빌드에서 아이템을 휴지통에 놓으면 WoW 기본 확인창이 열립니다. 선택한 등급에는 즉시 파괴가 미검증이라는 안내를 추가로 표시합니다. 퀘스트 아이템은 게임의 퀘스트용 확인창을 사용합니다. 보호 아이템과 수량이 불확실한 아이템은 휴지통에서 보존합니다.

## 검증

| 구분 | 결과 |
| --- | --- |
| 정적 | Lua 230개, XML 8개, TOC 19개의 구문·구성 검사 통과 |
| 모의 | 기존 하네스 450건과 가방 검사 432건 통과. 다섯 등급의 UI 토글, 휴지통 OFF 상태에서의 편집, 프로필 저장·복원, 선택 여부별 안내 및 기본 확인창, 보호·수량·판매 경로를 확인 |
| 인게임 | 1.11.7.5에서 사용자가 제공한 스크린샷으로 휴지통 드롭 후 `[조각난 곰 이빨] ×1` 기본 확인창 표시를 확인. 당시 가방 보기는 미확인 |
| 인게임 미검증 | 1.11.7.6 등급 설정의 실제 표시와 `/reload` 유지, 기본 가방 및 Baganator에서 추가 클릭 없이 이루어지는 즉시 파괴 |

동작 변경 파일은 `KHQOL_Convenience/Modules/BagTrash.lua`와 `KHQOL_Convenience/UI/BagItemSettings.lua`입니다. 관련 사용 문서와 릴리스 버전 표기를 업데이트했습니다.
