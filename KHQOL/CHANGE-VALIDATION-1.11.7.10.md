# KHQOL 1.11.7.10 변경·검증 보고서

기준은 KHQOL 1.11.7.9 전체 설치 ZIP입니다. WoW Forever 1.60.1 / 빌드 70938 / Interface 16001용으로 패키징했습니다.

**편의기능 → 일반 편의 → 공통 → 아이템**의 **확인 없이 파괴할 등급** 아래에 **퀘스트 분류 일반 아이템도 즉시 파괴**를 추가했습니다. 기본값은 OFF이고, 선택은 프로필에 저장됩니다. 홉 열매처럼 퀘스트 분류가 있는 아이템이라도 가방 슬롯과 퀘스트 로그에서 진행 중인 퀘스트와 연결되지 않은 것으로 확인되면, 선택한 등급을 드래그해 놓을 때 즉시 파괴를 요청합니다.

진행 중인 퀘스트는 기존 퀘스트 확인창을 사용합니다. 퀘스트 상태를 알 수 없거나 등급을 선택하지 않았거나 클릭으로 놓은 경우에는 수동 확인을 사용합니다. 보호한 아이템은 파괴를 차단합니다. 분할은 확인된 커서 수량만 대상으로 하며, 게임이 별도 확인을 요구하면 기본 확인창을 사용합니다.

Lua 231개, XML 8개, TOC 19개를 정적으로 검사하고, 전체 ZIP의 CRC와 내용 일치를 확인했습니다. 설치 구성 5개에서 기존 기능과 새 옵션을 포함한 모의 검사 **1,131건**을 통과했습니다. 기본 OFF, 등급 조건, 스택 분할, 진행 중·확인 불가 퀘스트, 보호 아이템, 게임 확인창, UI 토글과 프로필 복원을 확인했습니다. 실제 Forever에서의 홉 열매 드롭과 파괴 결과는 **미검증**입니다.

변경 파일은 `KHQOL_Convenience/Modules/BagTrash.lua`, `KHQOL_Convenience/UI/BagItemSettings.lua`, `KHQOL_Convenience/UI/SearchIndex.lua`입니다. 릴리스 버전과 설치 문서를 갱신했습니다.
