## 표시 변경

### 단일 값과 사망 대상

기존 단일 값은 공개된 실측값이 없으면 범위 형식으로 되돌아갔습니다. 이제 실측 가능 시 반올림한 숫자 하나, 실측 불가 시 확인된 상한 하나와 `이하`를 표시합니다. 예를 들어 기존 `32~37 m`은 `37 m 이하`입니다. 구간 중간값을 실제 거리로 만들지 않습니다. 범위 형식은 기존 양 끝 숫자를 유지하며 최대 거리 구간 라벨은 아래 규칙을 따릅니다.

`Distance:Measure(unit)`는 생존이 공개적으로 확인된 대상만 측정합니다. 사망·유령·생존 상태 읽기 실패/제한은 표시하지 않습니다. 시체를 다시 선택해도 미확인 기호로 전환하지 않습니다. 기타 측정 불가는 글꼴 누락 위험을 줄이기 위해 ASCII `-`를 사용합니다.

단일 값의 실측 경로는 종전처럼 `UnitDistanceSquared`의 공개된 값과 checkedDistance 또는 같은 맵의 공개된 `UnitPosition` 좌표를 사용합니다. 이 API의 특정 적 대상 지원 여부는 실제 게임에서 확인해야 합니다. [Forever 거리 API](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/UnitDocumentation.lua#L1043-L1056) · [좌표 API](https://github.com/Gethe/wow-ui-source/blob/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/UnitDocumentation.lua#L2566-L2581)

### 단위와 색상 구간

거리 단위 드롭다운은 `m / yd / 미표시`입니다. 미표시는 마지막 m/yd 계산 기준과 변환값을 보존하고 접미사만 숨깁니다. 경계 의미를 나타내는 `이하`, `+`는 유지합니다.

색상 행에는 다음 입력을 배치합니다.

| 행 | 편집 값 | 적용 |
| --- | --- | --- |
| 근접 | 최대 | 최대 이하 |
| 사냥꾼 데드존 | 최소·최대 | 사냥꾼의 적 대상, 양 경계 사이 전체 포함 및 기존 근·원거리 검사 모두 실패 시 |
| 원거리 | 최소·최대 | 구간에 완전히 포함될 때. 사냥꾼은 데드존 상한 이상부터 |
| 최대 거리 | 원거리 최대를 읽기 전용으로 표시한 `값+` | 원거리 최대를 넘는 것이 확인된 구간의 색상 |
| 중립·미확인 | 색상 | 여러 구간에 걸치거나 판정 불가 |

초기 경계는 종전 **5·8·30yd**를 유지합니다. 화면에는 선택한 단위로 변환해 소수 둘째 자리까지 보여주며, 변경하지 않은 입력을 확정해도 저장된 원래 정밀도를 보존합니다. 입력은 0~200yd에 해당하는 범위이며, 잘못된 숫자·역전된 최소/최대는 이전 값을 유지하고 안내합니다. 근접 최대 ≤ 원거리 최소 ≤ 원거리 최대를 확인합니다. 데드존 입력·색상 변경은 사냥꾼에게만 활성화됩니다.

### 최대 거리의 라벨과 표시 상한

사용자의 추가 선택에 따라 **원거리 최대 30m / 표시 상한 50m**이면 먼 거리 구간의 문구는 `50+`입니다. **이 숫자는 사용자가 지정한 구간 라벨이며 실제 거리가 50m를 초과했다는 뜻이 아닙니다.** 설정에도 이 의미를 표시했습니다. m/yd 단위 표시를 켰으면 접미사를 붙입니다.

표시 여부는 이 라벨과 별도로 판단합니다. 실측 60m는 상한 50m에서 숨기며 정확히 50m는 표시합니다. 실측이 없으면 범위의 상한이 표시 상한 이하로 확인된 경우만 표시합니다. 따라서 `40~60m`처럼 경계에 걸치거나 상한이 없는 범위도 숨깁니다. 이는 상한 밖 유닛이 남는 것을 피하는 보수적 동작으로, 실제로 50m 안이더라도 API의 범위가 넓으면 숨겨질 수 있습니다. 색상 구간 입력으로 측정 API의 정밀도가 높아지지는 않습니다.

### 고정 대상 + 마우스오버

대상 표시의 `마우스 커서 옆 표시` 체크박스를 제거하고 고정 좌표 표시로 통일했습니다. 마우스오버 거리 측정에는 다음 선택을 제공합니다.

- 텍스트 표시: 기존 등록 주문의 공격 가능·불가 판정.
- 숫자 표시: 실제 `mouseover`를 별도로 측정하고 숫자 형식·단위·상한·색상 구간을 공유.
- 표시 위치: 툴팁 아래 / 툴팁 왼쪽 / 커서 옆. 보정 좌표·글자 크기는 마우스오버 자체 설정을 사용.

선택한 target을 바꾸지 않고 다른 유닛에 마우스를 올려 두 값을 동시에 표시합니다. target을 해제해도 마우스오버가 있으면 갱신을 유지합니다. 고정 표시가 기존 스킬 판정이어도 마우스오버 숫자를 사용할 수 있으며 공유 숫자 설정도 표시합니다. 숫자 모드에서는 기존 공격 가능·불가 문구 입력만 비활성화합니다.

커서 위치는 기존 반복 콜백에서 매 프레임 따라가고, 거리 API 검사는 종전 약 0.08초 간격으로 수행합니다. 새로운 반복 프레임을 만들지 않습니다. 모듈 OFF와 대상/마우스오버 모두 해제 시 반복 갱신을 해제합니다. 마우스오버 표시 프레임은 마우스 입력을 받지 않습니다. 고정 대상 표시는 잠금을 해제하면 기존 방식으로 이동할 수 있습니다.

1. 대상 거리에서 단일 값·m를 선택합니다. 적 NPC에 접근·이탈하며 두 숫자 범위가 표시되지 않는지, `/frange api`의 exact/range 출처와 함께 확인합니다. 실제 값이 없으면 ‘이하’ 표기를 확인합니다.
2. 전투 중 처치 후 루팅할 시체를 다시 선택합니다. 고정·마우스오버 양쪽에 숫자나 네모가 남지 않는지 확인합니다. 다른 생존 유닛으로 옮겨 표시 복귀도 확인합니다.
3. 단위를 yd → 미표시 → m 순으로 바꾸고 숫자 기준 유지·접미사 제거를 확인합니다. 색상 구간을 바꾼 뒤 경계 앞뒤와 겹치는 측정 범위를 확인합니다. 사냥꾼/다른 직업에서 데드존을 각각 확인합니다.
4. 원거리 최대 30m, 표시 상한 50m로 설정합니다. 확인 가능한 30~50m 사이 먼 거리에는 50+ 라벨, 60m에는 숨김을 확인합니다. 범위만 제공되면 상한을 넘어 걸친 결과도 숨기는지 확인합니다.
5. 고정 target이 있는 상태에서 다른 적에 마우스를 올립니다. 숫자 두 개가 각 유닛을 따라 바뀌는지, target 해제·시체 선택 중에도 생존 mouseover가 독립적인지 확인합니다. 위치·글자 크기·텍스트 모드도 바꿉니다.
6. 기존 커서 ON 프로필에서 업데이트한 뒤 고정 좌표 보존과 숫자 mouseover 이전을 확인합니다. 위치 편집 저장/취소/초기화, 프로필 전환, /reload·재접속을 반복합니다. 기존 시계 단축키·퀘스트·가방 휴지통·파티 버튼 회귀도 확인합니다.
