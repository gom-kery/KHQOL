# KHQOL 1.11.8.19 / DevTools 0.3.2 — 위치 잠금 UI 수정

## 결과와 기준

최신 1.11.8.18 작업본을 그대로 복사해 수정했습니다. 전문기술 숙련 안내, 공통 슬라이더와 도안 알림 위치 보완이 포함된 기준입니다. 기준 Full SHA256: 2bf06be37cfea62417fc72293c29a807e66a9a7bd4794a34fedb021104316798. 이전 결과/sources/실제 설치본은 수정하지 않았고 Git commit/push도 하지 않았습니다.

상단에는 기존 모듈 사용과 현재 대상의 잠금만 남겼습니다. 모듈별 ‘위치 편집 ▼’·대상 선택 메뉴·그 메뉴로 가던 검색 별칭은 제거했습니다. 설정창 오른쪽 위의 전역 ‘위치 편집’은 유지합니다. 기존 검색의 위치 잠금 경로/ID는 헤더 컨트롤을 직접 강조합니다.

## 요청한 1차 확인과 전체 적용

먼저 실제 설정 빌더를 사용하는 Lua UI 모의 환경에서 다음 두 페이지를 검증한 뒤 전체 페이지 검증으로 확장했습니다. 아래는 배치 의미이며 인게임 스크린샷은 아닙니다.

```text
단일 대상
선택한 탭의 설명                         [ON] 모듈 사용
                                        [ON] 위치 잠금
------------------------------------------------------
기존 본문 / 좌표·크기·초기화

일반 편의: 복수 대상
선택한 탭의 설명              가방 휴지통 [ON] 위치 잠금
                               버프 알림 [ON] 위치 잠금
------------------------------------------------------
본문: 가방 휴지통 사용 / 버프 알림 사용 / 기존 세부 설정
```

기존에 모듈 사용 토글이 없는 일반 편의 페이지는 대상 잠금부터 표시합니다. 모듈 사용이 있는 페이지는 바로 아래에 표시하며 X 위치와 행 간격을 일치시켰습니다. 복수 이름은 왼쪽에, 단일 이름은 생략합니다. 좁은 너비에서는 설명 다음 줄에 오른쪽 컨트롤을 두어 겹침을 피하고 긴 이름의 줄 높이를 반영합니다. 잠금 헤더 높이로 본문 시작을 계산하며 빈 편집 버튼 행은 남기지 않습니다.

첫 단계 PASS: 단일 경험치 페이지, 가방 휴지통·버프 알림 2행, 이름/X/Y/본문 사용 설정 구분/원래 잠금 콜백/잠금 계측. 이후 전체 페이지/시계 3행/자원 2행/전문기술 공유 1행/검색/너비 650·900·1200/긴 한국어 이름과 설명을 검증했습니다. 전체 23개 적용 목록은 HEADER-LOCKS.md와 Review의 locks-inventory.json에 있습니다.

## 버프 알림의 실제 코드 조사와 보완

.18 BuffThanks에는 position 테이블·Position Editor preview·PointWriter·resetWrite는 있었지만, locked 값과 RegisterForDrag/OnDragStart/OnDragStop은 없었습니다. 그래서 잠금 UI만 추가하지 않고 실제 직접 이동 경로를 구현했습니다.

- 신규 프로필 값 `modules.generalConvenience.buffThanks.locked=true` 하나만 누락 시 보충합니다. 좌표는 기존 `buffThanks.position={point,relativePoint,x,y}`를 재사용합니다. true/false 명시 값과 기존 메모/좌표/크기/방향/유지시간을 보존합니다.
- 기능 ON + 잠금 OFF + 비전투 + 전역 편집 아님에서 이동합니다. 실제 알림이 없으면 별도 소유 이동 예시가 표시되고, 알림이 있으면 어느 아이콘이든 드래그해 묶음을 이동합니다. 사용 기능과 위치 잠금은 별개이며 잠금을 풀어도 기능/배치 모드/좌표를 초기화하지 않습니다.
- 두 번째 이후 아이콘을 끌면 인덱스/방향/크기별 간격을 빼서 묶음의 기준점을 저장합니다. 다른 아이콘은 움직이는 소유 프레임에 붙여 따라오며 새 OnUpdate를 사용하지 않습니다. 양 방향/다중 알림/이동 중 새 알림·만료를 검사했습니다.
- 기존 PositionStore:Point 검증과 Committed를 통해 저장·프로필·설정 화면을 갱신합니다. 잘못된 상대 프레임/읽기 실패/다른 프로필 세대의 좌표는 저장하지 않습니다. 잠금/비활성화/전투 진입/프로필 종료/알림 만료/전역 편집에서 이동을 마무리합니다.
- 드래그가 시작되면 해당 마우스 해제를 감사 실행/우클릭 닫기로 해석하지 않습니다. 다음 마우스 누름에서 이 상태를 해제하므로 정상 좌클릭 감사와 우클릭 닫기는 유지됩니다. 전투 중 일반 감사 클릭의 기존 정책도 유지합니다.
- 기존 글로벌 대상 `buffThanks`와 초기화 함수를 보존했습니다. 전역 편집 완료 시 새 잠금도 잠그며 취소는 원래 잠금 상태를 유지합니다. 전역 Enter는 대상 스냅샷을 만들기 전에 기존 프레임 이동을 마무리합니다.

## 보존과 독립 잠금 예외

기존 22개 잠금의 getter/setter·전투·모듈·Labs·현재 접속/프로필/계정 범위를 유지했습니다. 휴지통은 기존 free 모드에서만 잠금 조작/직접 이동이 가능하며 attached 모드를 바꾸지 않습니다. 버프 알림은 새 독립 잠금으로 보완했습니다.

파티 버튼은 원래 Alt+좌클릭 드래그·좌표 저장·위치 초기화가 있으며 그대로 유지했습니다. 독립 잠금이 없는 기본 창/유닛 루트/전용 부품 등은 전역·전용 편집의 보호/연결 배치 정책을 유지합니다. 이번 수정으로 네이티브 프레임에 새 직접 이동 동작을 붙이지 않았습니다. 기존 실제 좌표·크기 슬라이더와 초기화는 삭제하지 않았습니다.

공통 CreateSlider 구현과 SettingsLayout.lua는 .18과 바이트/본문 비교로 동일합니다. 전문기술 단계 데이터/판별/툴팁·아이콘/등록/안내의 주요 5개 소스는 동일하고 회귀 검증도 통과했습니다. ProfessionSettings의 제거된 메뉴 검색 별칭만 변경했습니다. 9직업 각 공통 슬라이더 300개와 창 슬라이더 2개의 범위·입력·화살표·정규화·저장 기본값은 .18과 동일하며 비교 시 새 buffThanks.locked 키만 제외했습니다.

## 통계와 데이터

.18의 고정 카탈로그 1567개 행을 보존했습니다. 새 ID는 `setting.generalConvenience.buffThanks.locked` 하나입니다. 기존 CommitSetting/UsageDiagnostics 경로로 실제 잠금 변경을 1회 집계하며 Unlock·Refresh·프로필 적용은 Position Editor 시작이 아닙니다. 실제 전역 편집 버튼으로 시작한 경우만 해당 지표가 증가합니다.

이동 예시는 실제 감사 알림 표시나 감사 실행이 아니며, 드래그는 감사 전송 요청으로 집계하지 않습니다. 이름·좌표·숙련값·메모는 새 지표에 전달하지 않습니다. 기록 OFF/DevTools 미설치에서도 기능 동작을 검증했습니다. DevTools 0.3.2는 신규 설정 ID/카탈로그 revision 4만 반영하며 Usage v0.1/schema 1/protocol 1과 기존 로그/버전 이력을 유지합니다. 새 게임 기본 UI 훅은 없습니다.

## 실제 게임 확인 순서 — 전부 NOT TESTED

1. 경험치 단일 페이지에서 설명 오른쪽 모듈 사용 바로 아래 `[ON] 위치 잠금`을 확인합니다. 모듈별 위치 편집/대상 선택 메뉴가 없는지 확인합니다.
2. 일반 편의에서 ‘가방 휴지통’, ‘버프 알림’ 두 잠금이 직접 표시되고 본문 기능 사용과 독립적인지 확인합니다. 휴지통 attached/free 모드, 기능 OFF 상태도 확인합니다.
3. 버프 알림을 켜고 잠금을 풀어 예시를 이동합니다. 알림 수신 후 첫/두 번째 아이콘, 좌/우 방향을 끌어 같은 묶음의 위치가 유지되는지 확인합니다.
4. 드래그 해제에서 감사 전송/닫기가 발생하지 않고 다음 일반 좌클릭 감사와 우클릭 닫기가 정상인지 확인합니다. 채팅 제한 시 기존 초안 정책도 확인합니다.
5. 이동 중 잠금/기능 OFF/전투/알림 만료/프로필 전환을 확인하고 리로드 후 위치와 잠금을 확인합니다.
6. 시계 3행·자원/콤보 2행·전문기술 공유 1행, 긴 이름/설명/좁은 창/스크롤/검색을 확인합니다. 좌표·크기·초기화와 전역 위치 편집의 저장/취소도 확인합니다.
7. 기록 ON/OFF에서 잠금 실제 변경 1회/편집 시작 0회, 전역 편집 시작만 증가하는지 확인합니다.
8. 전문기술 숙련 안내·노트 등록·길 안내, 슬라이더 화살표/직접 입력, 도안 알림 위치 및 보호 UI/다른 애드온 조합을 확인합니다.

## 설치·검토 자료

설치는 KHQOL-1.11.8.19-Full.zip을 사용합니다. DevTools 0.3.2도 포함합니다. 단독 ZIP은 도구만 교체할 때 사용합니다. Review ZIP의 full/은 최종 소스, baseline/은 변경하지 않은 .18 기준, compat/은 Usage .13 호환 기준, release/은 DevTools 0.3.2입니다. tests/와 결과 JSON, 차이/변경 파일 목적/manifest를 함께 제공합니다. 사용자 실데이터를 포함하지 않습니다.

재검사는 Python+lupa.lua51 환경에서 tests/lock_ui.py, locks_guide.py, global_editor.py, compatibility.py, run.py, sliders_run.py, audit_sliders.py, profile_roundtrip.py, regression.py, recipe_positions.py를 실행합니다. 문서의 PASS는 모의/정적 결과이며 인게임과 구분합니다.
