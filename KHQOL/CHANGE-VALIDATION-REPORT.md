기존 모듈 회귀 도구의 첫 파일이 Bootstrap.lua라고 하던 의존성 검사는 각 TOC의 실제 첫 파일을 읽도록 정리했습니다(KH_map은 Core.lua). 문법/의존성 검사를 완화하지 않았습니다. KH_map 1.0.0의 문서에 있는 119개 검사 스크립트는 입력 ZIP에 없으므로 이번 실행 수에 넣지 않았습니다.

별도 패키지 대조는 원본 ZIP 해시·원본 파일 경로 보존·파티 보호/체력/휠 및 개인 프레임 실행 코드·미디어·원래 지도/버튼 코드의 제한된 변경·19개 아이콘·Bindings.xml·리소스 경로·저장 선언·파일별 SHA256·ZIP CRC/내용을 확인합니다. 실제 모의 출력 JSON은 설치 ZIP 밖 검증 자료에 제공합니다.

## 저장과 이전

기존 KHQOL 변수 10개는 KHQOL.toc, KHminimapDB 하나는 KH_map.toc이 소유합니다. 기존 계정·캐릭터 파일 이름을 바꾸지 않습니다. 계정 공용 파티 라이브러리는 KHQOLDB.globalData.partyFrameProfiles에 저장합니다. 캐릭터별 옛 frameProfiles/frameProfile은 살아 있는 공용 테이블과 분리해 보존합니다.

접속하지 않은 캐릭터의 옛 프로필은 읽을 수 없으므로 A 접속→정상 로그아웃→B 접속 순서로 이전합니다. 설정이 다른 동일 이름은 캐릭터명과 필요 시 번호가 붙습니다. 공용 프로필의 변경·초기화·삭제는 다른 캐릭터에도 반영됩니다. 이미 이전한 캐릭터의 백업으로 삭제한 공용 프로필을 다시 만들지 않습니다.

미니맵 세부 설정은 원래의 계정 공용 KHminimapDB에 남고 전체 KHQOL 프로필 변경의 캡처 대상이 아닙니다. 전체 프로필 문자열은 공용 파티 라이브러리나 미니맵 데이터의 백업 수단이 아닙니다. 전체 백업은 실제 WTF 사본입니다.

## 검증 한계와 인게임 확인

Lua 5.1 모의 실행은 실제 WoW 보호 프레임·taint·시각 렌더링·실제 다른 애드온·로그아웃 디스크 저장의 검증이 아닙니다. 테스트의 네이티브 지도는 개발용 모의 프레임입니다. 실제 게임 설치 폴더나 WTF를 이 작업에서 수정하지 않았습니다.

최종 확인은 A→B→A의 프로필 공유·선택·4종 배치·역할·휠, 미니맵 드래그·아이콘·정리/제외·원래 클릭·모듈 OFF 복원·편집 모드·전투 종료 후 적용·재접속 유지입니다. 사용 중인 UI 배율/해상도에서 두 탭의 글자·드롭다운·목록 스크롤도 확인합니다.

복귀 시 기존 1.11.1.2가 옛 캐릭터 프로필 원본을 읽는 모의 검사는 통과했습니다. 1.11.2에서 새로 편집한 공용 데이터가 옛 원본에 역으로 반영되지는 않습니다. 정확한 이전 상태는 업데이트 전 WTF 사본으로 복원합니다.
