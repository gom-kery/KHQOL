# KHQOL 1.11.0.1 변경·검증 보고서

> 보존 자료: 이 문서 본문은 기준 1.11.0.1의 설치 분리/버전 변경 인계 기록입니다. 1.11.1.0은 같은 설치 구성과 공개 계약을 유지합니다. 이번 유지보수 변경·검증 및 인게임 체크리스트는 설치 ZIP 밖에 별도 제출한 1.11.1.0 자료를 따릅니다. 과거 검사 결과를 이번 실게임 확인 완료로 간주하지 않습니다.

작성: 2026-10-16. 입력 `KHQOL-1.10.10-TEST-FULL.zip`, 결과 `KHQOL-1.11.0.1-Full.zip`.

## 변경

1.11.0 아이콘/단축키 수정본을 기준으로 18개 TOC, 내부 `KHQOL.VERSION`, 현재 문서와 배포명을 1.11.0.1로 변경했습니다. 과거 변경 이력은 유지합니다. 이번 버전 표기 변경에 따른 기능·설정 형식 변경은 없습니다.

후속 수정: 사용자가 보고한 `Couldn't open KHQOL/Bindings.xml`에 대응해 원래 경로의 빈 호환 XML을 보완했습니다. 노트 동작은 `KHQOL_Clock/Bindings.xml`에만 남겨 중복 등록을 피합니다. 18개 TOC의 `IconTexture`는 `Interface\AddOns\KHQOL\Media\kh-qol-minimap-button.tga`로 통일했으며 미니맵 원본 이미지와 같습니다. 실제 클라이언트에서의 경고 해소와 목록 표시 반영은 수정 후 확인이 필요합니다.

실행·TOC·전역·DB·설정·검색·위치 제공자·미디어·로드 이벤트로 의존성을 조사한 후 폴더를 확정했습니다. 개인 프레임/기본 UI/시전바, Clock/Todo, Tooltip/WeaponGuide는 실제 결합을 유지합니다. 파티는 개인 프레임과 사거리 없이 설치합니다.

기능별 코드·이벤트·설정 빌더·검색 인덱스·프로필 적용/드래그/위치/알림 연결은 소유 애드온에 둡니다. 공통 기반은 등록된 코드만 실행합니다. 모듈 내부 파일은 새 애드온의 두 번째 `...` 테이블을 공유 네임스페이스로 간주하지 않고 `_G.KHQOL`을 명시적으로 사용합니다.

모든 기능 등록 이후 설치 구성을 고정하고 프로필을 준비합니다. 미설치 모듈은 메뉴·탭·검색·편집에서 제외하고 일반 페이지에서 설치 상태를 안내합니다. 미설치 모듈의 DB·프로필·사용 선호를 보존합니다. 재등록/중복 초기화와 초기화 실패/재시도, 필수 누락·순환을 검사했습니다. 실행 중 신규 모듈 핫등록과 새 지연 로딩은 추가하지 않았습니다.

기존 KHQOL TOC가 모든 저장 변수를 단독 소유합니다. 새 기능별 SavedVariables 파일은 없고 원본 계정/캐릭터 KHQOL.lua 경로를 유지합니다. 프로필·내용 필터와 캐릭터별 데이터 범위는 유지합니다. 구형 파티 역할 프로필 이관은 종전 캐릭터 DB의 성공 마커를 유지합니다.

공용 폰트와 경고/내비게이션 자산은 기반에, 전용 시계·전투 상태 자산은 해당 기능에 둡니다. 중복 글꼴/텍스처 사본을 제거했고 자산 파일 32개는 모두 입력 파일과 해시가 같습니다. 외부 라이브러리를 추가하거나 라이브러리 버전을 바꾸지 않았습니다.

성능 모니터는 Labs 애드온 하나가 아니라 설치된 KHQOL 기반·기능 전체를 합산합니다. 모듈별 최대·지연 횟수 합계는 전체 동시 최대/횟수와 다를 수 있음을 화면·로그에 표시합니다. 그래픽 복원 기록을 읽는 기존 안전 복원부는 기반에 공유하여 Labs 제거 후에도 복원을 시도하고 실패·충돌·전투에서는 기록을 보존합니다.

## 자동·모의 검사의 실제 범위

환경: Python + **실제 Lua 5.1 실행기(Lupa 2.8)**. WoW API/Frame/이벤트/타이머는 시험용 모형입니다. 모형의 폰트 길이·좌표·화면은 실제 렌더링 결과가 아닙니다. 보안 XML은 구문/파일 구조를 검사했으며 보호 실행 엔진을 재현하지 않았습니다.

| 검사 | 결과·범위 |
|---|---|
| Lua 구문 | 배포 Lua **186개** 전부 Lua 5.1 컴파일 |
| TOC/XML/버전 | 18개 애드온, 일치하는 TOC 이름/파일, 버전 1.11.0.1, XML 구문, 저장 변수 10개 단독 소유 |
| 단축키 경로·등록 | 기존 KHQOL/Bindings.xml 경로 존재·빈 루트 XML, Clock에 노트 동작 1회, TOC 중복 로드 없음 |
| 목록 아이콘 | 18개 TOC의 동일 IconTexture 경로 존재, 미니맵 이미지와 원본 바이트 일치 |
| 설치 의존 | 모든 기능의 필수 의존은 KHQOL 하나. 2^17=131,072가지 선택 집합에 같은 필수 정책이 적용됨. 이 수는 전체 실실행 검사 수가 아님 |
| 기준·전체 로드 | 기반만 + 단일 17개 + 전체 정방향/역방향 |
| 쌍별 경계 | 17개 중 2개인 **136조합**의 파일 로드·기본 프로필·메뉴·검색·전송 스키마 |
| 실행 UI/프로필 | 기반만·단일 17개·전체, 혼합 **24조합**의 로그인·페이지·위치 대상·프로필 복사/전환/삭제·내보내기/검사 |
| 기존 데이터 | 실제 1.10.10 코드를 실행해 대표 시험 저장 데이터를 생성하고 전체·각 단일 설치로 업그레이드 |
| 부분 설치·재설치 | 기반만인 상태에서 프로필 생성·복사·전환·삭제·이관 반복 후 데이터 동일성; 재설치 시 선택한 휴면 스냅샷 복원 |
| 내용·개인 범위 | 한글 노트·페이지·그룹·체크·알람, 버프/NPC/발동 목록, 알 수 없는 모듈 키, 위치, 주문, 캐릭터 색, 파티 휠/역할 프로필 |
| 다른 캐릭터 | 계정 프로필 연결과 별도의 주문/휠 DB·캐릭터별 역할 이관, 다른 캐릭터 데이터 보존 |
| 실패·복귀 | 잘못된 프로필 적용 실패 후 원래 선택/데이터 복구, 이관 반복, 재로그인 모형, 실제 1.10.10 소스로 다시 로드 |

| 설치 상태 | 미설치·비활성·미로드, 잘못된 경로의 일반 페이지 복귀, 미설치 검색 제외 |

| 성능 집계 | 기반+설치 패키지 CPU/메모리 합, 모듈 최대 합, 전체 메모리 분모 중복 없음 |
| 리소스 | 정확한 파일 경로 17곳 및 동적 디렉터리 소유권 검토, 전체 32자산 원본 동일·중복 해시 없음 |

검사 목록과 결과는 `docs/validation-results.json`에 포함합니다. 개발용 시험 실행기·스크립트·원본 ZIP·실제 WTF 데이터는 설치 ZIP에 넣지 않습니다.

## 실제 게임에서 남은 확인

로그인과 게임 로더의 SavedVariables 파일 I/O, /reload 후 실제 저장, 다른 캐릭터 재접속, 파티/공격대 인원별 표시와 실제 체력/자원, 보호 프레임 배치·Show/Hide와 전투 종료 복원, 실제 클릭·휠 주문 시전·등급·임시 바인딩 해제·외부 바인딩, 설정의 글자·IME·색·숫자·작은 창·검색·위치 편집, 시전/오라/대화창/상점/퀘스트/지도/ESC/기본 편집 모드, 프레임 시간·메모리·실제 성능이 남아 있습니다.

2단계의 핵심 실게임 미확인은 이 작업의 코드 보존 검사로 완료 처리하지 않았습니다. 대표 설치 조합과 실게임 기대 결과는 `INSTALL-GUIDE.md`에 있습니다.

## 범위·호환 제한

- 기반 없는 기능 실행과 실행 중 임의 핫로드는 지원하지 않습니다. 모든 기능에 같은 필수 의존 정책을 적용합니다.
- API가 없는 클라이언트에서는 해당 기능의 기존 안전한 미지원 안내/보류를 유지합니다. 모형은 실제 client API 지원을 보증하지 않습니다.
- 프로필 문자열은 종전과 같은 지원 표시 설정 범위입니다. 부분 설치 시 미설치 설정은 제외/부분 호환으로 보고될 수 있습니다. 저장 DB를 지우지 않으며 재설치에는 원래 WTF 로더를 사용합니다.
- 기준 자산의 별도 배포 허가서는 ZIP에 없었습니다. 원본 바이너리·기존 출처 기록을 보존하고 글꼴 권리자/공식 안내를 `ATTRIBUTION.md`에 추가했습니다. 독립 재배포 권한의 포괄적 검증 완료를 주장하지 않습니다.

실게임 결과가 확인되기 전에는 이 결과를 **1.11.0.1 설치 분리 구현·시험 패키지**로 취급합니다.
