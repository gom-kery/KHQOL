# 실제 Forever 체크리스트 — 전 항목 NOT TESTED

정상 종료 후 Full 1.11.8.15를 설치합니다. 기존 통계/설정을 자동 초기화하지 않습니다. 테스트 전 값을 적고 실행 뒤 비교하세요. Usage 테스트는 기록을 직접 ON으로 켜며 테스트 행동도 실제 통계에 포함됩니다. 필요하면 먼저 JSON을 백업합니다.

페이지 이동으로 메뉴 지표가, 모듈 ON으로 활성 날짜가 함께 바뀔 수 있습니다. 검증할 설정 ID의 증가량을 보세요. 같은 드래그 안에서 시작값 복귀는 0회, 별도 드래그로 복귀는 각각 1회입니다. 입력 초안 확정 뒤 화살표는 서로 다른 실제 조작일 수 있습니다.

| 항목 | 행동 전 기준 | 행동 | 예상 | 확인 위치 |
|---|---|---|---|---|
| 정수 step | 현재 X=120, step=1 | < 한 번, > 두 번 | 119 → 120 → 121, 각 setter/저장 1회 | 해당 값/핸들/숫자 |
| 경계 | 현재 min 또는 max | 범위 밖 방향 클릭 | 해당 버튼 비활성, 값·저장·계측 0회 | 좌우 버튼/Usage 해당 ID |
| 소수점 | step=0.05 또는 0.1 | 여러 번 증감 후 왕복 | 정확한 단위·표시, 누적 오차 없음 | 실제 저장값과 표시 |
| 드래그/화살표 | 현재 값 기록 | 드래그 후 화살표, 반대 순서 | 동일 값으로 핸들·숫자 동기화 | 동일 설정 |
| 숫자/화살표 | 현재 값 기록 | 숫자 Enter 후 화살표 | 각 확정 변경 반영, 중복 저장 없음 | 동일 설정 |

| 전체 화면 | 설정창 기본 너비 | 각 모듈·상세·아코디언·검색 이동 | 버튼/트랙/입력/설명/피드백 겹침 없음 | 모든 설정 페이지 |
| 좁은 폭/배율 | 기존 창 크기와 배율 | 너비·배율 변경, 1/2열 전환 | 셀 안 정렬, 좌측 배율/투명도 정상 | 창 가장자리/클릭 영역 |
| 재진입 | 값 변경 | 페이지/창 닫고 다시 열기 | idle 숫자와 핸들·버튼 상태 유지 | 숫자 FontString/focus |
| 저장 복원 | 변경 후 실제 값 기록 | 정상 /reload, 재접속 | 값/프로필/기본 설정 보존 | 동일 프로필 |
