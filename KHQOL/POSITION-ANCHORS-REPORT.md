# KHQOL 1.11.8.21 — 탭 아래 위치 잠금·이동 앵커

## 기준과 배치 해석

확인 버전 .19보다 최신인 로컬 최종 .20 Full을 실제 기준으로 사용했습니다. 기준 ZIP SHA256: 03570b6ccc68efa0cf086cf184b12943ac746108b7491cf1939bf1e99b6f3e08. .20 전문기술 안내와 기존 공통 슬라이더 개선을 포함합니다. 첨부 화면은 중복 결함 신고가 아니라 **잠금 행을 탭 아래에 두자는 배치 제안**으로 해석했습니다.

배치는 `페이지 설명 + 오른쪽 모듈 사용 → 대상/세부 탭 → 위치 잠금 행 → 기존 본문`입니다. 단일 대상은 `[ON] 위치 잠금`, 복수는 `대상 이름 [ON] 위치 잠금`을 직접 표시합니다. 잠금 행은 본문 스크롤과 별도의 고정 영역입니다. 모듈별 위치 편집 메뉴/대상 드롭다운은 없고 설정창 전체의 전역 위치 편집은 유지합니다.

**오라 조건:** 모든 유닛 페이지에 탭/잠금 행은 존재하지만 공개 원본이 없는 클라이언트에 새 버프 아이콘을 만들지는 않습니다. 합성 기본 fixture에서는 모든 오라가 꺼져 있어 잠금이 비활성인 것이 정상입니다. 별도 공개 주시 오라 fixture에서 실제 원본 위치 writer·반복 적용 시 좌표 누적 없음·기능 OFF 시 원복을 검사했습니다. 실제 Forever 클라이언트의 소환수/대상의 대상 오라 영역 지원 여부는 NOT TESTED입니다.

## 앵커와 저장

OFF 시 이름이 붙은 청록색 테두리를 표시합니다. 내용이 숨겨져 있으면 기존 위치 예시를 사용합니다. 설정창을 닫고 왼쪽 드래그, 놓으면 저장, 잠금 ON이면 테두리 종료입니다. 아이템을 들고 있는 상태에서는 공통 테두리 드래그를 시작하지 않습니다. 버프 감사 알림의 전용 클릭 영역을 공통 테두리가 덮지 않습니다.

기존 ModuleRegistry PositionTargets의 좌표/스케일 변환·writer·apply와 PositionStore 저장 경로를 사용합니다. Blizzard 원본을 직접 StartMoving하지 않습니다. 전투/화면 이탈 시 미완료 드래그는 취소하며, 전투 종료 후 OFF인 대상의 테두리를 복원합니다. 프로필 전환 전에 진행 중인 드래그를 기존 프로필에 확정하고, 오래된 세대/대상에 대한 쓰기를 거부합니다. 전역 위치 편집 중에는 공통 테두리를 숨깁니다. 매 프레임 조회·새 반복 갱신기는 없습니다.

기존 프로필/SavedVariables 선언을 바꾸지 않았습니다. 추가 키는 유닛별 positionLocks·선택적 simpleAuras, 대상 시전바 locked, NativeAlerts roll/alerts locked, NPC locked/bannerPosition입니다. 기존 사용자 좌표를 이관/초기화하지 않습니다. 경험치 등 기존 접속 단위 잠금은 계속 접속 단위이고 좌표는 원래 프로필 범위입니다. NativeAlerts는 기존 계정 범위입니다.

시계 공유 잠금은 기존 positionLocked와 timerBarLocked를 함께 쓰며 positions는 변경하지 않습니다. 기존 두 값이 다르면 하나라도 OFF일 때 공유 상태는 OFF이고 사용자가 다음 조작할 때 두 값을 맞춥니다. 예전 timerBarLocked 통계 ID와 이력은 삭제하지 않았습니다.

## 실제 WoW Forever 체크리스트 — 모두 NOT TESTED

1. 단일 경험치 페이지와 일반 편의의 가방 휴지통/버프 알림 페이지에서 설명 옆 모듈 사용, 탭 아래 잠금, 본문 스크롤과 겹치지 않는지 확인합니다. 좁은 창/긴 이름도 확인합니다.
2. 유닛 5종의 기본/이름·레벨/상태·징표/오라 탭을 전환하고 해당 잠금만 보이는지 확인합니다. 대상·주시·소환수를 만들고 없애면서 예시와 실제 위치를 확인합니다.
3. 오라 표시를 켠 뒤 공개 원본이 있는 대상만 이동 가능한지, 반복 설정 적용/전투 종료 후 좌표가 누적되지 않는지, 기능 OFF 시 원복되는지 확인합니다.
4. 가방 닫힘·만렙 경험치·미시전·NPC 미경고 상태에서 OFF 테두리를 확인합니다. 드래그/ON/리로드/프로필 전환 후 기존 좌표·크기·초기화를 확인합니다.
5. 주사위 굴림과 실제 도안 습득의 위치/크기, 플레이어·대상 시전바, 사거리 모드 전환, NPC 경고 배너의 실제 표시를 확인합니다.
6. 알람 / 타이머의 한 잠금으로 도구 창·타이머 바가 함께 움직일 수 있는지, 각각 저장 좌표를 유지하는지 확인합니다. 버프 알림의 감사 클릭·우클릭 닫기·드래그를 확인합니다.
7. 드래그 도중 전투 진입/프로필 전환, 기본 UI/전역 위치 편집 전환을 확인합니다. DevTools 기록 ON/OFF/비활성에서 동일 기능, OFF 잠금 시 start 증가 없음, 명시적 전역 편집 시 1회만 증가하는지 확인합니다.
8. 기록 OFF와 ON에서 전투/비전투 첫 마법책 열기, 전투 종료 후 열기, 게임 메뉴에서 캐릭터 선택 화면으로 나가기를 확인합니다. 이전 시간의 오류 재표시와 새 오류를 구분합니다.
