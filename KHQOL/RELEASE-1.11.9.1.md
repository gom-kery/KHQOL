## 사용 방법과 저장값

- **거리**: 인터페이스 → 사거리 측정 → 거리 색상 제목의 [+]. 사용자 행의 색상 오른쪽 ▲/▼로 기본 행 사이까지 이동한다. 최대3개는 유지한다. 기존 저장 구간에 after가 없으면 예전처럼 기본 행 아래에 둔다. 신규 입력은5글자이며 예전 긴 이름은 표시만 줄이고 저장 원문을 그대로 둔다. 이름 칸을 실제 편집하면 새5글자 제한이 적용된다. 거리 경계는 원래 yd로 보존한다. 사용자 행이 기본 행 사이로 이동해도 색상 판정은 사용자 행끼리 위쪽 우선 → 기본 구간으로 유지한다.
- **음식**: 편의 기능 → 버프 리마인더 → 음식·포만감에서 알림 ON, 자동 선택 또는 지정 음식을 사용한다. 자동 후보는 공개 Food&Drink 분류와 한국어/영어 설명을 확인한 경우만 허용한다. 포만감이 없다고 확인된 때 아이콘을 표시하고, 잠긴 아이콘을 직접 클릭해 사용한다. 일반 가방 클릭도 실제 식사 오라가 읽히면 선택 음식의 검증된 초를 기준으로 시각 진행을 복원하지만 특정 음식 사용 성공 통계로 귀속하지 않는다. 공용 식사 오라만으로 먹은 아이템 ID를 판별했다고 주장하지 않는다. 포만감·식사 정보를 읽을 수 없으면 안전하게 숨긴다.
- **마크**: 유닛프레임 → 플레이어/대상 → 상태·징표. 간결한 프레임에서 진영·PvP/해골의 위치 보정과 초기화를 사용한다. 해당 탭 위치 잠금 OFF에서 마크 테두리도 드래그한다. 플레이어 기본 프레임에 실제 해골 표시기가 없으면 해당 설정은 비활성이다. 별도 플레이어 해골을 임의 생성하지 않는다.
- **보호막**: 바 설정 → 환경 타이머 → 보호막 연동 → 보호막 타이머 사용. 기본 OFF다. 각 보호막의 공개 오라 만료 시간으로 남은 시간을 표시한다. 흡수량은 **개별 보호막 잔량이 아니라 플레이어 전체 흡수 합계**이며 첫 활성 보호막에 한 번 표시한다. API 미지원/비공개 값은 `-`, 지속 시간 미확인은 타이머 생략이다. 이 부분은 클라이언트 공개 API에 따라 조건부 지원이다. 기본 호흡/피로도/죽은척 기능은 유지한다. 보호막에는 중앙 긴급 경고/경고음을 발생시키지 않는다.
- **이전 기능**: 전문기술 안내(공통 확장 레벨10/20/35), 습득처 정책·ForeverNote 등록, 스킬 설정/Shift 휠, 공통 슬라이더·탭 아래 잠금·앵커, 기존 프로필/노트/통계는 보존한다. 새 기본값만 보충하며 사용자 SavedVariables를 배포하거나 초기화하지 않는다.

## 계측·갱신

DevTools OFF/미설치에서도 기능을 실행한다. catalog9는 기존1,680개 고정 등록 행을 보존하고 마크12개·보호막6개 설정 ID만 추가한다. 음식 request/used/well_fed의 기존 의미를 유지하며 실제 공개 오라와 직접 요청이 맞아야 귀속한다. 반복 Refresh·미리보기·가방/리로드의 시각 복원만으로 사용 성공을 만들지 않는다. 위치 잠금 조작은 설정 변경이고 Position Editor 시작으로 집계하지 않는다. 이름·좌표·입력값·음식 ID·흡수량은 Usage에 넣지 않는다.

음식은 오라 관찰 캐시와 이벤트 시점의 가방 순회를 사용하고, 보호막은 enabled 동안만 오라/흡수 이벤트를 등록한다. 진행/타이머의 기존 활성 프레임 갱신은 표시 시간만 줄이며 매 프레임 오라·가방·흡수 API 조회를 추가하지 않는다. 거리 상태 문구는 기존 측정 결과를 재사용한다.

## 제출물과 설치

`KHQOL-1.11.9.1-Full.zip`이 게임 설치용이다. 게임 종료 후 내부19개 애드온 폴더를 Interface/AddOns의 같은 폴더와 교체하고 WTF/SavedVariables는 보존한다. DevTools는 선택 설치이며 별도0.3.7 ZIP과 Full 포함본은 동일하다.

Review ZIP은 설치하지 않는다. 기준/최종 소스·검사·근거·로그·변경 파일 목록을 검토하거나 재현할 때 쓴다. README·CHANGELOG·INSTALL-GUIDE·DESIGN은 실제 사용법으로 갱신하고 과거 기록은 이전 버전으로 구분해 보존했다. 모든 수정 파일과 전후 지문은 CHANGED-FILES.json, 설치 파일 지문/폴더/검사 요약은 release-manifest.json, ZIP 지문은 CHECKSUMS.txt에 있다.
