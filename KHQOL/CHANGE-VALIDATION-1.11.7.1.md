# KHQOL 1.11.7.1 변경·검증

기준은 KHQOL 1.11.7.0의 기본 ZIP과 선택 프레임 ZIP입니다.

## 원인과 수정

- 공통 외형 코드 분리 과정에서 `UnitFrameDecor.lua`의 위치 비교 함수 연결이 빠졌습니다. 대상의 대상 프레임은 기존 배포본 831번째 줄에서, 소환수 포만감 아이콘은 447번째 줄에서 같은 오류를 일으켰습니다. 저장된 보정값이 있을 때 첫 적용 뒤 이어지는 재적용에서 재현했습니다.
- 두 위치 보정 경로가 공통 UI의 기존 위치 기록과 비교 로직을 사용합니다. 재적용에는 게임의 기준 좌표를 사용하고, 게임이 위치를 바꾸면 새 기준 좌표를 기록합니다. 해제 시 마지막 기본 위치를 복원합니다.
- 선택 묶음은 같은 버전의 기본 설치와 사용합니다. 필요한 위치 기능을 제공하지 않는 이전 기본 설치와 섞이면 선택 묶음 등록을 보류합니다.

## 검증 결과

- 새 회귀 검사 **7/7**. 접속·월드 진입·반복 적용, 게임 좌표 변경, 모듈 OFF와 초기화, 전투 종료 후 재적용, 읽을 수 없는 좌표 및 이전 기본 설치와의 혼용을 검사했습니다.
- 전체 모의 검사 **261/261**. 이전 254개 시나리오를 수정본에서 다시 실행했습니다.
- Lua 5.1 문법 222개, XML 7개, TOC 19개, 저장 변수 12개 소유권, ZIP CRC·파일별 SHA-256 및 제외 폴더를 확인했습니다.
- 실제 Forever에서의 재접속과 화면 배치는 미실시입니다.
