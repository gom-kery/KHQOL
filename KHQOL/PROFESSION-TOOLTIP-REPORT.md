# KHQOL 1.11.8.20 — 전문기술 다음 숙련 안내 툴팁

## 기준과 결과

실제 최신 로컬 작업본은 1.11.8.19였으며 위치 잠금 23개·버프 알림 드래그·전역 편집과 공통 슬라이더 개선이 포함되어 있습니다. 이를 수정하지 않은 baseline/과 작업 full/로 분리해 1.11.8.20을 구현했습니다. 기준 ZIP SHA256: f4bedc775fa25968057482b93ea7053d01e6b17613401c11e08eac4361cfe220. sources/·이전 결과·실제 설치본은 수정하지 않았고 Git commit/push하지 않았습니다.

다음 형식으로 표시하며 라벨은 기본 흰색, 숫자 묶음만 충족 초록/부족 빨강/판정 불가 중립입니다. 숙련 판정은 다음 단계 요구 기본 숙련과 비교하며 현재 상한 도달 여부와 혼합하지 않습니다.

```text
연금술

레벨 22 (20)
숙련 75/150 (125)
```

위 예시는 레벨 초록·숙련 빨강이며 다음 상한·장소·등록 안내는 없습니다. 개별 조건을 둘 다 충족한 단일 교관의 실제 자료 기반 모의 결과는 다음과 같습니다.

```text
연금술

레벨 22 (20)
숙련 125/150 (125)

225 숙련
다르나서스 · 에이네실

우클릭 시, 좌표등록
```

두 조건 충족 + 3곳 이상은 다음 상한까지만 표시합니다. 두 조건 충족 + 충분한 후보 자료로 1~2곳은 장소와 습득 방법을 표시합니다. 등록 가능한 대표 좌표와 노트 상태를 확인한 경우에만 하단에 정확히 ‘우클릭 시, 좌표등록’을 표시합니다.

## 미확인 값과 데이터 범위

현재·요구 값을 읽을 수 없으면 —와 중립색입니다. 알려진 상한은 유지하여 다음 요구 조건을 판별할 수 있지만 읽기 불가 기본 숙련을 이전 캐시값으로 대신하지 않습니다. 서로 다른 공개 필드를 따로 읽어 일부 값이 제한되어도 다른 공개 값까지 잃지 않습니다.

요구 조건은 VERIFIED(확인된 임계값), NONE(조건 없음이 명시적으로 확인됨), UNKNOWN(자료 미표기/읽기 불가)을 구분합니다. NONE은 ‘없음’으로 표시하고 해당 조건은 충족으로 처리합니다. **이번 실제 자료에 미표기 레벨을 NONE이나 0으로 바꾸는 보완은 하지 않았습니다.** NONE과 책 표시 검증에 쓰인 변경값은 합성 테스트 전용이며 배포 데이터에는 반영하지 않았습니다.

특히 낚시 숙련 225 단계의 요구 레벨은 [WOWF 낚시 원문](https://wowf.io/ko/professions/fishing/ranks)과 제공 자료에 미표기여서 다음과 같이 표시합니다. 예시의 20을 넣거나 레벨 조건 충족으로 판단하지 않습니다.

```text
낚시

레벨 22 (—)
숙련 125/150 (125)
```

요리·응급치료 등 레벨 미표기 단계도 같습니다. 상세 표는 PROFESSION-PLACES.md입니다. 값이 없다는 이유로 습득처가 한 곳이어도 노출하지 않습니다. 확인된 최종 상한은 ‘최종 숙련’, 다음 단계/상한 데이터가 없으면 ‘다음 단계 정보 없음’으로 구분합니다. 툴팁에 판정 태그·원문 미표기 설명·좌표/mapID·현재→다음 문장·긴 사용 설명을 표시하지 않습니다.

## 장소 수 계산

1. 현재 진영과 중립, 바로 다음 단계의 교관/책 판매처/퀘스트 제공 후보만 포함합니다. 진영을 확인하지 못하면 희소 장소를 확정하지 않습니다.
2. 보존된 원문 48단계의 전체 구조화 목록을 기존 카탈로그와 대조하고 구성 서명·개수·필수 필드·장소 식별 근거를 검증합니다. 누락/미확인 시 목록의 두 NPC만 보고 ‘두 곳’으로 판단하지 않습니다. 이는 해당 원문의 대조 범위이며 모든 실제 게임 NPC의 완전성 증명은 아닙니다.
3. 명시된 지역+마을/습득처를 같은 장소로 묶습니다. 명시 장소가 없으면 같은 지도+동일한 원문 X/Y만 합칩니다. 같은 도시/지역 지도 전체를 한 곳으로 합치지 않고 근접 거리로 추측하지도 않습니다. 같은 지역의 서로 다른 마을/지점은 별개입니다.
4. 장소마다 안정적인 대표 NPC 한 명을 표시·등록합니다. 다른 후보와 방법은 내부 목록에 보존합니다. 표시한 대표 후보 외의 좌표로 자동 대체하지 않습니다.
5. 좌표를 등록할 수 없어도 확인된 장소 수에서 빼지 않습니다. 울다만 안노라는 한 장소로 표시할 수 있지만 좌표가 없어 등록/하단 안내는 제공하지 않습니다. 두 장소 중 한 곳만 좌표가 유효해도 메뉴는 두 곳을 보여 주며 무효 항목을 비활성화합니다.

지역 관계는 원문의 place/zone 쌍이 확인된 경우에만 `무법항(가시덤불 골짜기)`처럼 표시합니다. 별도 도시 지도에 확인하지 않은 상위 지역을 추측해 붙이지 않습니다.

## 책·퀘스트·등록

책은 검증된 실제 이름과 가격을 사용합니다. 금/은/동은 기존 게임 MoneyFrame 아이콘을 사용하고 0인 단위를 생략합니다. 확인된 0원만 무료로 구분하며 미확인 가격은 금액 부분을 생략합니다. 퀘스트는 NPC·지역과 퀘스트명만 짧게 표시합니다. 긴 NPC/지역/책 이름에 네이티브 줄바꿈을 사용합니다. 책 가격·이름 포맷은 합성 NONE 조건에서 검사했으며 실제 낚시 숙련 단계의 미표기 레벨은 그대로 UNKNOWN입니다.

툴팁과 우클릭은 동일한 Presentation 결과를 사용합니다. 조건 미충족/불가·3곳 이상·후보 자료 불완전·습득 위치 설정 OFF에서는 메뉴와 등록 안내를 제공하지 않습니다. 계측 의미는 유지하여 안내 ON + 다음 단계가 있는 상태의 명시적 우클릭은 거부되는 경우에도 note_request 1회입니다. 자동 Refresh/후보 메뉴 열기/선택은 별도 요청을 추가하지 않으며 실패/선택/중복은 note_added가 아닙니다. 노트 미설치/비활성/전투/좌표 미검증은 기존 안전한 메시지와 제한을 유지합니다.

한 장소는 즉시, 두 장소는 공통 작은 메뉴에서 선택합니다. 티켓은 owner·현재 기술·상한·다음 단계·현재 진영·프로필 세대·표시 장소 서명을 검증하고 레벨·기본 숙련 조건과 좌표를 다시 확인합니다. 상태가 바뀌면 예전 메뉴를 닫고 등록을 거부합니다. 마우스 오버 이후 바뀐 상태도 우클릭 직전에 갱신합니다.

기존 Point 검증/0~100→0~1 변환과 AddTodoCoordinate 경로, 같은 mapID·XY 차이 1e-7 미만의 중복 정책을 유지합니다. 기존 메모/완료/체크리스트를 덮어쓰지 않습니다. 반환 항목의 실제 존재를 확인한 후만 note_added를 집계합니다. 등록 후 길 안내는 기존 명시적 메뉴에서 시작하며 강제로 노트·지도 핀·안내 옵션을 켜지 않습니다.

지도 핀 검증은 실제 NoteMapPins provider와 KHQOLNoteMapPinMixin의 OnLoad/OnAcquired를 합성 MapCanvas에 연결해 수행했습니다. 등록한 항목이 생산용 핀 템플릿으로 생성되어 원래 정규화 좌표/ID/노트 목록과 연결되는지 확인했고, PLAYER_LOGOUT 후 SavedVariables를 새 런타임에 복원하여 같은 핀을 다시 생성했습니다. 실제 게임 화면 렌더링/좌표 위치는 NOT TESTED입니다. 세계지도 핀 표시가 꺼져 있으면 그 설정을 유지합니다.

## 갱신·계측·호환

기존 창·숙련·레벨·프로필 이벤트와 합쳐진 0초 예약을 재사용합니다. 새 OnUpdate/반복 타이머/전체 기술 목록 폴링을 추가하지 않았습니다. 조건이 부족해지면 이전 장소/상한/등록 안내와 메뉴를 정리하고, 닫힌 owner의 툴팁도 정리합니다. Refresh/기술 전환 갱신은 새 조회가 아니며 실제 표시 구간만 기존 guide 지표로 집계합니다.

기존 Usage 고정 카탈로그 1569개 행과 모든 ID/정의/바인딩을 보존했습니다. DevTools는 실제 코드 변경이 없으므로 **0.3.2 유지**, schema/protocol 1과 기존 로그/버전 이력도 유지합니다. 새 설정/SavedVariables 키가 없습니다. 정적 장소/완전성 정보와 임시 티켓을 사용자 데이터에 복사하지 않습니다. NPC/캐릭터 이름·좌표·숙련값·노트 내용은 진단에 보내지 않습니다.

위치 잠금 23개, 제거된 모듈별 위치 편집 메뉴, 전역 편집, 버프 알림 드래그, UI.lua·SettingsLayout.lua와 실제 슬라이더 구현은 .19와 동일합니다. 프로필 기본값도 제외 항목 없이 .19와 같습니다. 기존 숙련 조건/좌표/지도 값은 ProfessionRanks.lua를 바이트 단위로 보존했고, 기존 노트·핀 구현도 변경하지 않았습니다.

## 실제 게임 체크리스트 — 전부 NOT TESTED
