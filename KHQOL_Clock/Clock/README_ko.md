# KHQOL 1.11.6.0 — 시계와 포에버 노트

전체 설치 ZIP: `KHQOL-1.11.6.0-최종안정화.zip`. **KHQOL + KHQOL_Clock**으로 설치하고 별도 ForeverClock 폴더는 사용하지 않습니다. ForeverClockDB·노트·경로 콘텐츠를 유지합니다.

시계는 인터페이스→시계·정보 표시, 노트/핀/경로는 편의 기능→포에버 노트에서 설정합니다. **새 경로 그리기**를 한 번 누른 뒤 Shift+우클릭으로 핀을 찍거나 기존 핀을 좌클릭해 순차 등록합니다. 지도 표시줄에서 완료 또는 안내 시작을 누릅니다. 핀에 선택 경로 순번을 표시하며 그리기 종료 후 일반 조작으로 돌아갑니다.

[설치·사용법](../../KHQOL/INSTALL-GUIDE.md) · [변경·검증](../../KHQOL/CHANGE-VALIDATION-REPORT.md). 실제 Forever 실행은 별도 확인이 필요합니다.


퀘스트→길 안내→표시의 점선 표시도 기존 노트 핀 연결선 표시와 같은 프로필 값을 사용합니다. OFF여도 핀·순번·안내는 유지합니다. 시계의 FPS·지연 표시는 실험실에서 제거한 성능 모니터와 별개로 유지합니다.
