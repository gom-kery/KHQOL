# PvP Alert v0.1 · KHQOL 1.8.5

화면에 네임플레이트가 있는 적 플레이어가 나를 주시하고, 접근하고, 나에게 시전하는 것을 단계적으로 알립니다.
기본값은 활성화 ON / 비전투 전용 ON입니다. Interface 16001을 유지합니다.

## 사용

1. 배포 ZIP의 `KHQOL` 폴더를 기존 애드온 폴더에 덮어씁니다. 기존 SavedVariables는 그대로 사용합니다.
2. `/kh pvp` 또는 `/khqol pvpalert`로 설정을 엽니다. 미니맵 설정의 `PvP Alert` 항목에서도 열 수 있습니다.
3. WATCHING, APPROACHING, CASTING 테스트 버튼으로 세 가지 표현을 확인합니다.
4. CASTING 테스트는 2.5초입니다. 시작 1초 후 남은 시간은 약 1.5초입니다.
5. `위치 이동 / 이동 완료`를 누른 후 프레임을 드래그합니다. 다시 누르거나 설정 페이지를 닫으면 잠깁니다.
6. 기본 위치는 화면 중앙 위 +165, 크기 및 투명도는 100%입니다. `위치 초기화`로 위치만 복원합니다.

## 표시

| 상태 | 표현 | 기본 효과 / 소리 |
|---|---|---|
| 주시 중 | 작은 노란 텍스트와 주시 아이콘, 배경 없음 | 0.15초 Fade In / 0.25초 Fade Out, 무음 |
| 접근 중 | 주황색, 검은 반투명 배경, 거리 단계 3칸 | 짧은 Pulse 1회, 약한 알림음 |
| 시전 → YOU | 빨간색, 주문 아이콘·이름, 감소하는 바와 남은 시간 | 120% → 100%, 테두리 Pulse, 강한 알림음 |

Primary 한 명과 Secondary 최대 세 명을 표시합니다. Secondary에는 한 줄만 표시합니다.
표시 상태가 바뀌면 즉시 반영하고, 효과·소리는 GUID별로 주시 5초 / 접근 4초 / 시전 1초 간격으로 제한합니다.
효과·소리는 Primary에만 적용하여 다중 적 상황의 소리 중첩을 줄입니다.

## 동작

`WATCHING`은 타겟 확인을 기다리는 내부 상태이며 아직 표시하지 않습니다.
0.4초 유지하면 `TARGETED`로 확정하고 화면에는 `주시 중`으로 표시합니다.
확정된 적만 거리 검사를 수행하고, 가까워지는 단계 변화 두 번을 관찰하면 `APPROACHING`이 됩니다.
같은 거리 유지로는 점수를 올리지 않습니다. 멀어지거나 거리가 판정 불가하면 `TARGETED`로 돌아갑니다.
일반 시전과 채널링 모두 감지합니다. 실제 시전 대상 이름이 나이면 즉시 `CASTING`이 됩니다.
실제 시전 대상이 다른 사람으로 확인되면 현재 타겟이 나여도 시전 경고를 표시하지 않습니다.
실제 대상 API가 없거나 값이 비어 있으면 현재 타겟을 보조 증거로 사용합니다.

## 사거리 / 호환성

Range 모듈을 꺼도 PvP Alert는 독립적으로 동작합니다. 기존 FRange DB와 함수에 의존하지 않습니다.
습득한 직업별 단일 대상 스킬 및 주문책을 기준으로 near / medium / far / out 단계를 구성합니다.
`C_Spell` → 현대식 주문책 → legacy 주문 이름 / 주문책 인덱스 순으로 호환 경로를 적용합니다.
근거리에는 기존 KHQOL에서 사용하는 아이템 범위 확인과 필요 시 짧은 상호작용 거리 구간을 보조로 사용합니다.
이 호출은 아이템을 사용하거나 주문을 시전하지 않습니다.
Hunter의 최소 사거리는 사거리 밖으로 오인하지 않도록 별도 확인합니다.
nil·보호된 값은 접근 증거로 쓰지 않고, 사용할 수 없는 API는 오류 없이 건너뜁니다.

API 및 사거리 진단 버튼에서 현재 캐릭터의 스킬 Provider, API와 이벤트 지원 여부를 확인할 수 있습니다.
Debug는 기본 OFF이며 켜면 채팅창에 상태 전이를 출력합니다.

## 알려진 한계 / 게임 검증

- 실제 Forever 클라이언트 실행 및 화면·음향·FPS 측정은 이 배포를 만드는 환경에서 수행하지 않았습니다.
- 네임플레이트가 없는 적, 은신 적, 이미 사라진 적은 감지할 수 없습니다.
- 타겟 확인은 기본 0.20초 간격으로 이루어집니다. 확인 완료 표시는 스캔 위상에 따라 약 0.4~0.6초 후 나타날 수 있습니다.
- 스캔 사이에 발생하고 끝나는 타겟 변화는 `UNIT_TARGET` 이벤트가 제공되어야 구분할 수 있습니다.
- 일부 직업·레벨은 판정 가능한 거리 구간이 적습니다. 두 번의 거리 변화를 관찰하지 못하면 주시·시전 경고만 동작할 수 있습니다.
- 화면 단계는 직업별 스킬 사거리에 따른 상대적인 구간입니다. 정확한 yard 또는 적이 이동한 방향을 계산하지 않습니다.
- 실제 시전 대상 API가 없는 경우 현재 타겟에 의존하므로 직접 시전 대상 여부를 확정할 수 없습니다.
- 보호된 적의 시전 타임스탬프는 계산하지 않습니다. 대상·주문명이 읽히면 시전 경고는 유지하고 `시간 확인 불가`를 표시하며 바는 숨깁니다.
- 전투 중 실행 옵션은 제공하지만 적 플레이어 정보 제한이 있는 클라이언트에서는 감지가 제한될 수 있습니다.
- 실제 `/reload` 후 설정 복원, 전장·필드의 네임플레이트 정보, 직업별 사거리, 일반 시전·채널 대상, 소리 및 위치 이동을 게임에서 추가 확인해야 합니다.

고급 Combat Log 분석, 스킬 위험도 데이터베이스, CC/DR/Trinket·쿨다운 추적은 v0.1 범위에 포함하지 않습니다.
