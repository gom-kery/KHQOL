# KHQOL 1.11.4.6 — 미니맵 KHQOL_Map

KHQOL 공통 기반 + KHQOL_Map으로 동작하며 계정 설정은 KHQOLMapDB입니다. 전체 ZIP에는 KH_map 호환 폴더가 없습니다. 기존 WTF·SavedVariables를 그대로 사용합니다.

미니맵/버튼 정리 두 탭, 자유 드래그·36px 트레이·HIGH 표시·보관 해제 복원과 /khmap·/kh_map·/khminimap 명령은 유지합니다. 일반 목록에 버튼 정리 진입도 표시하며 두 탭은 기존 미니맵 모듈 사용 상태를 공유합니다. 설정의 단일 항목/설명 전용 섹션과 공용 위치 편집 진입은 새 공통 정책을 사용합니다.

전체 설치 파일은 `KHQOL-1.11.4.6-탭설명-토템위치편집.zip`입니다. [설치 안내](../KHQOL/INSTALL-GUIDE.md), [변경·검증 보고서](../KHQOL/CHANGE-VALIDATION-REPORT.md).
