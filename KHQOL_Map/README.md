# KHQOL 1.11.3 — 미니맵 KHQOL_Map

KHQOL 공통 기반 + KHQOL_Map으로 동작합니다. 계정 설정은 KHQOLMapDB입니다. 이번 전체 ZIP에는 KH_map 호환 폴더가 없으며, 이미 생성된 KHQOLMapDB를 그대로 사용합니다. WTF는 삭제하거나 이름을 바꾸지 않습니다.

왼쪽 미니맵 메뉴는 인터페이스 아래에 있습니다. 미니맵/버튼 정리 두 탭과 공용 Design System v2.0, /khmap·/kh_map·/khminimap 명령을 유지합니다. 수납 버튼은 36px 트레이이며 화면 어디든 드래그해 놓고 계정 공용 위치를 저장합니다. 버튼과 수납함은 HIGH 계층이며 수납 해제 시 원래 아이콘 상태를 복원합니다. 위치 초기화는 버튼 정리의 수납 버튼 위치 초기화를 사용합니다.

독립 시절의 미사용 Theme.lua와 Switch.tga를 제외하고 TOC에서도 Theme.lua를 제거했습니다. 현재 설정 화면은 KHQOL.UI 공용 컨트롤을 사용합니다. 설치 절차는 ../KHQOL/INSTALL-GUIDE.md를 따릅니다.
