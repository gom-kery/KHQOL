# KHQOL_Map 1.11.9.6

외형 사용을 상단 모듈 사용에 통합했습니다. 지역명 표시는 기본ON이며 기존 위치·크기·호버 표시 방식을 유지합니다. 이전 appearance/zone 저장값은 호환을 위해 보존하지만 별도OFF 동작에는 사용하지 않습니다. 모듈OFF는 기존 journal로 기본 외형을 복원합니다. 하단 미니맵과 기본 행동 단축바 분리 수정도 포함합니다. 실제 게임 NOT TESTED.
