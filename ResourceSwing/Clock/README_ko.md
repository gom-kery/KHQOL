# ForeverClock 1.2.0

World of Warcraft Forever Beta용 소형 HUD 시계 애드온입니다. 중앙 시간이 기준점이며 날짜, 소지금, 성능 정보는 시계의 검은 배경 영역 안에서 자유롭게 배치할 수 있습니다.

## 설치

1. `ForeverClock` 폴더를 게임의 `Interface/AddOns/` 안에 그대로 복사합니다.
2. 게임을 시작하거나 `/reload`를 실행합니다.
3. 캐릭터 선택 화면의 AddOns 목록에서 **ForeverClock**이 켜져 있는지 확인합니다.

ZIP으로 설치한다면 압축을 푼 뒤 `AddOns/ForeverClock/ForeverClock.toc` 경로가 되도록 해주세요. `ForeverClock/ForeverClock/`처럼 폴더가 두 번 중첩되면 로드되지 않습니다.

## 사용 방법

- `/fclock` 또는 `/fc`: 설정 창 열기/닫기
- 미니맵 아이콘 왼쪽 클릭: HUD 전체 표시/숨김
- 미니맵 아이콘 오른쪽 클릭: 설정 창 열기/닫기
- 시계 왼쪽 클릭: 기본 Calendar 열기 (날짜 모듈을 숨긴 경우에도 사용 가능)
- 시계 오른쪽 클릭: 저장형 ToDO 메모장 열기/닫기. 여러 페이지를 만들고, 이름을 붙이고, 이전/다음으로 이동할 수 있습니다. 페이지별 텍스트/체크리스트 전환, 체크리스트 그룹, 완료 항목 하단 이동, `배경` 체크박스에 따른 배경/테두리 표시를 지원합니다. 아이템 링크 삽입은 대상 클라이언트 호환성을 확인할 때까지 보류합니다.
- 날짜 패널 오른쪽 클릭: 기본 Calendar 열기 (지원되는 클라이언트만)
- 설정의 `LOCK` / `UNLOCK`: 시계와 사이드 패널의 위치 잠금 전환. 잠금 상태에서는 시계의 큰 배경/외곽 테두리와 모든 사이드 패널의 배경/테두리가 숨겨집니다.
- 잠금 해제 후 시계 본체를 드래그해 HUD 전체를 옮기고, 날짜·소지금·성능 패널을 직접 드래그해 검은 배경 영역 안의 원하는 위치에 놓습니다. 위치는 저장됩니다.

설정은 즉시 반영되며 SavedVariables `ForeverClockDB`에 저장됩니다. 시계의 위치, 잠금, 글자 크기, 모듈 활성 상태/슬롯, 금액 표시 단위, 미니맵 아이콘 각도를 보존합니다.

## 텍스트 스타일

설정창에서 시계와 `사이드 글씨 크기` 대상(공통·날짜·소지금·요일·FPS·전문기술)을 선택한 뒤 글자색, 볼드, 텍스트 효과를 각각 지정할 수 있습니다. 효과는 없음·외곽선·두꺼운 외곽선·그림자입니다.

스타일은 `ForeverClockDB.textStyle`에 저장됩니다. 기존 사용자 데이터에는 현재와 같은 흰색·외곽선·볼드 해제 기본값만 자동 보완되며, 기존 크기·위치·모듈 설정은 변경하지 않습니다. 번들 폰트는 Light 단일 파일이므로 볼드는 글자를 미세하게 겹쳐 렌더링하는 방식으로 구현합니다.

## 파일 구성

- `ForeverClock.toc`: 애드온 메타데이터와 로드 순서
- `Locale.lua`: koKR 우선 / enUS 기본 문자열
- `Core.lua`: 데이터 초기화, 이벤트, 슬롯 교환
- `Clock.lua`: 중앙 시계, 드래그, 분 단위 갱신, 초대 Glow
- `Modules.lua`: 날짜·소지금·성능 모듈 및 저빈도 갱신
- `Calendar.lua`: Calendar 기능 감지 및 초대 처리
- `Minimap.lua`: 외부 라이브러리 없는 미니맵 버튼
- `Settings.lua`: 독립 설정 UI
- `Todo.lua`: 이동·크기 조절 가능한 다중 페이지 ToDO 메모장

## KHQOL 편입 준비 메모

ForeverClock은 현재 독립 실행·배포 가능한 애드온으로 유지합니다. KHQOL 통합을 위한 별도 Core, 통합 설정창, 의존성은 포함하지 않습니다.

- 코드 경계: 시계(`Clock.lua`), 알람·타이머(`ClockTools.lua`), 사이드 모듈(`Modules.lua`), 전문기술(`Professions.lua`), 달력(`Calendar.lua`), 메모(`Todo.lua`)는 현재 파일 단위 경계를 유지합니다.
- 데이터 경계: 저장 데이터는 고유 SavedVariables인 `ForeverClockDB` 아래에만 보관합니다. 향후 편입 시 KHQOL의 모듈 저장 영역으로 이 테이블을 한 번만 이관하거나, 기존 테이블을 호환 데이터로 읽으면 됩니다.
- 이름 충돌 방지: 애드온 공유 테이블은 `FC`, 전역 프레임 이름은 `ForeverClock` 접두사를 사용합니다. 새 전역 변수·프레임·슬래시 명령은 같은 접두사 규칙을 따라야 합니다.
- 편입 시점: KHQOL이 모듈 등록·설정·활성화 인터페이스를 확정한 뒤, 각 생성 함수와 설정 데이터를 그 인터페이스에 연결합니다. 그 전에는 현재 독립 애드온의 동작과 UI를 변경하지 않습니다.

## Forever Beta에서 확인할 호환성 항목

이 애드온은 존재 여부를 먼저 확인하는 방식으로 Calendar와 성능 API를 사용합니다. 실제 클라이언트에서 다음을 확인해 주세요.

1. `.toc`의 `## Interface: 120000`이 해당 Forever Beta 빌드의 인터페이스 번호와 맞는지 확인합니다. 다르면 그 숫자만 빌드 번호로 바꾸면 됩니다.
2. Calendar를 열 수 있는 함수가 `ToggleCalendar`, `CalendarFrame_Show`, 또는 `CalendarFrame:Show()` 중 하나인지 확인합니다.
3. 대기 초대 수 API가 `C_Calendar.GetNumPendingInvites()` 또는 `CalendarGetNumPendingInvites()`인지 확인합니다.
4. 초대 변경 이벤트가 `CALENDAR_UPDATE_PENDING_INVITES`, `CALENDAR_UPDATE_INVITE_LIST`, `CALENDAR_UPDATE_EVENT_LIST` 중 어떤 것인지 확인합니다.
5. `GetNetStats()`가 반환하는 네 번째 값(월드 지연시간)을 지원하는지 확인합니다.

Calendar API가 없거나 달라서 호출할 수 없으면 Clock, Date, Money, Performance은 계속 동작합니다. 날짜 오른쪽 클릭 시 채팅창에 미지원 메시지만 표시합니다. 초대 수 API가 없으면 초대 Glow/알림만 조용히 비활성화됩니다.

## 인게임 점검 순서

1. 로드 후 중앙 시간이 분 단위로 바뀌는지 확인합니다.
2. `/fc`에서 중앙/사이드 글자 크기, 각 모듈 토글, 골드·실버·코퍼 체크박스를 변경합니다.
3. `UNLOCK` 상태에서 사이드 모듈을 검은 배경 영역 안의 원하는 위치로 끌고, `/reload` 뒤에도 위치가 유지되는지 확인합니다.
4. `UNLOCK`에서 시계를 옮긴 뒤 `/reload`하여 위치가 유지되는지 확인합니다.
5. `LOCK`에서 시계가 움직이지 않는지 확인합니다.
6. 돈을 얻거나 사용해 소지금이 바로 갱신되는지 확인합니다.
7. 미니맵 버튼 동작과 Calendar/초대 동작을 확인합니다.

## 성능 설계

시간과 날짜는 분 경계에 맞춰 갱신합니다. 소지금은 `PLAYER_MONEY` 이벤트에서만 갱신합니다. FPS/지연시간은 성능 모듈이 표시 중일 때만 2초 `C_Timer`로 갱신합니다. 상시 HUD 전체를 계산하는 `OnUpdate`는 없으며, 미니맵 버튼은 실제 드래그 중에만 커서 위치를 읽습니다.
